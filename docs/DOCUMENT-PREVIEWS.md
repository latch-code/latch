# 文档预览

`DocumentPreview` 接收已授权的 `FileMetadata`、文件版本键、读取字节的回调与 `renderFrame`。读取回调的 Range 末端是包含端点；PDF 的范围传输把其排除端点减一再交回父页。秘密文件和没有 `actions.preview` 的文件在读取前拒绝。文件、版本或组件撤下时取消读取与渲染，销毁 worker 和 MessagePort。

PPTX 使用逐页纵向窗口化列表、适应宽度、页码、翻页与手机横向滑动。备注从每页关系对应的 notesSlide 提取，只作为文字放在折叠块；不增加缩略图栏、搜索或放映。DOCX 保留分页、页眉页脚、脚注，修订显示为实验开关。文档原色与排版由框内渲染器处理，界面外壳跟随 UI 令牌。

XLSX 由第一方读取器处理工作表、共享/内联字符串、缓存公式、数字格式、1900/1904 日期、合并区域、列宽与冻结信息。公式不执行、外部链接和宏不读取。隐藏表保持隐藏；超出预算时标明部分内容未显示。CSV/TSV 在 worker 解析，按 BOM 判断 UTF-8/UTF-16，分隔符可切换；公式形状的输入仍是文字。

`SheetGrid` 在页面上做行列虚拟化，提供范围选择、方向键、TSV 复制与列宽调整，使用 `role=grid`。复制限制为一万个单元格与一百万字符，超出时要求缩小选区。PDF 使用核心 API 的 canvas 与纯文本层，不执行 PDF 动作。PDF 字符选择的几何行框使用文档单位，不继承界面字号。

`NOTICE` 与公开许可证目录保留实际依赖和内嵌 MPL 代码的对应源码位置。供应链金丝雀检查依赖年龄和脚本策略；格式 e2e 使用生成的样例与真实 worker，覆盖缓存公式、字面文本、PPT 窗口化、PDF 范围读取及查找。

## 工作台与文件服务

Host 声明 `catalog.features.filePreview` 时，回复中的文件标记单击打开同一会话侧列的文件标签，右键或向下箭头打开原文件菜单。会话信息和可信插件面板保留各自标签，不共用文档运行环境。每个会话或项目/Harness上下文最多六个文件；本设备最多记住四十个上下文的相对路径与文件夹 ID，不保存文件字节或句柄。Office、PDF、HTML 默认半个窗口，至少 480px；文本、代码、图片默认 320px，最窄 280px，分别记住内容列与文档列宽度。对话保留 520px，必要时收起侧栏，窄屏推入文件页。展开按钮可把文件列变为整页。更新、下载、复制、引用与原生动作收进文件菜单，减少常驻图标。旧 Host 缺少能力时保留原来的文件菜单与复制行为。

父页通过已授权句柄读内容，并给分块读取附上原始 ETag 的 `If-Match`；媒体地址通过 `v` 绑定同一版本。Host 返回 412 时拒绝混入新版本。可见文件每两秒查元数据，变化后保留旧内容并提示更新，删除保留已读画面和原因，权限被撤回则卸载内容。句柄过期只自动重取一次，失败后要求重新打开。下载随标签卸载取消。大文本按 200 行呈现并支持查找、跳行、换行，超过读取上限标明截断。媒体沿用同一受限 Range 服务。

可能含密钥的文件只显示文本。文件的复制、引用到输入框，以及桌面端真实可用的访达、快速查看、默认应用动作仍经原先的 Host 裁决；Quick Look 未完成真实网络验收的格式继续拒绝。

### 文件树与项目上下文

文件树从标题栏或会话面板的「文件」进入；新会话选中已保存项目时也可打开，默认私有会话目录尚未创建时不虚构文件。首个根自动展开，其余目录按点击加载一层。键盘支持上下、首尾、左右展开/折叠与 Enter 打开；符号链接只标记。客户端串行读取目录，每层先显示 100 项、按需再显示 100 项，整棵树最多显示 1,000 行；保留至多 32 个展开的有内容目录，并回收已收起的旧缓存。隐藏项和生成目录可切换，目录变化可就地重试，项目根配置变化会清理树缓存。

文件标签的持久状态显式保存 session 或 workspace/Harness 上下文，兼容旧的 sessionId 记录；不持久保存字节、文件句柄或搜索结果。项目预览、相对 Markdown 链接、图片和文件搜索都用同一上下文。引用动作把根 ID 与相对路径作为结构化 `fileRefs` 随原请求发送，并保留原草稿；Host仍重新授权。`work`设备隐藏树与文件搜索，已有会话引用继续可打开。

## 浏览器与桌面边界

预览在浏览器隔离框内运行，不是 OS 沙箱，浏览器也不保证文档数据的完整机密性；可能含密钥的文件只显示文本。

## 代码、Markdown、公式和图表

`useHighlightedTokens` 把有界源文交给共享 Shiki worker，返回逐行 `{text, role}`；页面核对每个字符与原输入一致，只接收固定八种角色，通过 React span 和 `VisibleText` 显示。30 种常用语法按需加载，使用 JavaScript 正则引擎；不返回 HTML 或任意颜色。整块超过 200 KB、任一行超过 1,000 字符、不支持的语法或 worker 超过五秒，均保留纯文本。请求延迟 300 ms；缓存最多 30 块，超时销毁 worker。流式回复只对闭合围栏着色，差异块按完整旧/新文本着色后逐行取出。查看器可使用同一 hook 保留行号、查找和跳行。

`MarkdownPreview` 使用 `MessageContent` 静态模式，保留 URL 检查、跳过 HTML、深度限制和文件路径标记。文件列提供预览与源码切换，相对链接按该文件的目录归一化，在同一会话、同一冻结根中打开。会话正文和文件列共用图片解析器：先通过会话文件服务授权，再使用绑定 ETag 的句柄 URL；不取得绝对路径或其他文件的内容。`work` 范围仍只允许会话已经提到的路径，不因 Markdown 中出现一个新链接而放宽。秘密、未知尺寸、过大或不可读图片保留路径入口；元数据给定尺寸后再加载图片，点击可打开文件列。图片回调只接受同源 Host 文件句柄 URL 或宿主创建的 blob，最大显示宽度 320px。远端图片仍为普通链接，不发送第三方请求。秘密文件保持纯文本，不调用高亮、数学或图表渲染器。

源码查看器复用共享高亮 worker，保留行号、复制、查找与跳行；在查看器内按 Command/Ctrl-F 聚焦本列查找。更新文本期间保留已读内容与行位置，新版本变短时夹到末尾；查找词和换行偏好保留。正常会话在 Host 声明文件预览能力时启用图表框，没有能力的旧 Host 保留代码块。

`remark-math` 解析美元围栏，单美元两侧必须贴着非空白文字，货币保持文字；第一方预处理还接受代码之外的 `\(…\)` 和 `\[…\]`。KaTeX 延迟加载；失败显示 TeX 源码。

Mermaid 在独立框内加载，渲染结果作为图片显示。可以切换图与源码、放大后滚动；触摸设备与 WebKit 由点击开始渲染。缺少 frame 宿主时保留代码块，卸载回收 frame 和 Blob URL。

新增依赖均固定在 catalog，发布至少七天；`micromark-extension-math>katex` override 收紧到 0.19.0。公开目录 `licenses/rich` 保留依赖许可证；EPL-2.0 的 elkjs 源码位置见 `NOTICE`。

消息附件使用同一个文件列，但通过 `attachmentId` 换取独立内容句柄，标签保存其有限 ID。私有附件没有项目路径、原生文件动作或文件引用到输入框；草稿尚无会话时只在输入框预览。详细契约见 [ATTACHMENTS.md](ATTACHMENTS.md)。

## HTML 页面

HTML 默认静态显示；桌面端可按文件开启「运行页面脚本」，脚本没有网络与同源权限。

图片的 100% 对应一个图片像素到一个 CSS 像素；适应模式按可用宽高缩小，不放大小图。Command/Ctrl 加滚轮、加减键与双指缩放围绕当前点调整，拖动平移，0 回到 100%，F 适应；同一标签更新后保留缩放。棋盘可在固定的浅、深背景间切换，颜色来自 UI 的预览令牌，不随主题反转。SVG 仅作为 img，并可切换源码。Host 签发元数据时就拒绝超过本机一亿、其他设备五千万像素的预览；未知尺寸只提供元数据与有界下载，页面不尝试解码。格式不支持或头部不足以确认尺寸时也按此处理。

文本查找用 CSS Custom Highlight 标记当前两百行中的匹配，能跨越语法 span，不改写 DOM；最多一千个可见匹配。查询最多 512 字符，不支持 Highlight 的浏览器仍可查找并跳行。

## 单个文件的历史变更

会话信息的变更行打开同一文件列的历史视图，预览入口仍可读取当前文件。历史按冻结文件夹 ID 和相对路径归组；相同文件名不会跨根合并，也不改写文件名的 Unicode 编码。界面显示文件夹名称，ID 只用于内部关联。

历史直接使用 Host 已记录的工具差异，按用户轮次关联，保留消息顺序的原始记录；界面从最新修改开始展示，可切换本轮与历史。它不运行 Git、不重新读取旧文件或创建本地快照。仍在排队、等待审批或实际未运行的拒绝调用不计入；已经执行的 Agent 调用保留其真实记录，即便它的权限询问只是建议。文件删除后，历史仍可查看；预览当前文件另经原文件服务裁决。切换视图只记在本设备的文件标签状态中，不把差异字节另存浏览器。


Office 更新版本时保留当前页、适应状态与有限缩放比例，页数变少时夹到末页。⌘/Ctrl ± 与双指缩放不增加工具栏按钮，⌘/Ctrl 0 恢复适应宽度。文档只读，页首说明排版可能与原应用不同。点击文档里的外链在默认浏览器打开。

设置中的「运行结束后自动打开新生成的文档」默认开启，仅作用于本设备，保留用户明确关闭的偏好。`useAutoOpenOutputs` 只考虑当前视图确实见过运行中的那一轮，等待输出观察结算，在能同时保留对话与至少 480px 文档列的宽屏中展开首个明确新增的文档；文件列先前可以关闭。打开不移动输入焦点、不改草稿；手机、设置页和展开审阅时不抢占当前页面。失败、取消、修改文件、加载历史或切换会话后的旧结果都不自动打开。macOS 快速查看仍由文件宿主按白名单与设备权限决定。

`@latch/testkit` 的 `documentFixtures` 生成 DOCX、XLSX（缓存公式、日期、合并与隐藏表）、窗口化 PPTX（1–500 页与备注）及 PDF；测试提供已有 ZIP 编码器，无第三方样本进入仓库。没有所有者从 PowerPoint/Keynote 导出的参照图时，只报告真实渲染结果，不声称原应用逐像素保真。

代码审阅在宽屏提供行内与左右对照，左右布局先展开文件列；窄屏保持行内及旧/新行号。每个修改块独立保留两侧行号与空行，插入或删除缺失的一侧留空，不把未提供的原内容说成新文件。代码在各自区域横向滚动；多文件导航按冻结根与路径区分。历史初始最多五次修改，最新一项展开，其余折叠，更早记录按需加载；语法高亮仍只在可见展开项中请求。
