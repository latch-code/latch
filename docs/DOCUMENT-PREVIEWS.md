# 文档预览

`DocumentPreview` 接收已授权的 `FileMetadata`、文件版本键、读取字节的回调与 `renderFrame`。读取回调的 Range 末端是包含端点；PDF 的范围传输把其排除端点减一再交回父页。秘密文件和没有 `actions.preview` 的文件在读取前拒绝。文件、版本或组件撤下时取消读取与渲染，销毁 worker 和 MessagePort。

PPTX 使用逐页纵向窗口化列表、适应宽度、页码、翻页与手机横向滑动。备注从每页关系对应的 notesSlide 提取，只作为文字放在折叠块；不增加缩略图栏、搜索或放映。DOCX 保留分页、页眉页脚、脚注，修订显示为实验开关。文档原色与排版由框内渲染器处理，界面外壳跟随 UI 令牌。

XLSX 由第一方读取器处理工作表、共享/内联字符串、缓存公式、数字格式、1900/1904 日期、合并区域、列宽与冻结信息。公式不执行、外部链接和宏不读取。隐藏表保持隐藏；超出预算时标明部分内容未显示。CSV/TSV 在 worker 解析，按 BOM 判断 UTF-8/UTF-16，分隔符可切换；公式形状的输入仍是文字。

`SheetGrid` 在页面上做行列虚拟化，提供范围选择、方向键、TSV 复制与列宽调整，使用 `role=grid`。复制限制为一万个单元格与一百万字符，超出时要求缩小选区。PDF 使用核心 API 的 canvas 与纯文本层，不执行 PDF 动作。PDF 字符选择的几何行框使用文档单位，不继承界面字号。

`NOTICE` 与公开许可证目录保留实际依赖和内嵌 MPL 代码的对应源码位置。供应链金丝雀检查依赖年龄和脚本策略；格式 e2e 使用生成的样例与真实 worker，覆盖缓存公式、字面文本、PPT 窗口化、PDF 范围读取及查找。

## 工作台与文件服务

Host 声明 `catalog.features.filePreview` 时，回复中的文件标记单击打开同一会话侧列的文件标签，右键或向下箭头打开原文件菜单。会话信息和可信需求包面板保留各自标签，不共用文档运行环境。每会话最多六个文件；本设备最多记住四十个会话的相对路径与文件夹 ID，不保存文件字节或句柄。文件列默认半个窗口，至少 480px，并给对话保留 520px；必要时收起侧栏，窄屏推入文件页。展开按钮可把文件列变为整页。旧 Host 缺少能力时保留原来的文件菜单与复制行为。

父页通过已授权句柄读内容，并给分块读取附上原始 ETag 的 `If-Match`；媒体地址通过 `v` 绑定同一版本。Host 返回 412 时拒绝混入新版本。可见文件每两秒查元数据，变化后保留旧内容并提示更新，删除保留已读画面和原因，权限被撤回则卸载内容。句柄过期只自动重取一次，失败后要求重新打开。下载随标签卸载取消。大文本按 200 行呈现并支持查找、跳行、换行，超过读取上限标明截断。媒体沿用同一受限 Range 服务。

可能含密钥的文件只显示文本。文件的复制、引用到输入框，以及桌面端真实可用的访达、快速查看、默认应用动作仍经原先的 Host 裁决；Quick Look 未完成真实网络验收的格式继续拒绝。

## 浏览器与桌面边界

预览在浏览器隔离框内运行，不是 OS 沙箱，浏览器也不保证文档数据的完整机密性；可能含密钥的文件只显示文本。

## 代码、Markdown、公式和图表

`useHighlightedTokens` 把有界源文交给共享 Shiki worker，返回逐行 `{text, role}`；页面核对每个字符与原输入一致，只接收固定八种角色，通过 React span 和 `VisibleText` 显示。30 种常用语法按需加载，使用 JavaScript 正则引擎；不返回 HTML 或任意颜色。整块超过 200 KB、任一行超过 1,000 字符、不支持的语法或 worker 超过五秒，均保留纯文本。请求延迟 300 ms；缓存最多 30 块，超时销毁 worker。流式回复只对闭合围栏着色，差异块按完整旧/新文本着色后逐行取出。查看器可使用同一 hook 保留行号、查找和跳行。

`MarkdownPreview` 使用 `MessageContent` 静态模式，保留 URL 检查、跳过 HTML、深度限制和文件路径标记。文件列提供预览与源码切换，相对链接按该文件的目录归一化，在同一会话、同一冻结根中打开。会话正文和文件列共用图片解析器：先通过会话文件服务授权，再使用绑定 ETag 的句柄 URL；不取得绝对路径或其他文件的内容。`work` 范围仍只允许会话已经提到的路径，不因 Markdown 中出现一个新链接而放宽。秘密、未知尺寸、过大或不可读图片保留路径入口；元数据给定尺寸后再加载图片，点击可打开文件列。图片回调只接受同源 Host 文件句柄 URL 或宿主创建的 blob，最大显示宽度 320px。远端图片仍为普通链接，不发送第三方请求。秘密文件保持纯文本，不调用高亮、数学或图表渲染器。

源码查看器复用共享高亮 worker，保留行号、复制、查找与跳行；在查看器内按 Command/Ctrl-F 聚焦本列查找。更新文本期间保留已读内容与行位置，新版本变短时夹到末尾；查找词和换行偏好保留。正常会话在 Host 声明文件预览能力时启用图表框，没有能力的旧 Host 保留代码块。

`remark-math` 解析美元围栏，单美元两侧必须贴着非空白文字，货币保持文字；第一方预处理还接受代码之外的 `\(…\)` 和 `\[…\]`。KaTeX 延迟加载；失败显示 TeX 源码。

Mermaid 在独立框内加载，渲染结果作为图片显示。可以切换图与源码、放大后滚动；触摸设备与 WebKit 由点击开始渲染。缺少 frame 宿主时保留代码块，卸载回收 frame 和 Blob URL。

新增依赖均固定在 catalog，发布至少七天；`micromark-extension-math>katex` override 收紧到 0.19.0。公开目录 `licenses/rich` 保留依赖许可证；EPL-2.0 的 elkjs 源码位置见 `NOTICE`。
