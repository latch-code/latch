# 个人助手

个人助手与项目工作共享 Harness、模型服务和插件注册表。日常会话不要求先保存项目；助手的名字、职责、Harness、模式、模型和插件选择保存在 Host。`GET /link/api/personal` 返回助手概览，助手详情包含用户明确维护的记忆和直接归属的会话。客户端仅在 `catalog.features.personal` 为真时提供入口。

`POST /personal/assistants` 创建配置，`PATCH /personal/assistants/:id` 使用 `baseRevision` 作并发检查。`/personal/assistants/:id/memories` 支持用户创建、修改和删除记忆；模型没有写入记忆的工具。每条记忆最多 4000 字、每个助手最多 128 条且正文总计不超过 256 KiB；全部定义最多 512 KiB，保证有界手机响应。`model: null` 可恢复使用默认模型。

个人助手数据只对完整数据范围的设备开放；范围不足时说明如何在电脑上允许。

Web 与桌面在导航提供「个人助手」，展示真实助手、职责、直接会话与显式记忆。创建和编辑使用 Host 声明支持私有上下文的 Harness、实际模型和已启用插件的有限元数据；普通已允许设备不需要额外管理权限来选择插件。新会话只提交助手 ID、输入和附件／引用，普通项目选择与模型覆盖不会混入。既有私有会话使用同一份对话、审批、取消和阅读位置界面；模型与执行方式回到助手配置中修改，不提供必然被 Host 拒绝的会话覆盖控件。

页面只在可见时读取职责和记忆，卸载、数据范围收紧或查看权限消失时撤下内容与编辑器，不写浏览器本地存储。刷新提示只传计数，在私有页面中合并后重新授权读取，不在流式 token 变化时反复取私有正文。配置和记忆的未知提交保留完整请求与同一个请求 ID，重试不会创建第二条记录；新对话沿用已有持久提交恢复流程。

## 创建与继续会话

`POST /link/api/tasks` 接受 `{assistantId,prompt,requestId,attachmentIds?,fileRefs?}`；助手会话不能同时传入 `workspaceId`、`harnessId`、`mode`、`model` 或 `forkOf`。Host 从已保存配置选择执行端，沿用普通创建路径的目录、风险分级、审批、出站和本机确认规则。Agent 模式在默认启动目录下沿用自有会话目录；显式配置的工作区共享行为不变。归属在执行开始之前随 `TaskSummary.personal` 持久化，Host 收到新 ID 时先保守标为私有，再保存 Host 元数据。后者失败不撤回内存分类；未知请求恢复先补写元数据，私有 Driver 在 Host 接受请求前从实际会话重建分类。目录或项目归属不代替助手归属。

`TaskSummary.pluginIds` 记录本轮选择的插件。Standard 的 `registry.acquire(providerId,{tools,pluginIds})` 只租用这些已启用插件贡献的工具和技能，空数组表示不提供 Host 工具或技能。Provider 本身独立租用，Provider 所属插件的工具不会因此自动被选中。实际工具分发也使用同一租约；这不是提示词约定。插件和外部 Agent 仍是可信本机代码，应用层选择不构成 OS 沙箱。

职责和私有记忆只放在当前运行的系统上下文中，不写入用户 `Message.text`、模型持久历史、分叉种子或导出记录。下一轮由 Host 重新读取本助手的显式记忆；其他助手、项目会话和群聊不自动继承。助手生成的可见回复仍属于用户选择查看或分享的会话内容。

Driver 必须显式声明 `agentContext: 'private'`，确保隐藏上下文不进入可分叉历史并执行所选 Host 能力边界。当前内置 Standard 实现该契约；没有声明的 ACP 或自定义 Driver 在界面中给出不可用原因，不会静默回退。更换 Harness 或模式后，原会话不能迁移执行，需创建新会话。个人会话的队列能力由 `catalog.features.personalQueue` 单独声明；缺少时客户端不能把普通队列当作已支持。

## 个人会话队列

个人助手复用 Host 的普通持久 FIFO，每个会话最多五条。`POST /tasks/:id/prompt` 的 `queue:true` 固定当前实际模型、执行配置哈希和原设备；职责、记忆、Harness、模式、插件代码及配置参与绑定，展示名字不参与。队列只持久化哈希与模型，私有指令在派发前重建，不进队列文件、审计或普通消息。无显式助手模型时继续沿用该会话的实际模型，不因 Host 默认模型变化而自动迁移。

入队、编辑与派发都复查当前个人数据权限。职责或执行配置改变时保留文字并暂停，用户移除旧项后重新加入；不能通过编辑文字或手动发送把旧项改绑到新配置。重启暂停、未知结果保持原请求、实际完成才发送下一条等规则沿用普通队列。手机固定最初的 App 窗口哈希，到期或新代次不能复用新验证继续旧队列。群聊管理的子会话仍不提供独立输入与队列，附件及文件引用尚不支持排队，接口严格拒绝。

## 持久化与未知结果

每次修改携带 `requestId`，按设备和操作内容保存哈希回执；同编号不同内容返回冲突。删除减少私有数据，审计故障仍执行并返回 `x-latch-audit: failed`。

会话启动先落盘原始 Harness、模式、模型、插件与定义摘要。派生的内部请求 ID 绑定设备，重试不会迁往后来修改的 Harness。已接纳的用户输入用 `Message.requestId` 找回原会话；尚未确认且定义变化时拒绝自动重跑，提示先同步。私有记忆正文不写入这个启动回执。

原子写在 rename 后也可能失败。此时保留本次待确认草稿与已分配 ID，拒绝其他修改和读取，直到同一请求成功确认；不会再分配第二个助手或第二条记忆。重启从持久回执恢复。已删除实体的原始创建请求返回已删除，不复活记录。修改回执和启动预留各最多 10000 条且不淘汰；容量满时新授予失败，删除仍可执行。删除不清理启动身份，避免迟到重试重新执行。

## 每日定时任务

`catalog.features.personalRoutines` 表示 Host 已接入真实每日调度。`POST /personal/routines` 创建停用的任务；`PATCH /personal/routines/:id` 使用 `baseRevision` 修改；`POST /personal/routines/:id/enabled` 接受 `{requestId,baseRevision,enabled}`。开启只允许已登记的电脑端通过 `host.sock` 明确操作，L1 不额外请求 Touch ID。关闭只影响以后启动，正在执行的会话继续显示真实状态，可从实际会话取消；删除要求当前执行已结算。`GET /personal` 的 `plugins` 仅提供启用插件的 ID、名字、说明与能力名称，普通私有数据查看设备无需管理员权限也能选择插件，不能借此读取源码或配置。

定义或执行配置变化后任务暂停，需重新开启。

每日时间按指定 IANA 时区计算。夏令时跳过不存在的当地时间；同一当地日期最多执行一次，回拨重复时刻不能触发第二次。`unattended.maxLevel` 约束 L1（低于 L1 时不能开启或运行）；开启者超过配置的闲置天数后暂停。等待审批超过 Standard TTL 时调用实际执行端取消，直到执行结算后才显示取消，不能自动批准。Host 最多同时跟踪两个例行执行；停机错过和超过一分钟的过期时间暂停，不能在重启后批量补跑。任务先在 `personal/routines.json` 的严格记录中保存本次唯一请求与日期，再沿现有 Standard 执行；Agent 模式沿用自有目录规则、工具风险分级和真实审批，不增加自动批准 R2 或 L3 的路径。

已接受会话 ID 的运行只依据执行端 `runOutcome` 结算；失败和取消保留实际结果，不伪报完成。创建结果未知或只有已保存意图而没有会话回执时暂停，不自动重发。原子存储恢复仅重写同一份状态，不能调用执行回调；已经成功的创建与开启请求必须继续使用原 `requestId`，冲突内容拒绝。设备撤销、范围变化、模型或插件失效以及执行配置变化会在下一次启动前暂停。定义与结算变化仅发无私有正文的全局刷新提示，客户端再按原私有门禁读取。

## 助手群聊

`catalog.features.personalGroups` 表示已经实现真实接力。`POST /personal/groups` 创建名字、成员、默认回复者、共同指令与 `maxRelays`；`PATCH /personal/groups/:id` 使用 `baseRevision`，删除要求当前轮次已结束。最多 32 个群聊，每组 1–8 个成员；目前只接受有真实私有上下文接口的 Standard。群聊读取与新输入沿用个人助手的 `all` 数据范围和手机正文窗口。

`POST /personal/groups/:id/messages` 接受 `{requestId,prompt,assistantIds?}`，原文与原请求 ID 先落盘。没有指定响应者时只使用默认成员；有指定时按用户明确的顺序执行，最多 `maxRelays + 1` 位且不超过四位，模型文本不能扩大接力。每位成员创建一个真实 Harness 会话，固定所选模型、插件与能力租约；职责只给该成员自己的临时系统上下文，私有记忆不读取。下一位只得到明确共享的用户发言与可见回复，保留原 `user` / `assistant` 角色；最近至多 64 条、256 KiB 的共享上下文不进入子会话持久历史。自己的职责也不进入公共历史，成员的可见回复仍由用户选择在群聊中共享。

每个轮次边界复核所有本轮成员的职责、模型、Harness、插件代码与配置，以及原始设备权限。职责与执行配置变化会停止后续成员并给出 `turn.reason`；名字或私有记忆的正常编辑不打断群聊。手机自动接力固定原 App 窗口，重新解锁不能把旧轮次改绑到新窗口。失败、取消、未知或中断不能自动进入下一位；等待审批显示真实子会话，问答数量来自 Host 实际问题记录，用户在该会话处理。群聊不批准 R2，不开启 L3，不声称插件是 OS 沙箱。没有邮件等插件时不会显示发送能力。

`GET /personal/groups/:id` 返回群聊、可见发言、当前轮次和至多 64 个实际子会话，优先保留本轮成员，再按最近更新排列。成员完成后才发布群内回复摘要，过长内容明确提示打开完整子会话；界面可链接正在执行的子会话查看真实流。群内正文最多保留 512 条且总量不超过 192 KiB，接收前为本轮全部成员预留空间；满时拒绝新轮次，原内容保留，不自动淘汰历史。附件和文件引用尚未接入群聊输入，严格拒绝；进行中发送返回冲突，不能把它当作已实现的群聊队列。

`POST /personal/groups/:id/cancel` 只接受 UUID `requestId` 与准确 `turnId`，先停止继续接力，再等待已启动子会话真实结算。它在手机锁定时仍可用，只返回 `{accepted,turnId,state}`，不返回正文。取消回执持久化；迟到的旧轮次请求不能停止新轮次。

群聊定义、发言、轮次与哈希回执在私有 `personal/groups.json` 中严格校验，复用原子存储。未知写入只恢复同一份状态，不重复启动成员；Host 重启将未结束轮次标为中断，不自动重放。关闭时等待已接纳请求、实际取消和存储完成，不在关闭后启动新成员。所有配置与轮次变化只发无正文的全局刷新提示，客户端再按私有门禁读取。


## Web 群聊与定时任务

个人助手页按 `personalGroups` / `personalRoutines` 真实能力显示群聊和定时任务。群聊只读取共享记录，成员选择保留用户明确的回复顺序与保存的接力上限；不读成员私有记忆，不把附件、文件引用或排队显示为可用。流式内容、审批和问题打开实际成员会话处理。取消固定实际 `turnId`，独立于普通写入保留原停止请求 ID，等待 Host 的真实结算。

例行表单只提交名字、助手、明确内容和每日 IANA 时区计划；创建不带 `enabled`，由 Host 保存为关闭。开启只在真实 `access.local` 时提供，沿已实现接口直接请求，不增加本机确认墙；允许写入的其他设备仍可暂停以后执行。未知请求保留完整请求体和原编号，不能改成新的创建或开启。时间、结果、会话链接只取 Host 返回值。

`PersonalPage.open` 默认开启。工作台在个人访问仍允许时可保留页面组件、仅撤下 Modal；隐藏时停止读取，有限群聊草稿和未知请求在内存保留，不写浏览器存储。`initialGroupId` 与 `onGroupSession(sessionId,groupId)` 让工作台记录来源并返回原群聊。个人访问失效时父级卸载页面，页面也清理私有状态；迟到请求按权限代次丢弃。群聊和例行页按需加载，不增加普通首条消息的加载链。纯 Node 的表单和 payload 用例不能代替浏览器三宽、未知结果恢复及成员会话只读接线验收。

## iPhone 与 iPad

原生应用在 Agent 标签下提供「助手与群聊」入口，读取 Host 真实配置并编辑职责、模型、已安装插件和显式记忆；插件选项直接来自个人概览的受限元数据，普通使用设备无需管理员接口；不要求先选项目。`HarnessInfo.personalContext` 只由 Driver 的真实声明发布，手机只提供已有 L1 私有上下文的执行方式。消息继续用现有 TextKit 2 对话与输入视图；所有编辑器同样使用本机、到期剪贴板，窗口过期、设备权限变化或换电脑时撤下私有内容并关闭编辑器。冷缓存只保留会话的 `personal` / `pluginIds` 等归属元数据，记忆和职责不会进入列表缓存。

群聊与定时任务在个人助手首页提供独立入口，按 Host 的真实能力标记显示。群聊用 TextKit 2 展示共享历史，回复顺序由用户明确选择，最多遵守 Host 保存的四人接力预算；进行中输入、附件及群聊队列不显示为可用。正在执行、等待审批和问答均链接到实际成员会话，管理子会话不出现独立输入框。群聊取消只保留已知轮次 ID 与状态，正文窗口到期仍可发起无正文停止；未知取消从加密 control 回执复用原请求，不生成新 ID。全局结果待确认入口只显示通用状态，原停止按钮因终态消失后仍可明确重试上次操作；重连仅读取回执元数据，不自动重放。

手机可创建、编辑或删除已结算的定时任务，也可暂停以后执行；开启提示回电脑明确操作，不在手机提供必然被拒绝的开关。例行时间绑定 IANA 时区，最新执行跳到普通实际会话。群聊详情、例行内容和全部表单草稿随权限变化、窗口到期或换电脑撤下，不写列表缓存。普通个人会话按 `personalQueue` 开启真实队列，配置变化原因使用 Host 返回的说明。全局刷新提示合并后重新读取个人页面，逐 token 的会话事件不触发反复读取职责与记忆。

手机显式点击文件预览时，已核对句柄与 ETag 的大文件可使用 Host 声明的原生大文件通道，自动预览保留普通请求。手机文件预览展示真实收到字节的进度。取消会取消拥有的 Swift Task，关闭当前读取流，后续 Range 不再启动；旧任务的晚回按请求与内容代次丢弃。格式白名单仍为 UTF-8 文本与重绘 PNG/JPEG，不因个人助手入口而放开 Quick Look 格式。

自动验证包含真实 Swift 连接临时 Host 的配对、正文窗口、Mac 显式授权、配置/记忆/会话/幂等/缓存归属与删除链。SDK 构建不代表真机 Face ID、Secure Enclave 或视觉验收；无已安装模拟器运行时时不声称已有原生截图。
