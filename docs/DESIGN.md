# Latch 界面设计

Latch 是跨设备的 Agent 工作台：任务在 Host 上运行，用户从桌面、浏览器或手机查看、审批、取消并继续同一段工作。界面要同时表达会话内容、执行状态、设备连接与设备权限，且只展示真实存在的能力。传输、续期与阅读位置的机制见 [STREAMING.md](./STREAMING.md)。

## 品牌与原则

- **名称与图标。** 名称为 Latch。应用图标是炭黑圆角方块、两片象牙色折面与一个橙色接点；`apps/web/public/icon.png`（512px）用于界面、窗口与主屏幕，`apps/web/public/favicon.png`（64px）用于浏览器标签，`build/icon.png` 是高分辨率源图。不要改动图形本身。图标是界面里唯一的暖色元素，不使用它的橙色表达状态。
- **简约、克制。** 蓝白为主：近中性的灰（色相极轻地偏暖，读作中性，不是米色或蓝灰），平涂的地面、更亮一级的纸、近黑的墨色文字；深色是近黑的地面与柔和的白字，黑不是纯黑、白不是纯白。层次靠表面（地面、托盘、纸、浮层）的明度阶梯和墨色深浅，不靠装饰色、渐变、插画或表情。控件按数据的形状选择，一种意思只用一种画法。
- **每种颜色只表达一件事。**

| 颜色 | 只用于 | 不用于 |
| --- | --- | --- |
| 蓝 | 执行动作的主按钮（发送、允许一次、请求本机确认），每个界面最多一个；被勾选的控件（开关的开、复选框、单选、菜单里的勾）；焦点环；跳到别处的链接文字 | 运行中、计数与进度、图标、用户气泡、徽标；列表的选中行（会话行、设置导航、模型服务列表）；视图、筛选与外观的选中；切换按钮的「开」 |
| 琥珀 | 等你处理（待批准、等待本机确认；轮到它时扫过待批准胶囊的暖光，与等你处理的计数增加时的一圈涟漪）；警告（连接中断、原内容未知、含不可见字符、已开启的完全访问会话）；演示标记 | 可按的按钮；普通信息；没被选中的选项与常驻的属性（菜单与列表里的完全访问 Harness、Agent 行的 L3） |
| 红 | 高风险（R2）审批、失败、权限模式漂移、审计记录回滚、设备撤销、差异中的删除、确认对话框里的销毁按钮 | 完全访问、开发版、停止按钮 |
| 绿 | 差异中的新增；成功的结果（本机确认后的对勾、连接检测通过） | 已连接、已就绪、已检测到、已验证这类默认状态；已保存、已启用这类本地操作的结果（值原位更新就是反馈） |
| 墨色 | 运行中的彗星、加载中的转圈与流式光标、未读点、计数与进度、所有静止的图标、列表的选中行（中性的不透明底）、视图与外观的选中、切换按钮的「开」 | — |

- **默认状态安静。** 连接正常、逐项询问、已检测到、已验证的预设这类默认状态不用颜色，也不加标记；顶栏只在偏离默认时出现标记（连接异常、完全访问、演示，以及失败、已取消、已中断、正在取消的会话），运行中与已完成不标；侧栏页脚不写「已连接」。风险色只在风险值真的被选中时出现。
- **内容优先。** 对话列是主角；导航安静，不使用大面积饱和色。只有用户自己的消息有气泡，且是中性的。
- **每个状态只出现一次，并出现在正确的位置。** 会话级状态在顶栏状态标签与侧栏图标；进行中的活动在最新一轮末尾的活的一行；能处理的事（待批准、停止）在附着于输入框的运行条；单步状态在它的过程行。
- **只展示真实能力。** 选择器只列出 Host 目录中真实的 Harness、模型与项目；只有一个选项时以只读标签显示。演示模型必须带琥珀色"演示"标记。不展示虚构的数量、进度或尚未实现的菜单。设备做不到的操作直接隐藏或停用并说明原因，不让用户提交后再失败。
- **默认隐藏内部细节。** 路径中段省略并提供复制；工具 ID 作为次要文字；空参数显示"无参数"。

## 设计令牌

令牌在 workspace 包 `@latch/ui` 的 [tokens.css](../packages/ui/src/tokens.css)，页面的样式入口 [index.css](../apps/web/src/styles/index.css) 第一行导入它。页面的每个颜色、阴影、字号与行高、间距、圆角与时长都只读这些令牌。[styles.test.ts](../apps/web/test/styles.test.ts) 检查：样式表只读已定义的令牌；颜色不写字面值（遮罩与配对二维码的白底除外，二维码在深色下也要深色模块配白底才能扫描）；字号与行高只用角色令牌，字重只有 400、500、600；内外边距与间隔不落在台阶之间；圆角矩形与胶囊各自的形状。

**主题。** 浅色写在 `:root`；深色重写每个含颜色的令牌，同时写在 `@media (prefers-color-scheme: dark)`（仅当根元素没有 `data-theme="light"`）与 `:root[data-theme="dark"]` 下，两份完全相同（[tokens.test.ts](../packages/ui/test/tokens.test.ts)）。只由其他令牌组成的令牌（`--comet`、焦点环）只写一次，随主题变化。所有中性的表面与墨色都近于无彩（OKLCH 彩度在 8 位取整的误差内，不超过 0.005，色相极轻地偏暖），半透明的中性色一律是同一种墨加透明度（浅色 `rgb(29 28 26)`，深色 `rgb(234 233 231)`；深色的凹槽与落影是黑色），所以在任何表面上读起来都一样。主题偏好（跟随系统 / 浅色 / 深色）按设备保存，写入根元素的 `data-theme`；浏览器的 `theme-color` 取它下面那层表面的颜色：768px 起是地面（`--bg-app`），手机上没有地面露出，是纸色；`index.html` 按宽度与配色方案写成四条，选定主题时 `applyTheme` 按同样的宽度改写（[styles.test.ts](../apps/web/test/styles.test.ts) 核对它们与令牌一致）。manifest 不分深浅，`theme_color` 与 `background_color` 都用浅色的地面色；桌面端窗口在首次绘制前的底色与它的错误页也用两种主题的地面色。深色不反转主色：主按钮仍是 `#2461E0` 配白字（5.44:1）。黑不是纯黑、白不是纯白：浅色正文 `#1D1C1A`，深色正文 `#EAE9E7`；浅色的纸是 `#FBFBFA`，只有浮层（输入框、菜单、对话框）是纯白。深色下应用图标的炭黑方块会和纸融在一起，所以沿方块自己的边画一圈 1px 的环（`--brand-ring`，浅色下透明）：图片四周有透明留白，环画在留白内侧方块的边上，不画在图片的方框上，图形本身不变。

**地面。** 地面是平涂的 `--bg-app`，没有渐变；base.css 把它画在根元素与 body 上，外壳、侧栏、图标栏、会话抽屉、设置导航与底部面板都用它。层级靠明度的阶梯：浅色里地面最暗，托盘、纸依次更亮，浮层是纯白；深色里地面最暗，托盘、纸、浮层依次提亮，纸始终比地面亮，层级不倒置（地面对纸约 1.09:1 与 1.08:1）。列表里被选中的行（侧栏的会话行、设置导航、模型服务列表）是不透明的中性色 `--bg-selected-solid`，不用蓝：浅色里比地面深一级，深色里比地面亮一级，对地面 1.19:1 与 1.36:1、对悬停 1.10:1 与 1.21:1，所以在地面与纸上都读得出来，也不会和悬停混淆。所有墨在地面、纸、浮起、托盘与选中行上，以及叠在地面与纸上的悬停与按下上都达到 WCAG 对比度：正文、次级与提示墨色和错误文字 4.5:1，图形墨色 3:1；四种墨的最低值都在选中行上（浅色 12.67、7.26、4.74、3.11，深色 11.20、7.56、4.72、3.50）。`tokens.test.ts` 逐项计算并核对这些最低值，也核对表面与墨色近于无彩、明度从地面起逐层升高；调整任何表面、选中或墨色的值都要通过它。

**层叠层。** tokens.css 第一行声明层的顺序：`tokens, base, ui, app, security`。`@latch/ui` 的 [ui.css](../packages/ui/src/ui.css) 把元素默认样式（[base.css](../packages/ui/src/base.css)：盒模型、文档字体与颜色、焦点环、按键、减少动效）导入 base，把每个原语的样式表（`packages/ui/src/styles/`）导入 ui；页面的 index.css 先导入 tokens.css 再导入 ui.css，然后把自己的每个样式表导入一个层：还没有做成原语的共用部件（`ui.css`：品牌图标、状态点、字母磁贴、进度条、表单字段与值选择 chip）也在 ui，页面自己的布局与界面在 app，登记、设备、权限与本机确认的样式（`auth.css`、`security.css`）在最上面的 security。后面的层总是胜过前面的层，与选择器的权重无关，所以页面可以在 app 层按位置调整原语，安全相关的界面不会被普通样式改写；新增的安全界面放进 security 层。

**安全界面的锁定。** 审批、登记、配对与确认带 `data-secure`，样式放 security 层。

| 线 | `--line`、`--line-subtle`、`--line-strong`、`--kbd-ring` | 一律 1px，颜色是墨加透明度，所以在任何底色上都刚好可见；按键的环是 `--kbd-ring`；`--line` 是静止容器的边，`--line-subtle` 分隔行，`--line-strong` 只作装饰分界与虚线框，不作控件唯一的边 |

| 主色 | `--accent`（`#2461E0`）、`--accent-hover`、`--accent-press`、`--accent-text`、`--accent-text-hover`、`--on-accent`、`--focus`、`--focus-halo` | 深色下主色不变；蓝色文字与链接用 `--accent-text`；深色只有 `--accent` 与 `--accent-text` 两个蓝；没有蓝色的底色调 |
| 磁贴与指示 | `--tile-plate`、`--tile-ring`；`--comet`、`--comet-track`、`--sweep`、`--ripple-ink` | 所有 Harness 与模型磁贴放在同一块托板上（浅色是白色，深色是比纸亮一级的灰），托板上的字母、图形与单色标志都是 `--text-1`；运行中的彗星是 `--comet`（即 `--text-2`），画在 `--comet-track` 的底环上；待批准胶囊上的暖光是 `--sweep`，计数增加时的涟漪是 `--ripple-ink`，都是琥珀，只表示等你处理 |
| 语义色 | `--warn-*`、`--err-*`、`--ok-*`；差异 `--diff-add-bg`、`--diff-add-tok`、`--diff-del-bg`、`--diff-del-tok` | 每组有文字、底、边与实心色；状态胶囊是底色加同色调的 1px 内环；琥珀填充上放墨色（`--on-warn-fill`），不放白字；差异只染行背景，文字保持 `--text-1`，加减号与行数用色调文字 |

| 字体 | `--font-sans`、`--font-mono` | 平台系统字体与中文字体，不加载网络字体；等宽用于代码、参数、工具 ID、设备指纹、核对码与内容哈希 |
| 间距 | `--sp-2` 到 `--sp-64`、`--bleed` | 台阶为 2、4、6、8、12、16、20、24、32、40、48、64；2 与 6 只在控件内部；10、14、18、22、26 不是台阶。可悬停的行可以向两侧外扩 `--bleed`（6px），让文字仍对齐列边 |

| 动效 | `--ease`、`--ease-exit`、`--d-fast`、`--d-base`、`--d-slow`、`--d-fast-exit`、`--d-base-exit`、`--d-slow-exit`、`--d-stagger`、`--d-shimmer`、`--delay-hint` | 一条进入曲线 `cubic-bezier(.2, 0, 0, 1)`、一条退出曲线 `cubic-bezier(.4, 0, 1, 1)`，三档进入时长 120 / 180 / 240ms，离开各快约四分之一（90 / 140 / 180ms）；一个块的内容晚它的盒子 40ms 出现；进行中文字的光带 1.6s 一次；只在停留后才出现的提示（调整宽度的竖线）等 300ms。悬停立即出现、120ms 退去；按下只深一档，不位移、不缩放；弹层与展开 180ms，对话框、底部面板与抽屉 240ms。脚本里要按过渡计时的地方读 `MOTION`（与这些令牌相等，有测试核对）。活的指示有自己的节奏（见「界面原语」的「活的指示」），动画只写在 `prefers-reduced-motion: no-preference` 里。`prefers-reduced-motion` 时动画与过渡都变成瞬时，只保留加载的转圈；活的指示停在能独立表达状态的静帧 |
| 布局 | `--sidebar-width`、`--sidebar-open-width`、`--inspector-width`、`--inspector-open-width`、`--content-width`、`--gutter`、`--topbar-height`、`--shell-inset`、`--touch` | 见「布局」；侧栏与会话信息栏的宽度由页面写在外壳上 |

## 布局

断点定义在 [breakpoints.ts](../apps/web/src/breakpoints.ts)，CSS 媒体查询使用相同数值；侧栏另在 1440px 处变宽。

| 宽度 | 结构 |
| --- | --- |
| ≥1280 桌面 | 侧栏（默认 1440px 起 300px，以下 264px；可调宽与收起，见下）/ 对话列 / 会话信息栏（默认 320px，可调宽；1440px 起默认打开）。侧栏与会话信息栏直接放在地面上，不画分隔线；对话区是嵌在地面上的一张纸：距窗口上、下各 8px，圆角 12，1px `--line`，不带阴影；会话信息栏关闭时纸距窗口右边 8px，打开时纸的右边就是栏的左缘。纸内顶栏 48px，消息列最大 760px 居中。 |
| 1024–1279 | 侧栏默认 248px（同样可调宽与收起）+ 对话列（纸）+ 会话信息栏（同上，默认关闭）。 |
| 768–1023 平板 | 56px 图标栏（地面：应用图标、打开会话列表、新建会话、搜索、有待处理时带琥珀计数的「等你处理」、开发版标记、设置）；对话区是纸；会话列表从左侧滑出，带浮层阴影；会话信息在对话旁仍留得下 440px 时并排（320px，不可调宽），否则换成占据对话位置的页面。 |

抽屉打开时主区域设为 `inert`，焦点限制在抽屉内，Esc 关闭后焦点回到打开按钮。对话框与底部面板同样捕获并恢复焦点。

**设置是整页。** 设置（[SettingsPage.tsx](../apps/web/src/settings/SettingsPage.tsx)）是盖住整个窗口的模态页面，后面的会话保持原状（阅读位置、草稿都不变），本机确认对话框照样开在它上面。768px 起，设置导航放在地面上会话侧栏的位置（1024px 起与侧栏同宽，平板 240px）：48 高的头行与纸的上缘、与它替换的侧栏头行对齐（距窗口 8px），里面是「返回会话」（有审批等待时后面跟琥珀计数，读屏名称也说出数量），下面是 12/16 提示墨色的「设置」与分区行（32 高、8 圆角，选中是中性选中底与 500 字重，图标不变蓝）；分区内容是一张纸，与对话纸一样距窗口 8px、圆角 12、1px `--line`，内容最宽 720px 居中，上下各 48px。分区里的页面（某个 Agent、某个模型服务、「其他设备可用的项目」这类列表，[navigation.tsx](../apps/web/src/settings/navigation.tsx)）在 768px 起原地替换纸上的分区内容，上方一个幽灵的返回链接写着上一级的名称。手机上每一级都是一页：分区列表是根页面（标题栏左侧是「返回会话」，有审批等待时后面跟琥珀计数），分区从右侧推入，分区里的页面再推入在分区之上，各有自己的标题栏与返回按钮（读屏名称说出回到哪一级）；新的一页 240ms 从右侧滑入，上一页同时左移 24%，盖住后从阅读顺序中移除，返回是同一滑动的反向；一级只有一个返回，页面里不再有返回链接。第一次进入分区也是滑入：分区在设置打开时就排在屏幕外。打开设置时整页淡入 120ms，离开时整页以退出曲线 90ms 淡出后会话才回来；设置页没有遮罩，所以两者交叉淡化。换分区、进入分区里的页面或从页面回到分区时内容从下方 4px 淡入（120ms）。减少动效时手机的各级只交叉淡化（120ms），其余只淡入。Esc 在桌面上回到会话，在手机上回到上一级。

**可调宽的侧栏（1024px 起）。** 侧栏的内侧边缘（对话纸的左边框）是调整宽度的把手（`ResizeHandle`，见「界面原语」）：宽度在 220–480px 之间，对话纸始终至少 520px，拖拽中与窗口变窄时都按此收紧（会话信息栏并排时也算上它）；双击恢复默认宽度。拖到 160px 以下就收起，与侧栏头部「收起侧栏」按钮是同一个状态：侧栏的格道滑到 0（180ms），内容保持原宽被裁切、不重新换行，收起后不可聚焦；拖拽越过这个点时（收起，或把收起的侧栏拖出来）格道同样滑过去，而不是跟着指针一下跳到位，之后的宽度才继续跟手。顶栏开头的「展开侧栏」与「新建会话」（有等待处理的审批时还有带琥珀计数的「等你处理」）从 1024px 起一直在顶栏里，随格道一起展开与收起（宽度 180ms，淡入 180ms、淡出 120ms），所以标题跟着纸朝一个方向滑动、不会先跳一下；侧栏打开时它们不可聚焦，也不在无障碍树里。⌘K 先展开侧栏再聚焦搜索；展开或从窗口左缘拖出时回到上次的宽度。收起时侧栏的格道只留窗口的 8px 边距，纸四周的间距不变。键盘：把手可聚焦，←/→ 一步 8px（Shift 32px），Home/End 到最窄与最宽，Enter 收起或展开；用侧栏或顶栏的按钮收起、展开时，焦点移到做相反动作的那个按钮。拖拽中跟手的宽度不做过渡、不选中文字，指针由把手捕获。宽度与收起状态按设备保存在本地偏好里（从不发给 Host），按断点类别（1024–1279 与 ≥1280）分别记住，窄窗口不会继承宽窗口的宽度；读不到或不合规的值按默认处理。平板与手机没有把手。

**会话信息栏。** 打开的会话的信息（[Inspector.tsx](../apps/web/src/components/Inspector.tsx)，放法在 [inspectorLayout.ts](../apps/web/src/inspectorLayout.ts)）是地面上的一列独立的块，从不是盖在对话上的抽屉。顶栏的「会话信息」切换按钮在每个宽度都有（打开时是中性的按下底）。768px 起它是外壳网格的第三列：打开与关闭时格道滑动（180ms），内容保持打开时的宽度被裁切，不重新换行；栏自己有 8px 内边距，所以块离纸、离窗口与彼此都是 8。1024px 起它朝纸的边缘是调整宽度的把手（`ResizeHandle`，「调整会话信息宽度」）：280–480px，双击复原 320，纸始终至少 520px；侧栏打开会让纸不足 520px 时，栏打开期间侧栏自动收起，展开侧栏则关上栏。平板上对话旁仍留得下 440px 时并排，否则和手机一样换成一页：页面从右侧推入（240ms），对话在下面向左移四分之一，返回时反向（180ms）；页头是返回（手机是 44 的图标按钮「返回」，平板是带文字的「返回对话」）、「会话信息」与会话标题，焦点进入页面，返回后回到切换按钮；对话在页面下保持挂载并设为 `inert`，阅读位置不变；切换会话时页面关闭。打开状态按窗口类别（≥1440、1024–1439、平板）分别记住，未选择过时只有 1440px 起默认打开；宽度按侧栏的宽度类别记住；块的收起记在同一份本地偏好里，从不发给 Host。

## 界面原语

原语在 workspace 包 `@latch/ui`（[index.ts](../packages/ui/src/index.ts)），是 React 组件加上它们在 ui 层的样式。页面从这里取按钮、胶囊、开关、分段控件、选值、菜单、对话框、提示与磁贴，不再各自画一份；同一种意思只有一种画法。样式只读令牌。类名以 `ui-` 开头，变体与尺寸写在 `data-variant`、`data-size`、`data-tone` 上，状态直接用 ARIA 属性（`aria-pressed`、`aria-checked`、`aria-expanded`、`aria-disabled`、`aria-busy`、`aria-invalid`），所以样式跟着可访问性状态走，不另设状态类。

**交互约定。** 悬停立即出现、120ms 退去；列表里选中底的切换 120ms（刚点过、还在指针下的那一行也淡入），不做滑动的选中块；按下只深一档，不位移、不缩放。禁用的控件用 `aria-disabled`：整个控件降到 45%，仍能用键盘聚焦，提示框说明原因，点击与表单提交都被拦下（不用原生 `disabled`，否则原因无人能读）。成组的单选控件（分段控件、文字标签页、筛选胶囊、单选列表）整组只有一个 Tab 停靠点，方向键移动并立即选中，Home / End 到首尾，跳过不可选的项。弹层与菜单在顶层（top layer）显示，滚动容器与对话框都裁不到它；打开时焦点进入当前项或第一项，Escape 关闭并把焦点还给触发器，Tab 离开即关闭，点外面或滚动让触发器移动了 1px 以上时关闭（打开时把触发器滚进视野的那次滚动、别处的滚动都不算）。手机宽度（<768px）下，菜单、选值与弹层都换成底部面板。对话框与底部面板里 Tab 只经过真正的 Tab 停靠点（`tabindex="-1"` 的菜单项和单选组里的其余项不在其中），从最后一个回到第一个。

**图标与转圈。** Lucide（ISC）线性图标只用 12、14、16、20、24 五个尺寸，描边随尺寸变化（2.5、2.15、1.9、1.8、1.5），画出来的线宽在 16 及以下约 1.25px，20 与 24 为 1.5px；`ICON_STROKE` 按尺寸取值，用其他尺寸时类型检查失败。静止的图标是 `--icon`，悬停与激活时是 `--text-1`，和文字放在一起时随文字颜色；图标只在表示状态时带色相，失败是红色三角，被选中的完全访问是琥珀色的 `shield-alert`。箭头各有一种意思：向右是进入下一层或展开（展开时转 90°），上下双箭头是原地选值，向下是下拉动作。停止是 10×10、圆角 2 的实心方块，不是描边图形。转圈是一圈淡轨道加一段四分之一弧，旋转加在外层元素上，900ms 一圈；页面上所有转圈按文档时间线对齐相位，并排时不会错开。它只表示加载或等待一个响应（加载行、按钮运行中、取消中），是墨色，在按钮里随文字颜色；减少动效时仍然转。Agent 正在运行用彗星（见「活的指示」）。

**按钮。** 尺寸只有四档：xs 24（提示、托盘行、回合脚部与会话信息里的行内动作）、sm 28（桌面默认：页头、卡片按钮行、行尾）、md 32（对话框与面板的脚部）、lg 44（手机）；带前导图标时起始内边距少 4。变体：主按钮是一个界面里唯一的蓝色，只给执行或创建的动作（发送、允许一次、请求本机确认、添加服务）；「保存」「保存默认值」这类不执行操作的确认用次按钮。次按钮是中性填充，没有环和阴影，放在琥珀或红色调的容器里（容器标 `data-tint`，内联提示自己会标）时改为浮起的白色；幽灵按钮用于工具栏、行尾与「重置」这类安静的动作；链接样式只用于跳到别的页面或位置（`ButtonLink` 是同样画法的 `<a>`）；页面上的危险操作是红字的次按钮；实心红（destroy）只在确认对话框里。运行中的按钮宽度不缩、前导位换成转圈、文案可以换成进行时（「检测中…」），并标 `aria-busy`，不再接受点击；运行中的按钮不算禁用，页面同时禁用它时也不降透明度，主按钮运行中仍是蓝色。快捷键写在提示框里（「允许一次 ⌘⏎」），从不放进按钮。每张卡、每个对话框脚部与面板头部最多两个可见按钮，次在前、主在最后，第三个动作进 ⋯ 菜单。图标按钮是 24、28、32、44 的正方形（图标 12、16、16、20），名称同时是它的提示框；切换按钮的「开」与菜单打开时的触发器（`aria-expanded`）是中性的按下底，不用蓝；输入框里的发送与停止是圆形。图标按钮的面（悬停、按下与「开」的底，以及键盘焦点环）按它自己的尺寸画在中间，所以在任何屏幕上看起来一样大；触屏上它的盒子长到 44×44，工具栏与图标栏里相邻的按钮因此相隔 44，点按区不重叠；页面在密集的行里保留较小的盒子时（回合脚部的复制、列表头的筛选），透明的点按区仍伸到面四周的 44×44。计数放在面的右上角外 4px，垫着一层所在表面的颜色并镂空一圈 2px（`--surface`），字形不被遮住，琥珀的半透明底也不透出字形。`--surface` 默认是纸色；放在别的表面上的容器把它改成自己的颜色：图标栏在地面上，所以是地面色；菜单、弹层、对话框与 Toast 是浮起色，底部面板是地面色，面板里的卡片与单选列表又回到纸色。

**提示框。** 悬停 500ms 后出现，键盘聚焦时立即出现；离开、按下或 Escape 立即消失；从一个提示框移到相邻的控件时立即切换。浮起表面、圆角 6、24 高、12/16 文字，跟随主题，不反色，不接收指针；提示文字同时是触发器的读屏描述（图标按钮的名称已经是同一段文字时除外）。禁用控件的原因（按钮、图标按钮、选值）、开关与分段的说明和开发版标记的整句都用它，不用浏览器原生的 `title`。触屏上不出现。

**胶囊、小徽标、计数、状态点与按键。** 胶囊表示状态、视图或身份，圆角矩形表示动作、值与容器，所以状态胶囊和按钮一眼可分。20 高的状态胶囊是卡片、行或会话的状态（待批准、失败、已取消）；16 高的小徽标是跟在名字后面的属性（默认、本机、内置、离线、开发版、演示）。中性是填充，琥珀、红、绿加同色调的 1px 内环；没有蓝色胶囊，没有前导点。计数是 16 高的胶囊、等宽数字、超过 99 写 99+：被动计数中性，手机上的未读是墨色实心，等你处理的是琥珀；页面亲眼看到计数变了一时数字滚一格，等你处理的计数增加时另有一圈涟漪（见「活的指示」）。状态点桌面 6、手机 8，琥珀与红点总要和文字或图形一起出现，叠在磁贴上时用所在表面的颜色（`--surface`）镂空一圈。按键（kbd）只出现在提示框、菜单项尾部、搜索框与审批卡聚焦时的提示行里。

**选值（ValuePicker）。** 在原地从一组互斥的值里选一个，只显示当前值：幽灵、28 高（会话信息里是 24、箭头只在悬停或聚焦时出现）、值 13/18 常规字重、末尾上下双箭头，前导、值与箭头彼此相隔 6。值总是紧跟前导（没有前导时从内边距开始），所以会话信息里外扩的一列值与列的边缘对齐；手机设置面板里的值离箭头 6，同一张卡的值右缘对齐。悬停与菜单打开时变深，值换成正文墨色；只有一个可能值时是不可点的文字；没有选择时写「选择模型」这类说法，用提示墨色，不用警示色。读屏名称是「标签：值」。菜单打开时焦点在当前值上，Enter 选中，可以按首字母跳转；不可选的值也能聚焦，下面一行带禁止图标的原因保持原色并被读出。选中即生效，不弹提示；值改变时淡入 120ms。调高权限这类要验证的改动返回一个 Promise，等待期间前导位是转圈、值换成「等待验证…」，取消验证时值不变。箭头不动：设置行尾部的选值向左伸展；输入框工具栏里左对齐的权限菜单（`reserve`）预留值与「等待验证…」中较宽的宽度，多出的宽度留在值和箭头之间。只有可能等待验证的选值才预留，模型、项目这类选值、会话信息的 24 高选值与手机行都不预留。设置行尾部的选值按 `--bleed` 向右外扩 6px，使箭头与同卡导航行的箭头对齐。长列表可以带搜索行。禁用的选值降到 45%，原因在提示框里。手机上是底部面板里的单选列表，打开时焦点在当前值上（单选组唯一的 Tab 停靠点），不论它排在第几；`variant="row"` 是手机设置面板里的一行（标签、值、箭头），同一张卡里相邻的行之间有一条从文字边开始的 `--line-subtle` 细线，最后一行下面没有。

**权限菜单（PermissionMenu）。** 有序的权限等级只用这一个菜单，不用一排分段：整层 320 宽，头部写作用对象，四个两行项从低到高，每项一句后果，默认项带中性小徽标「默认」，越级的项不可选并写出原因，脚部是一行导航或带锁的说明。菜单里的完全访问不带琥珀；只有它被选中后，触发器前才出现琥珀色 `shield-alert`。调低立即生效，调高走上面的验证流程。等级的文案由页面传入，原语只负责顺序、画法与交互。手机上的单选面板用同一份文案：头部写在列表上方并作为单选组的名称，「默认」徽标跟在标题后面，脚部说明与单选和标题两列对齐。

**菜单与弹层。** 浮起表面、圆角 12、内边距 4、浮层阴影，最小宽 220（给出的宽度都是整层的外宽，内边距在内；可搜索的选值 360），距触发器 6，设置行与会话信息里右缘对齐触发器，输入框里左缘对齐。打开时从触发器一侧移入 4px 并淡入（180ms），关闭只淡出（120ms）。菜单项 32 高（带说明 48），圆角 8，前导槽 16：选值菜单里当前项是蓝色对勾、标题换成 500 字重，动作菜单里是图标；没有任何项带图标的动作菜单（例如审批卡的 ⋯）不留前导槽，文字从菜单的内边距开始；尾部只放一样（元信息、小徽标或按键）；两行项（带说明或不可选的原因）把前导与尾部放在标题那一行，不放在两行中间；原因行在上一行下 4、禁止图标与文字相隔 6；高亮瞬时变化。菜单项的图标静止时是图标色，悬停、键盘高亮与按下时换成正文墨色。危险项（删除）排在最后，前面一条分隔线，文字与它的图标都是红色。菜单的读屏名称是它的标签加头部写的作用对象（「权限：在这台电脑上发起的会话」，头部只重复标签时不再加），头部的元信息是它的读屏描述。分隔线下的脚部行与菜单项用同一网格，文字从标题那一列开始：导航行（「电脑与权限上限…」）是正文墨色 13/18，前导槽空着，末尾向右箭头；说明行（「调高要在这台电脑上验证身份」）把锁放在前导槽中间，文字 12/16 提示墨色。`Popover` 是同样表面的内容弹层，焦点进入它的第一个控件。

**输入。** 文本字段放在凹槽里，带 1px 环；聚焦时（不只是键盘）升到浮起表面并换成蓝环与外晕。标签在上（12/16·500），提示在下（12/18 提示墨色），出错时环变红、下面一行红字写原因与改法，并作为读屏描述。桌面 32 高；手机 44 高、16px 字，iOS 聚焦时不缩放。页面内的搜索框是同样的凹槽加前导放大镜（与文字相隔 6，控件内图标与文字的间距），有内容时尾部是 24 的清除按钮（触屏上四周有 44×44 的透明点按区），Escape 先清空。地面上一列行里的搜索（侧栏）用 `variant="ghost"`：与那一列的行同样 36 高、16 的放大镜距起点与文字各 8，静止时没有凹槽，悬停是悬停底，只有聚焦时升到浮起表面并带蓝环。

**开关与选择。** 开关只给能立即开关的行：桌面轨道 32×18、滑块 14（触屏 44×26、22），关是实心 `--track-off` 加一圈 `--icon` 色的 1px 环（对纸达到 3:1），开是蓝色；滑块是浮起的白色，180ms 滑到位，按住时向前进方向拉宽 4px；Space 切换；键盘焦点环画在轨道外 2px，跟着胶囊的形状，不画在更大的点按盒子上。`SwitchRow` 整行是开关的标签，点标题也能切换，整行不响应悬停；被策略锁住时开关关闭并降到 45%，前面一把锁，说明换成原因。分段控件只用于 2–3 个对等的视图或模式（类型只允许 2 或 3 项）：没有环的凹槽、等宽段、选中段是浮起的白色滑块，平移到位；它是一个单选组，段的说明（例如为什么不可选）在提示框里。文字标签页与筛选胶囊是没有轨道的胶囊，选中是中性填充（标签页的填充平移到位），从不下划线、不用蓝；标签页是 tablist，筛选是一组 `aria-pressed` 的切换按钮。复选框与单选框是 16px 的原生输入：未选中是 `--icon` 色的 1px 环，选中是蓝色（实心加白勾，或 5px 的蓝环）。单选列表放在卡片里，每行 48（手机 56），前导单选、标题与一句后果，选中项标题 500，单选与标题在同一行，下面有说明或原因时也不下移；不可选的行降低单选与标题，原因一行保持原色。

**选中的三种画法。** 列表里的对象（会话行、设置导航、模型服务列表）是中性的不透明底 `--bg-selected-solid`，标题换成正文墨色；被勾选的控件（菜单对勾、单选、复选、开关的开）是蓝色；视图、筛选与外观（分段、标签页、筛选胶囊）是中性的滑块或填充。蓝色从不画在选中行上。

**对话框与底部面板。** 对话框是原生模态 `<dialog>`：480（确认）、560（表单）、720（双栏），浮起表面、圆角 16、模态阴影与遮罩；头部 56（标题 15/22·600、可选副标题、关闭）、正文内边距 24、脚部 64（左侧说明，右侧最多两个 md 按钮，次在前、主在最后），头与脚各用一条 `--line-subtle` 分开；没有头尾的确认四边留 24。打开时聚焦第一个输入（没有输入时是正文的第一个控件），Tab 在对话框里循环，Escape 与点遮罩关闭，关闭后焦点回到打开它的控件；从 98% 放大并淡入，240ms。底部面板（手机）是地面色、上圆角 16，抓手、52 高的头部（左「取消」是常规字重的幽灵按钮、中间标题、右侧动作：执行操作的主按钮，或只关闭面板的次按钮「完成」，热区都是 44；只用来查看的面板（弹层在手机上的样子，例如计划）没有「取消」，只有右侧的「完成」；「取消」的文字与动作的右缘都落在下面卡片的 16 那条线上），从底部滑入；内容高时先停在窗口的 65%，向上拖到 92%，向下拖过三分之一或快速下滑则关闭。改动即时生效的面板不放「确定」。

**调整宽度（ResizeHandle）。** 侧边列（侧栏与会话信息栏）的边缘：跨在边缘上的 6px 透明命中区，光标是 `col-resize`；悬停 300ms 后（避免划过时闪烁）、拖拽中立即、键盘聚焦时随焦点环一起，在中间画一条 2px 的 `--line-strong` 竖线，不用蓝色，也不占布局。它是竖向的 `role="separator"`，读屏名称写明作用（「调整侧栏宽度」），`aria-valuenow`、`aria-valuemin`、`aria-valuemax` 是像素宽度，收起时 `aria-valuetext` 为「已收起」。它只报告宽度：拖拽中报告指针下的原始宽度、松开时再报告一次（由页面收紧、吸附收起并保存），键盘一步 8px（Shift 32px）、Home/End 到两端，Enter 切换收起，双击复原；拖拽时捕获指针，并在根元素上标 `data-resizing`，整页显示调整光标、不选中文字。

**提示与 Toast。** 内联提示（也用作消息区顶部的横幅；横幅在页面看着条件变化时像折叠块一样展开与收起，收起时保留原来的文字，加载、重连或切换会话后直接在位）是色调底加同色调 1px 边：警告配三角，错误配圆形叉号，中性配信息图标，中性的底是托盘；图标与标题用色调文字，说明是次级墨色 12/18；最多一个 xs 动作（琥珀与红色调里是浮起的白色次按钮），可选一个关闭按钮。先写保留了什么，再写原因，最后给动作。错误提示是 `alert`，其余是 `status`。本地操作成功（保存、启用、获取到模型）用中性提示或只让值原位更新，不用绿色。Toast 是 36 高的浮层胶囊，前面一个色调图形，用于发生在别处的事（「已由「设备名」处理」）和失败；置顶、归档、删除这类在本页做的操作成功时不弹 Toast，列表行的移动或收起就是反馈。

**空、加载与错误。** 空状态是一句短名词（「还没有会话」）、一行说明和最多一个 xs 按钮，左对齐，不放插画。加载在对象旁边放 14 的转圈和一行提示墨色的文字；页面中央的连接状态用 20 的转圈；列表的骨架只做呼吸（不透明度 .55 到 1，1.6s），不做扫光，占的盒子与内容相同。界面出错的卡片是一张 480 的纸：红色三角、标题、一行说明会话和草稿都在执行端，最多两个按钮。

**磁贴。** Harness 与模型的方形磁贴：16、20、24、32、40、56，圆角按 round(边长 × 0.225)，所有磁贴同一块托板（`--tile-plate`：浅色是白色，深色是比纸亮一级的灰）加 1px `--tile-ring`。磁贴放品牌自己的标志文件（`mark`），只有没有图标的东西才放调用方给的图形（`icon`）；类型上二者必有其一，磁贴从不画字母。标志居中占 62.5%，文件自己带了很宽的留白时（`margin`）铺满托板。彩色标志原样放在托板上（`<img>`），品牌另有深色版文件时（`dark`）按页面的主题换用；单色标志按品牌的单色复制方式，以文件为 CSS 遮罩、填成 `--text-1`，所以浅色里是近黑、深色里是柔和的白，图形本身不改；品牌自己的应用图标（`tile`）自带底色与外形，原样显示，不加托板与细环，也不按磁贴的圆角裁切。标志文件从不作为标记内联进页面。托板上的图形也是 `--text-1`；图形是 Lucide 图标，磁贴按它画出来的大小定线宽，画出的线在 20px 以下是 1.25px、20px 起是 1.5px，与图标尺度一致，小磁贴里的图形不会糊成一团；16 的位置上（选择器的按钮、顶栏与回复的来源行）没有图标的东西只画图形本身（`plain`），因为托板上 10px 的图形认不出来。`plain` 只有图形没有磁贴，图形用它所在表面上更安静的 `--text-2`（单色标志仍是 `--text-1`）。就绪度画在磁贴上，就绪不加任何标记：不可用（例如找不到命令）灰度并降到 40%；启动或检测中灰度、降到 70%，外面 2px 处一圈 2px 的进度环（有进度时从 12 点起顺时针按比例画弧，否则一段弧 1.4s 绕一圈，减少动效时和转圈一样仍然转）；失败在右上角放一个 8px 的红点并镂空一圈表面色。就绪度也要在文字里写出。

**活的指示。** 只有活的状态会动（运行中、等你处理、新到），静止的事实（时间、已完成、已取消、失败）从不动；每行最多一个动的东西，动的元素不超过 52×20，只动 transform、opacity 或小元素的背景位置，没有闪烁、弹跳与变色。所有动画只写在 `prefers-reduced-motion: no-preference` 里（[live.css](../packages/ui/src/styles/live.css)），默认的静帧就是减少动效时的样子，必须能独立表达状态。

- **彗星（`Comet`）。** 运行中：12（侧栏与「回到最新」）、14（过程行 16 的图标位）、16（手机列表）。计划的步骤不带彗星：运行中的工具已在它的行上转动，一个运行在桌面上最多同时转三四颗。一圈 `--comet-track` 底环（描边 1.5 / 1.6 / 1.75px）上一段 160° 渐亮的尾巴与圆头，`rotate(1turn)` 2.4s 线性；所有彗星同一相位：挂载时把 `animation-delay` 设为 −(文档时间 mod 2400ms)，每次它的旋转重新开始时（例如从 `display: none` 恢复，或从减少动效切回）再按旋转真正的开始时间重设一次。静帧是头停在 12 点、尾巴沿左侧淡出，仍读作运行中。`held` 的彗星不再运行：停在挂载时同一相位所在的角度，没有动画，也不参加接力，是运行结束时离开的那一颗。
- **接力。** 一个窗口里可见的活项（彗星与等你处理的胶囊）按阅读顺序编号：从上到下，竖直中心相差不到 8px 的算同一行、从左到右（不同大小的彗星并排时顶边不齐，按中心不会把大的排在前面），各得 `--i` 与 `--cyc`，周期 max(3, n) × 1.6s，只有前 8 个参与；轮到 `--i` 时彗星在常转之上多转一圈（1.6s，`cubic-bezier(.37, 0, .63, 1)`，转完回到同一相位），胶囊则扫过一次暖光，其余时间休息，所以一个周期里只有一处在做额外的事。3–8 格各有预置关键帧，由 `data-relay` 选择。可见指在窗口里（IntersectionObserver），且它与容器都不是不透明度 0：鼠标停在会话行上、状态槽让位给 ⋯ 时，那一行不再占一格，周期里没有看不见的一轮。每个格的边界重新量一次顺序与可见性（列表重排时行不重新挂载）；编号变了就在这个边界上换，所有接力动画一起重新开始，这时每一圈与每次扫光都已停下，不会被截断；只有已编号的项都已卸载时才立即编号。
- **等你处理（`WaitingPill`）。** 琥珀状态胶囊（「待批准」）；轮到它时文字后面一道 `--sweep` 暖光从左扫到右（宽 300% 的渐变，背景位置 100% → 0%，1.5s `cubic-bezier(.45, 0, .2, 1)`），其余时间静止。
- **一次性动效。** 计数变了一时数字栈滚一格（+1 上滚、−1 下滚，240ms）；等你处理的计数增加时一圈 1px `--ripple-ink` 涟漪（不随缩放加粗的 SVG 矩形，1 → 1.8 倍，两位数为 1.3 × 1.8，1.4s，延迟 .4s）；只在有东西等待时才出现的计数（侧栏的「待批准」行、图标栏的待批准按钮）由所在的组件用 `useLivePrevious` 记住它出现前的值并传给 `Count` 的 `from`，所以第一项到达（0 → 1）也有涟漪，但不滚数字，因为旧值不在屏幕上；状态槽从运行中变成未读时彗星收拢（240ms）、未读点落下（264ms，晚 48ms），从未读变成时间时点沉下（144ms）、时间淡入（192ms，晚 96ms）。它们只为页面亲眼看到的变化播放一次：页面经 `LiveChanges` 给出重新同步的纪元，在上一次渲染之后换了纪元的变化直接显示新值；没有纪元或减少动效时也直接显示。外壳（侧栏、图标栏）的纪元是 Host 状态重新同步的次数（首次加载、重连后的快照同步、页面重新可见，见 [STREAMING.md](./STREAMING.md)「客户端：事件流、凭据与版本门禁」）；对话区与会话详情的纪元另加打开的会话，切换会话时那里不播。会话列表跨会话存在，所以打开一个未读的会话时，它那一行的点沉下、时间淡入。过程行的状态变化（下一条）与页面里的其他一次性过渡用同一个 `useLiveChange`。
- **过程行的状态（`StatusGlyph`、`StatusWords`）。** 工具的过程行与计划步骤共用：图形格里运行中是彗星，其余是这一行的图标（计划步骤按状态是空心圆、带点的圆与对勾，都是静止的）；`state` 写明图形表示什么。页面看着它变化时，旧图形（运行中的是停住的彗星）120ms 沿退出曲线淡出，新图形从 80% 长到原大并淡入（120ms，进入曲线），在同一格里交叉淡化；状态文字（执行中 → 完成）上移 4px 淡入（120ms）。失败只换图标与文字，不抖动。首次渲染、重新同步、切换会话与减少动效时直接显示。
- **状态槽（`StatusSlot`）。** 列表行行尾的一格，右对齐、至少 24 宽，只显示一样：彗星、等你处理的胶囊、失败（12 的红色三角加文字，`--err-text`，文字由页面给出，默认「失败」）、未读点、时间，或什么都没有；尺寸跟彗星，桌面的侧栏 12，手机的列表 16（未读点在手机上也是 8）。收拢时彗星朝未读点的圆心（行尾向内半个点宽）缩小，像圆环收成一点，而不是在旁边跳一下。它对读屏隐藏，行自己用一句隐藏文字说出状态与时间。

**展开、替换与离开（[motion.tsx](../packages/ui/src/motion.tsx)）。** 动效只用来说明一个变化：高度只经网格行变化，其余只动不透明度与位移，所以展开的东西上方什么都不移动；减少动效时都立即完成。`Collapse` 是展开块的身体：打开时网格行从 0fr 到 1fr（180ms，进入曲线），内容晚 40ms 淡入（120ms）；关闭用 140ms 的退出曲线，内容先淡出；打开并停稳后不再裁切（焦点环、外扩的行不被切掉）。关闭时身体留在文档里，是 `hidden="until-found"`：不在 Tab 顺序与无障碍树里，但浏览器的页内查找能找到它，并经 `onReveal` 请主人打开；关闭过程中是 `inert`。`lazy` 的身体第一次打开时才渲染，之后保留（工具的输出这类重内容）。首次渲染直接显示当时的状态。`Swap` 在值变化时替换内容：图形从 80% 长到原大并淡入（复制图标变成对勾，`IconButton` 的 `swap`），文字原地淡入（`effect="fade"`，例如「正在思考」变成「思考了 6 秒」），首次渲染不播。`usePresence` 让离开的东西在退出动画期间留在页面上并标为离开（「回到最新」淡出、会话信息页滑走）。`Shimmer` 是进行中的文字：一道窄光每 1.6s 从左到右扫过文字，只动文字背后渐变的位置；减少动效时是静止的提示墨色。

**开发版与演示标记。** `DevMark` 是中性小徽标「开发版」，整句说明（「开发模式：Host 代码可被本机修改」）是它悬停时的提示与读屏名称，从不用红；`DemoMark` 是琥珀色小徽标「演示模型」（窄处写「演示」）。

**原语与页面。** 页面里的按钮、图标按钮、开关、分段控件、筛选胶囊、胶囊与小徽标、计数、内联提示、侧栏搜索框、发送方式的单选列表、加载行、Toast、开发版标记、Harness 与模型服务的磁贴、侧栏的调整宽度把手，以及运行中的彗星、等你处理的胶囊、会话行的状态槽、过程行的状态图形和文字、展开块、替换与进行中的文字都来自原语。会话行、选值 chip、菜单与对话框的外壳（`overlays.tsx`）与表单字段还在页面里，随各自界面的改版换成原语。

[packages/ui/test/gallery](../packages/ui/test/gallery) 是只供测试的原语总览页：每个原语的每种状态都在一页上（悬停、按下与键盘焦点由截图时强制），不进入 `dist/web`。一次性动效在总览页挂载后一帧重放一次，另有几格把暖光、涟漪、数字滚动、收拢与过程行的交叉淡化定格在中途，便于评审；「动效」一节是收起与展开的块（可以点开）、两种替换与进行中的文字；活的指示一节里只有「接力」那几行参加接力，其余单个样本都不参加，所以那几行自己轮流；总览页自己的排版只作用于它自己的元素，原语的标题与字号保持原样；就地画出的对话框、弹层与底部面板在手机宽度下收进卡片，完整可见；截图时视口长到整页高度，手机与平板的截图因此带着触屏尺寸（44 的点按盒子、44×26 的开关）。

**Harness 与模型服务的图标。** 每个 Harness 与模型服务都显示它真实的品牌图标，放在磁贴上（`BrandTile`，[brands.ts](../apps/web/src/brands.ts)）：先用品牌自己的文件（项目仓库里的或官网上不需登录即可取得的），没有时用开源图标集 LobeHub Icons（MIT）在固定提交中的文件，品牌标志是彩色的就用彩色版，否则用单色版。文件原样复制到 `apps/web/src/assets/brands/`，不作为 npm 依赖；以 `?no-inline` 导入，构建产物里是同样字节的文件，不被改写成内联数据；只经 `<img>` 或 CSS（遮罩）使用，从不内联成标记。来源（仓库与路径及提交，或网址与日期）、许可证、图标集的 MIT 声明与「标志属于各自的所有者，只用于标明服务或工具」写在仓库根的 `NOTICE`。目录里的会话与服务不带预设标识，所以按 Host 由预设派生的标识（`codex`、`codex-2`……）认出它的预设；设置里有预设标识时直接用它。没有图标的才用中性图形：自定义的 Agent 命令是 `bot`，插件是 `puzzle`，自定义的 OpenAI 兼容服务是 `plug`，演示模型是 `flask-conical`；Latch 内置的 Harness 用应用图标原样显示。[brands.test.ts](../apps/web/test/brands.test.ts) 检查每个 Harness 预设与模型服务预设都有图标，演示、插件与自定义各有图形，图标目录里正好是映射用到的文件，且每个 SVG 不含脚本、外来内容、事件属性、嵌入图片、样式表或指向文件外的引用。图标出现在侧栏的会话行、顶栏与每轮回复的来源行、选择器，以及设置里的模型服务（预设、列表与表单）与 Agent（预设、列表与表单）。

**侧栏。** 从上到下：头行（48：20 的应用图标与「Latch」，右侧是幽灵图标按钮「新建会话」——新会话页打开时是切换按钮的「开」——与「收起侧栏」；抽屉里换成「关闭会话列表」）、搜索（32，⌘K 聚焦，按标题即时过滤）、只在有审批等待时出现的「等你处理」行（`inbox` 图标、正文墨色 500 的文字与琥珀计数；点它打开最早一项等待的审批所在的会话并定位到它）、会话列表与页脚（52：`laptop` 图标、运行 Host 的这台电脑的名称、开发版标记、只在连接中断或离线时出现的琥珀小徽标，以及设置）。本设备的名称在「设置 › 设备」里，设备也只从设置进入。搜索与「等你处理」都是幽灵行：16 的图标位距起点与文字各 8，静止时没有底色，悬停是悬停底、按下深一级，所以这一列里唯一静止的底色就是打开的会话那一行的中性选中底；琥珀只在计数上。搜索聚焦、有内容或筛选不是「全部」时，它下面展开一行筛选胶囊：全部、对话、Agent，有已归档会话或正在看它们时还有已归档（展开与收起是高度加淡入淡出）。在搜索里按下、直到这次点击落下之前，搜索失去焦点而焦点无处可去也不收起胶囊（Safari 与 iOS 点按钮不会让它获得焦点：用鼠标时搜索在按下的一刻失去焦点，触屏时在手指抬起之后、点击之前），其余时候焦点离开搜索或在别处按下就收起；列表末尾另有一行安静的「已归档」与数量，有已归档会话时出现，点它切到已归档。页脚的连接徽标也是同步最新状态的按钮，点按范围在 16 高的徽标四周各多出 4px；平板图标栏不画连接，连接出问题时由顶栏的琥珀胶囊写出。会话先按置顶分组，其余按项目分组：会话的工作目录落在哪个保存的项目里（取最深的一个）就归哪一组，没有记录目录的会话属于启动目录，都不属于的归「其他目录」；启动目录这一组用它的文件夹名，其余用项目名。组按其中最近更新的会话排序，组内最新的在前；Host 不提供项目列表时按工作目录分组。组头 28（12/16·500 提示墨色），悬停或聚焦时右端出现 24 的「+」，在这个项目里新建会话（项目不可用，或设备不能发起会话时没有）。每行一行高（36px，触屏 44px）：20 的 Harness 磁贴、标题与状态槽；状态槽按优先级只显示一样：等你处理的「待批准」胶囊、失败（红色三角加「失败」；权限模式变化后停下的会话同样是红色，写「权限已变化」）、运行中的彗星（打开的会话不显示，它的运行条已经说了）、未读点，其余是相对时间（已取消与已中断的会话也显示时间，打开时由顶栏的状态胶囊说出）；手机的会话列表里状态槽是 16；悬停、键盘聚焦或菜单打开时状态槽 120ms 淡出，换成 ⋯ 菜单（鼠标点开会话不藏起状态），提供重命名、置顶、归档、导出 Markdown、删除（需确认，运行中不可删除）。标题太长时最后 16px 渐隐，不用省略号；菜单打开时这一行保持悬停底，指针移进菜单后仍看得出菜单属于哪一行。行里的 Harness 磁贴说的是这个会话，不画 Harness 现在是否可用（每轮回复的来源行也是）。行标题默认用次级墨色，比阅读列安静；选中的行是中性的不透明选中底（120ms 切换）与 500 字重；未读的行把标题换成正文墨色并在状态槽显示墨色圆点，字重不变。未读按设备记录。列表随 Host 变化时，移动的行与组从原位置滑到新位置（180ms），新到的行淡入，离开的行（归档、删除、移到别的组）高度收起并淡出（140ms）；换筛选或搜索时直接重画，减少动效时都不动。

**新会话。** 居中的问候与输入框。输入框工具栏依次是 Harness、模型（仅当该 Harness 使用 Host 模型）、项目、模式（只显示 Harness 支持的模式）；手机上合并为一个"运行设置"面板。选择按设备记忆，并按 Host 当前目录修正。缺少可用模型或 Harness 时显示指向设置的引导卡片。演示模式下显示带"演示"标记的示例卡片。

**会话。** 顶栏（纸内 48）左侧是标题：一个幽灵按钮，悬停时露出向下箭头，打开会话菜单（重命名、置顶、归档、导出 Markdown、删除）；接着是会话在哪里运行（16 的 Harness 磁贴与提示墨色的「Harness · 项目文件夹名」）和不是默认时的状态胶囊（失败为红色，已取消、已中断、正在取消为中性；运行中与已完成不标）。右侧依次是连接胶囊（只在连接不正常时出现：琥珀色写出状态与「· 重试」并带刷新图标，没有圆点，手机上同样写出文字；点击同步）、完全访问会话的琥珀胶囊（`shield-alert` 加「完全访问」）、演示标记（"演示模型"，手机为"演示"）、「会话信息」开关（每个宽度都有，打开时是中性的按下底，不用蓝色）与更多菜单（会话的操作与「同步最新状态」；新会话页里只有后者）。手机上标题是文字，会话的操作都在更多菜单里。连接中断或离线时，消息区顶部有一行琥珀色提示：三角图标与琥珀色标题（「连接已中断，正在重连…」或「当前设备已离线」），说明为次级墨色，右侧「重试」。

**对话与回合。** 对话按回合排列（[Transcript.tsx](../apps/web/src/components/Transcript.tsx)，推导在 [conversation.ts](../apps/web/src/conversation.ts)）：一个回合是用户的一条消息和回答它的一切；回合脚部属于回合，下一条消息在它之后 48（手机 32），所以一段回复的最后一行与下一条消息相距 84；消息与回复之间 32（手机同样 32，给下面那行留出位置）。对话列的第一行在顶栏下 16，避开 16px 的渐隐。只有用户消息有气泡：右侧的中性气泡，下面 4 处是 20 高的一行，写它的时间与「复制消息」，桌面上悬停或聚焦时淡入（120ms），触屏上最新一条常显、点按气泡显示其他的，显示它们不移动任何东西。页面亲眼看着到达的消息才有到达的动效：用户的气泡上移 6px 淡入（180ms），回复的来源行与第一块淡入（120ms），流式文字不做逐字动画；加载、重连与切换会话后不播放，减少动效时直接出现。切换会话时对话区只做 120ms 的透明度淡入，阅读位置照常恢复。回复整宽，顶部一次来源行：16 的 Harness 磁贴、Harness 名称与 Host 记录的模型（悬停写出模型服务；运行中的回合在第一步记下模型之前用会话的模型，所以这一行从第一帧起就不变）；然后是正文、过程行、证据与说明，最后是回合脚部。第一条消息前、隔天或相隔一小时以上的用户消息前有一行居中的提示墨色时间分隔（「今天 14:32」「昨天 09:15」、一周内写星期、更早写日期，同一天的第二个分隔只写时刻），它只开在用户消息前，从不切开一个回合。消息时间写「14:32」、「昨天 14:32」、「10月3日 14:32」，往年写「2025年10月3日 14:32」。所有时间都是 Host 记录的，悬停写出完整日期与时刻，跨过午夜自动换说法；缺少时间（旧 Host、旧记录）的部分不显示，不估算。每个数都带单位：token 写「12.4k tokens」，时长写秒、分、小时，计数写出数的是什么（「2 个文件」）。

**过程行。** 思考与每次工具调用都是一行安静的过程（28 高，手机 32）：16 的图形位（运行中是彗星）、按工具类型的动词（运行中是进行时：「正在读取」→「读取」）加对象（路径与命令是等宽字，搜索词是普通字；读不出对象时只写工具自己的标题）、工具 ID、用时（运行中每秒走），不是正常完成时再写状态（待批准、失败、已取消）。没有底色与竖线，悬停是悬停底并向两侧外扩 6px，箭头只在悬停或聚焦时出现（触屏常显）；有指针时工具行收起的箭头不占位，用时与状态落在列的右缘，悬停或聚焦时它们左移 18px（120ms）给淡入的箭头让位，行里的文字预留了这段距离，不会被盖住。连续的工具行聚成一组，正文与说明把组断开。思考行在推理流出时写「正在思考」（文字上一道光带扫过）与秒数，正文开始后换成「思考了 6 秒」（120ms 交叉淡化），推理只有模型真实报告时出现；它流出时自动展开、正文开始时收起，用户自己的展开与收起优先。展开思考或工具时，盒子在固定的行头下向下长出（180ms），内容晚 40ms 淡入；收起时内容先淡出。工具展开（或带输出的失败，会自己展开）后成为一张卡，落在列的两缘，与差异、提示和审批卡对齐：托盘（凹槽底、细线、圆角 12、内边距 4）在行的后面淡入，32 高的头部在托盘里离边 8；托盘里是一张纸，依次放参数、变更与输出（输出最多 240 高，在自己的框里滚动，运行中跟随最新的行，可复制）。工具的文件变更是证据：卡收起时显示在它的行下面，托盘里文件名、目录、原内容标记与增删行数，点开是差异；卡展开时差异成为纸里的「变更」一节，行下面的那份同时收起，所以托盘里从不再套一层托盘。差异较长时中段折叠为「展开其余 N 行」；手机只留一列行号，删除的行写它原来的行号。工具卡的内容在第一次展开时才渲染；收起的内容（思考、工具、折叠的过程、会话信息的块）仍留在文档里（`hidden="until-found"`），浏览器的页内查找能找到并把它展开。待审批时卡片就是审批卡（见「审批」）：卡片头部不写动词与对象，而是工具自己的标题，升为卡片标题（14/20·600），右侧的状态换成这次请求的状态胶囊。页面看着状态变化时，彗星与工具图标交叉淡化、状态文字上移淡入（过程行的状态原语，见「活的指示」）。

**折叠的过程。** 回合正常完成、最后是一段正文时，答案之前的过程收成一行「已处理 · 思考 6 秒 · 读取 4 个文件 · 运行 2 条命令 · 用时 2.4 秒」（只数折叠进去的行，最多列三类，其余写「等 N 项」），点开按原样展开。必须留在视野里的东西不折叠：有文件变更的工具、失败或等待中的工具、说明，以及紧接在它们或答案之前引出下文的那段正文。运行中、失败或停止的回合不折叠；页面亲眼看着回合结束时，过程先完整显示，下一帧再收起，所以看得到它收起；重新打开的会话直接显示收起的样子。

**回合脚部。** 每个回合最后一行（28 高，提示墨色、等宽数字，每个事实各占一段，段之间用同样间距的「·」）：没有正常完成时先按这一轮实际留下的写结果（红色「失败」；有正文时「已停止 · 保留了部分回复」，没有时只写「已停止」；有内容时「回复中断 · 保留了部分内容」，没有时只写「回复中断」），然后是回复发出（这一轮结束）的时间，悬停写「10月25日 14:31:05 开始 · 14:32:17 完成 · 用时 1 分 12 秒（不含等待批准 20 秒）」（用时是 Host 记录的工作时间，脚部不另列用时），再是「输入 12.4k tokens」「输出 850 tokens」（各步合计，悬停写出精确数与缓存、推理部分），Agent 只报告整个会话的上下文时，最新一轮写「上下文 74k tokens」；之后是「复制回复」（这一轮所有正文，空行分隔）。桌面上脚部静止时隐藏，指针或焦点在这一轮里时淡入；页面看着结束的那一轮再停留 3 秒；触屏上最新一轮常显，点按回复显示其他轮的。运行中它是活的一行：阶段（正在停止、等你批准（琥珀）、运行中的工具用它那一行的进行时（「正在运行 pnpm test」，读不出类型时写「正在执行」加工具标题）、正在回复、正在思考、正在启动 Agent（10 秒后写启动较慢）、等待模型，文字上有光带；运行中的工具行或思考行已经说了在做什么时，这一行只留事实）、按 Host 时钟走的已运行时间（等你批准时停住）、已完成步骤的输出量与「N 分钟没有新输出」。阶段至少停留 1.2 秒，快速切换不闪；停止与等你批准立即显示。回合结束时，活的一行在原地交叉淡化成结果（120ms），不移动。最新一轮失败或停止、且这台设备现在可以发送时，脚部有「重新发送」：把同一条消息作为新的一轮再发一次（新的请求 ID，不重放工具，输入框里的草稿不动）；上一次可能改动过东西（修改文件、运行命令、结果未知的操作）时，先在脚部下面展开一行说明会再次执行什么（完全访问会话另说明不会逐项询问），再由「重新发送」确认，Esc 或「取消」收起。

**说明。** 会话里的系统说明报告失败（模型服务出错、运行被中断、会话停止）时与错误提示画法相同：红色调、红色圆形叉号，文字为次级墨色；其余系统说明是居中的一行提示墨色小字，前面一个 12 的信息图标。

**回到最新。** 读者离开最新输出时，输入框上方 12 处浮起「回到最新」（上移 8px 淡入，180ms；回到底部时淡出，120ms）。回合运行中它带着 12 的彗星、阶段与已运行时间（最宽 280，窄于 360 时只留彗星与时间），读屏名称仍是「回到最新」，阶段是它的描述；等你批准时是普通的样子，因为输入框上方的运行条已用琥珀说了。

**计划。** Harness 报告计划时，运行条右端是一个「计划 2/4」小块，点开在上方弹出完整列表（320 宽；手机为底部面板，标题写「计划 2/4」，只有「完成」，列表不再重复标题）；会话信息里也有「计划」块。步骤的标记是静止的：空心圆、带点的圆（进行中，正文墨色与 500 字重）与对勾，已完成的步骤最淡；会话停下后，进行中的那一步读作未完成；步骤状态变化时标记交叉淡化。

**运行条与输入框。** 运行中输入框仍可编辑，但需等本轮结束才能发送。运行条只在有可做的事时出现在输入框顶部（高度随展开动效变化）：有待审批时琥珀色「N 项待批准 · 查看」；「正在停止…」；停止结果尚未确认时「停止结果尚未确认 · 重试」；以及计划小块。运行在做什么、做了多久由对话里最新一轮的活的一行说，运行条不再写。停止不是风险操作，按钮不变红。输入框浮在自己的阴影上，聚焦时只把环加深，不变蓝；发送是输入框里唯一的蓝色按钮，没有内容时退为中性填充。桌面 Enter 发送、Shift+Enter 换行；触屏设备 Enter 换行；⌘/Ctrl+Enter 总是发送；输入法组字时不会发送。

**会话信息的块。** 每块是地面上的一张纸（圆角 12、静止的线、不带阴影），36 高的头部，点标题收起或展开（收起按设备记住），行 32 高：16 的图标、提示墨色的标签与正文墨色的值；没有内容的块不出现。Agent：32 的磁贴、名称与来源（内置、插件，或 ACP 加许可证；管理这台 Host 的设备在中间看到 Agent 运行的命令名，悬停写出完整命令行），模型（使用 Host 模型时可在这里换，从下一条消息起生效；Agent 自己的模型与模式选项也在这里，24 高的选值，箭头悬停时出现），方式，以及这台设备不能修改时带锁的原因。环境：运行 Host 的电脑（桌面端加「本机」）与项目目录（目录名，下面是完整路径：按可用宽度在中段省略，最后一段保持完整，可复制）。权限：逐项询问或完全访问（琥珀 `shield-alert`）、权限模式变化后的红色胶囊，「权限说明」展开执行方、定义是否已验证、模式能否读回、是否请求审批与 Harness 的说明。用量：输入、输出（「12.4k tokens」，悬停写出精确数与各部分，Agent 报告的注明）、Agent 报告的上下文（「74k / 200k tokens」与 4px 的墨色进度条，80% 起琥珀并写「接近上限」）与费用（注明「由 Agent 报告，不是账单」）、各轮用时合计与轮数、开始于。计划：完整步骤，头部是进度。变更：会话中工具改过的每个文件一行（目录、文件名、合计增删行数；原内容未显示时不写删除数），点它在对话里展开并定位到最后改它的那次工具调用。

**设置。** 分区：通用、电脑、模型服务、Agent 成员、项目、插件、设备、关于。模型服务、Agent 成员、项目与插件需要「管理此 Host」权限；没有该权限的设备看到通用、电脑（只读）、设备与关于；旧版 Host 没有电脑与设备。每个分区由页头（18/26 的标题、13/20 的说明与最多一个次按钮）和若干组构成：组头 13/18·500 次级墨色，右侧可放提示墨色的元信息（计数写出数的是什么：「2 个项目」「1 个 Agent」）或一个链接按钮；组是纸上的卡片（1px `--line`、圆角 12），卡片下方最多一行 12/18 的说明，可带锁或信息图标；组之间 32px。卡片里的行至少 56 高、内边距 16，副行 12/16、只写一句（偏好写所选值的后果，记录写状态），命令与路径是一行等宽字，放不下时从中间省略、保留末尾，完整内容在提示里；尾部只放一样东西：选值（按 `--bleed` 外扩，箭头与导航行的箭头对齐）、开关、一个按钮、一个图标按钮（⋯ 菜单、复制、在访达中显示），或提示墨色的值；分隔线从文字左缘画起。进入对象或列表的行整行可点，尾部是提示墨色的值与向右箭头，悬停铺满整行；离线、不可用的对象只淡化磁贴、名字改次级墨色，状态写在副行。不能用的选项写出原因：12 的禁止图标加 12/16 次级墨色的一行，不随行淡化。危险操作（撤销此设备、删除 Agent、移除密钥、删除服务）放在页面末尾一张红色描边的卡片里。在页面上增删的行与卡片（出站白名单、项目）高度展开并淡入（180ms），移除时收起淡出（120ms）。只改一个值的操作（重命名、修改地址、设置密钥、添加环境变量、编辑启动定义）打开 560 的表单对话框，保存即生效。

- 通用：主题（跟随系统 / 浅色 / 深色的分段控件）、发送键（单选列表），有「管理此 Host」权限的设备还有新会话默认值：Agent、方式（对话 / Agent，副行随所选值写出后果）、模型（只在该 Harness 使用 Host 的模型时）与项目各是一行选值，选中即保存到 Host，失败时退回 Host 的值并显示原因。内置 Harness 在设置里都叫「Latch 内置」。
- 电脑：见「设备与权限」中的「电脑与权限上限」。
- 模型服务：列表卡片（默认服务带「默认」，停用的写「已停用」；演示与插件提供的服务在「其他来源」；还没有服务时，那一行进入「选择服务」）。点进去是该服务的页面，每个值单独生效：页头的「重命名…」；「连接」卡片里的启用开关、API 地址与「修改…」（改到另一个源时，对话框先说明保存会移除已保存的密钥），以及「检测连接」（结果写在副行：延迟与模型数，或原因）；「密钥」卡片写「已保存（不回显）」与只发往的源，或「未设置」，执行端桌面端有「设置密钥…」或「替换…」，经本机确认保存，其他设备在卡片下方看到原因与 `pnpm latch provider set-key`；「模型」卡片每个模型一行，单选框选默认、尾部移除，最后一行手动添加模型 ID，组头的「获取模型」把服务提供而尚未添加的模型列在「可添加的模型」卡片里（多于 8 个时可筛选）；被出站策略拒绝的地址可在桌面端经本机确认加入白名单；末尾红色卡片里是「移除密钥」与「删除服务」。「添加服务」先选预设，再在卡片里填名称、接口类型（自定义时）、API 地址、密钥（只在执行端桌面端）与模型，最后是「添加服务」。
- Agent 成员：「本机 Agent」卡片每行是磁贴、名称与小徽标（完全访问、许可证、未验证的定义、已停用）、命令与检测结果（找到时是一行从中间省略的路径），尾部是启用开关；点行进入该 Agent 的页面：页头的「重命名…」、启用开关；「启动定义」卡片里命令与参数各一行，执行端桌面端从组头的「编辑…」在对话框里修改，其他设备只读并在卡片下方说明原因；「环境变量」卡片只列变量名，桌面端可以添加（对话框）与移除，保存都经本机确认；「检测」卡片写找到的命令路径（可复制）或缺什么、定义的问题、是否已验证的预设，以及安装命令（可复制）与项目主页，组头是「重新检测」；末尾红色卡片里是「删除 Agent」。预设需要另一个程序时（pi-acp 连接 pi），检测写出缺的是哪一个：「已安装 pi，还差让 Latch 连接它的适配器 pi-acp」「已找到适配器 pi-acp，还没找到 pi」或两者都没找到。窗口重新获得焦点或回到前台时页面重新读取检测结果，读取本身也让 Host 重新查找命令。Latch 不安装 Agent，所以只提供可复制的安装命令，没有「安装」按钮。添加 Agent（先选预设，再在卡片里填启动定义与环境变量）在执行端桌面端进行，其他设备看到原因。
- 项目：每个项目一张卡片：头行是项目名（新会话默认在这里启动时带「默认」；Host 认为不可用的（有文件夹找不到、无法打开或不再符合规则）带琥珀色「不可用」与原因）与 ⋯ 菜单（「移除项目…」，确认后移除，文件夹不删除），下面一行是它的文件夹：文件夹名与完整路径，尾部在桌面端是「在访达中显示」（Windows、Linux 上按系统改名），其他设备是复制路径。另有「启动目录」卡片（Host 启动时使用的目录，不能移除）。新建项目只在运行 Latch 的电脑上的桌面端进行：页头的「新建项目…」打开系统的文件夹选择面板，也可以从访达把文件夹拖进页面（拖动时整页显示「松开以用这些文件夹新建项目」，拖入的不是文件夹时说「只能拖入文件夹」）；桌面端主进程先用原生对话框列出拖入的每个路径请你确认，再自己把项目加到 Host，页面从不发送路径。没加进去的文件夹逐个写出原因，加进去的直接出现（不弹提示）。浏览器和手机没有新建的入口，卡片下方写「新建项目要在运行 Latch 的电脑上用桌面端完成」；较早的桌面端写「重新启动 Latch 桌面端后，可以在这里新建项目」。新会话的项目选择器与默认值都不提供停用的项目；保存的默认项目不可用时，Host 让新会话改用启动目录。由几个文件夹组成的项目，Host 与桌面端已支持（见 [ARCHITECTURE.md](./ARCHITECTURE.md#项目与文件夹)），页面中的界面尚未实现（客户端界面正在改版，之后加入）：项目编辑页（重命名、图标、添加与移除文件夹、调整顺序与设为主文件夹、重新选择找不到的文件夹）、新会话选择器里的文件夹数与各 Agent 使用的文件夹、侧栏按会话记下的项目分组、会话信息里的每个文件夹，以及把会话自己的文件夹「存为项目…」。在此之前这一页每个项目只显示主文件夹；「新建项目…」可以多选，选中的文件夹组成一个项目，「新建项目…」与拖入都由桌面端主进程签名后提交。
- 插件：按类型分组（组头写「N 个插件」），每行是名称与版本、内置与使用中的标记，以及一句说明（它做什么，或为什么现在不能停用），提供的能力在提示里。尾部只放这里真正能做的事：能启停的插件是开关，正在被运行使用时开关锁住（锁图标加原因）；由模型服务或 Agent 成员管理的插件是进入该分区的导航（「在模型服务中管理」）；内置的写「始终启用」。
- 设备、关于：见下。

## 设备与权限

界面按设备的权限隐藏或禁用操作，只是为了不展示做不到的事；每条规则都由 Host 再次执行。门控规则集中在 [permissions.ts](../apps/web/src/core/permissions.ts)。

**安全文案。** 这些错误文案集中在 [securityCopy.ts](../apps/web/src/core/securityCopy.ts)。

**登记页。** 未登记或凭据失效的浏览器在地面上看到一张安静的纸（[EnrollmentPage.tsx](../apps/web/src/components/EnrollmentPage.tsx)，静止卡片的 12px 圆角）：标题「连接到 Latch」、说明、设备名称、权限清单与主按钮「请求本机确认」。输入框与主按钮在 768px 起是 32px，手机上是 44px。浏览器的权限清单中，查看会话、发起和继续会话、批准普通操作为固定项，「管理此 Host」为复选框，不经配对邀请登记 Host 的第一台设备时默认勾选；桌面端在 `host.sock` 上登记，六项权限全部列为固定项，没有复选框。表单用 `TextField` 与 `Checkbox` 原语。提交后进入等待状态：琥珀色的指纹图块（等待时一圈光晕缓慢离开它，减少动效时只是图块）、「等待本机确认」、琥珀色的剩余秒数、一条琥珀色倒计时细线与「取消」；设备指纹是页面上唯一的大号文字（与本机确认的核对码同一字级：等宽 24px、字距略宽，20 位、按 4 字符分为 5 组，排成三组与两组两行，不会有一组单独落在一行），下面是较小的核对码，便于和电脑上的确认窗口逐字比对。被拒绝、超时与指纹不一致用红色提示并可重新提交。本机确认不可用时，开头的说明改为用离线登记码完成登记（不再提 Touch ID），琥珀色提示写出原因与 `pnpm latch device enroll --offline`，表单只接受离线登记码；Host 接受离线登记码时，正常表单下方也提供「使用离线登记码」。手机等远程设备没有配对邀请时只显示获取邀请的说明；浏览器无法在当前地址安全保存设备密钥时只显示一行红色说明，建议换用新版浏览器或桌面端。旧版登录状态显示「此设备需要在本机重新确认」并沿用旧设备名。撤销（红色）、满 30 天、换地址、丢失密钥、登记后浏览器没有保存凭据（例如禁止了 Cookie）与续期后浏览器没有保存新凭据（琥珀色）各有一行说明；后者建议允许 Cookie 后重新加载页面。设备名称可以包含表情（如「❤️ iPhone」「👨‍💻 Mac」）；含换行、不可见字符或改变文字方向的字符时，输入框下方用红色小字说明，提交按钮停用；旧设备名只在符合同一规则时沿用。登记完成后若第一次读取执行端状态失败，页面停在一行琥珀色提示与「重试」上，重试只重新读取状态，不会再登记一台设备。第一次连上 Host 之前，页面只显示「正在连接执行端…」，失败时显示琥珀色提示与「重试」。

**电脑与权限上限。** 「设置 › 电脑」（[ComputerSettings.tsx](../apps/web/src/settings/ComputerSettings.tsx)，逻辑在 [ceilings.ts](../apps/web/src/core/ceilings.ts)）讲的是运行 Host 的这台电脑：名称（这台设备就在这台电脑上时带「本机」，以及开发版标记）、本机确认不可用时的一行原因、手机接入（HTTPS 地址与复制，或「未配置」与启动参数）。「权限上限」卡片：

- 「在这台电脑上发起」是一条阶梯，对应 `local.maxLevel` 与 `local.allowL3` 两个字段：允许完全访问时显示完全访问，否则显示内置 Harness 的上限。选完全访问写 `{maxLevel: 不低于逐项询问, allowL3: true}`，选更低的级别写 `{maxLevel, allowL3: false}`，两个字段在一次请求、一次确认里改。副行按保存的两个字段写出后果：允许完全访问时「在 Latch 桌面端发起；每个完全访问的会话仍要单独确认」（内置上限为只读时说 Latch 内置的会话不能发起）；不允许时「Agent 成员（完全访问）不能在这台电脑上发起会话」，只读时「只能查看、拒绝和停止会话」，自动编辑时先说它尚未实现、按逐项询问执行。
- 「从手机和其他电脑发起」写 `remote.maxLevel`，副行说明它也管这台电脑上的浏览器（只读时先说只能查看、拒绝和停止会话）；完全访问总是不可选，原因是完全访问会话只能在这台电脑的 Latch 桌面端发起。
- 「允许其他设备在这里新建会话」是开关（`remote.allowRemoteStart`）。
- 「其他设备可用的 Agent」「其他设备可用的项目」进入列表页：「全部」开关（`null`，包括以后添加的）或逐项勾选（`remote.harnesses`、`remote.workspaces`，组头写「N 个 Agent」「N 个项目」）；卡片下方说明加入或改为全部要在这台电脑的 Latch 桌面端验证身份，浏览器里不能勾选的条目写出带禁止图标的原因；列表还记着但 Host 上已经没有的条目显示为已移除，只能取消勾选。
- 卡片下方写「调高上限要在这台电脑上的 Latch 桌面端验证身份。高风险操作只能在这台电脑上批准。」

两条阶梯是 `PermissionMenu`，四项从低到高：只读（只能查看、拒绝和停止会话）、逐项询问、自动编辑、完全访问。自动编辑还没有自己的行为（内置 Harness 固定按逐项询问运行），所以它的说明写「尚未实现，目前按逐项询问执行」，保存的上限是自动编辑时副行写同样的话，从不说它会直接编辑。降低（级别降低、关闭开关、从列表移除、移除白名单条目）在任何管理设备上立即生效，值先原位更新，Host 拒绝时退回；调高（含打开开关、加入列表、选「全部」、加入白名单）只在执行端桌面端经本机确认进行：选择器原位显示「等待验证…」，本机确认对话框照常打开，取消时值不变、不报错。浏览器和手机在调高的选项、开关与按钮上直接写出原因（「只能在这台电脑的 Latch 桌面端调高」「…开启」「…添加」），桌面端在本机确认不可用时同样停用并说明。Host 对降低回应 `x-latch-audit: failed` 时，页面顶部用红色提示说明修改已生效但没有写入审计记录（[securityCopy.ts](../apps/web/src/core/securityCopy.ts)）。没有「管理此 Host」权限的设备只读地看到快照里的两个上限，副行与可修改时相同。「出站白名单」卡片列出 `hostEgressAllow` 的每个 `host:port` 与「移除」，没有条目时写「没有例外」与「Host 只访问公网地址（启动参数放行的地址除外）」；执行端桌面端在组头有「添加…」，打开表单对话框，地址必须是精确的 `host:port`，加入需要本机确认；其他设备没有这个按钮，卡片下方的说明在策略之后写出只能在这台电脑的 Latch 桌面端添加。

**本机确认。** 高风险操作只能在运行 Latch 的电脑上确认。

**审批。** 审批卡就是工具卡片等你决定的样子（[ApprovalCard.tsx](../apps/web/src/components/ApprovalCard.tsx)）：托盘里依次是卡片头部（工具图标、标题与工具 ID、状态胶囊）、Agent 给出的原因（次级墨色，与标题相同时不重复）、请求的时间、改变「允许」含义的说明、预览、一句允许会怎样的脚注与按钮行（44）。只用 Host 给出的数据：Host 没有的后果句、效果清单、排队位置与「由谁决定」的记录都不画。卡片的种类与这台设备能做什么由 `permissions.ts` 的 `approvalActions` 决定（只是显示，Host 会再次检查）：内置 Harness 的普通操作（R1）是中性托盘加琥珀的「待批准」胶囊（只有文字，轮到它时扫过暖光），这是卡上唯一表示等你的标记；高风险（R2，当前 Host 没有给出风险等级时也是）托盘与「高风险」胶囊为红色，红色只表示风险，卡上没有蓝色，按钮都是浮起的白色次按钮；完全访问会话里 Agent 的询问总是「仅提示」（琥珀胶囊，按高风险对待），下面一行琥珀色小字说明拒绝会转达给它，但不能阻止它执行其他操作，按钮按选项的种类写成「拒绝」「允许一次」「始终拒绝」，Agent 自己的措辞（可能是别的语言）放在提示框里；旧版 Host 的请求只有普通的允许与拒绝。标题、原因、参数、路径与差异含不可见或改变方向的字符时，它们显示为琥珀底的 `\u{XXXX}` 标记并多一行说明；这是与种类无关的另一个标记：普通操作的胶囊换成琥珀的「需要核对」，高风险与仅提示保持自己的胶囊，任何允许按钮都退为次按钮，⋯ 也不出现（只留拒绝与允许一次，更宽的选择要等内容干净的请求）。预览（参数与差异，放在托盘里的纸上）在「查看预览 / 收起预览」下展开与折起（展开 180ms、收起 120ms，按高度过渡，标题不动、纸向下长）：差异已经写出的路径与新内容不再作为参数重复；差异的纸先显示前几行（桌面 7 行、手机 6 行，含 `@@` 行），其余收在 28 高的折叠条「展开其余 N 行」后面（手机上点按区 44），所以纸不超过 240；桌面在预览放得下 240 时默认展开，手机默认折起，含不可见字符时总是展开；没有参数也没有差异时直接写「无参数」。手机上差异只留一列行号（删除的行写它原来的行号），每行是行号、符号与文字；预览里的差异是一张纸，没有托盘的内边距，所以前几行与折叠条在 240 之内。脚注只写真实的行为：普通操作的「允许一次」是「只允许这一次，之后的同类操作仍会询问。」，桌面端的高风险是「允许后要在这台电脑上用 Touch ID 或登录密码确认。」，手机上脚注是 13/20。按钮行最多两个按钮：拒绝在前，「允许一次」在最后，普通操作时是卡上唯一的蓝色；Host 提供的其余选项（「本会话始终允许」，附「只在这个会话里有效」）放进左边的 ⋯（「更多批准选项」），手机上是整宽的「更多选项」，打开底部面板。桌面端允许高风险操作的按钮是带锁图标的次按钮「在本机允许」（提示框说明需要 Touch ID 或登录密码）。按下后确认就在卡片里进行，没有另外的对话框：按钮保持原来的文字与宽度，锁的位置换成转圈，脚注换成「等待本机确认：在弹出的确认窗口中核对内容，再用 Touch ID 或登录密码确认。」（读屏会读出），确认通过后是「已在本机确认，正在执行…」，Host 结算后卡片收起；确认没有通过、超时或出错时，按钮立即恢复，卡片里留一行红色说明（例如「操作没有执行。本机确认没有通过。」），再按一次「在本机允许」就重新申请确认；Host 无法开始确认时那一行是琥珀色。完全访问会话的询问在桌面端只有拒绝与允许一次。设备不能允许时，「允许」不出现，按钮行左边用锁图标与一行说明写出原因（没有对应权限，或只能在执行端电脑的 Latch 桌面端批准或回应），「拒绝」始终可用；手机上它是整宽的一个按钮。卡片取得焦点时（不在触屏上，也没有选择正在发送）按钮行左边淡入快捷键提示「Esc 拒绝 · ⌘⏎ 允许一次」：Esc 拒绝一次，⌘/Ctrl+Enter 只为没有不可见字符的普通操作允许一次；卡片本身不响应单独的 Enter（按钮照常响应）。发送选择时只有被按下的按钮转圈，其余停用。结果未知（网络中断、超时）时卡片里出现红色提示，标题写出是哪一个选择（「「拒绝」的结果未知」），说明「可重试同一选择，不会重复提交。」，附「重试」，重试用原来的 `requestId` 再发同一个选择；这时 ⋯ 不出现，两个按钮都是次按钮，「重试」是卡上唯一明确的动作（换一个选择仍可以发，Host 会处理冲突）。这台设备此前作了不同选择时输入框上方提示「此设备此前已选择「…」，本次「…」未生效。」；已由其他设备处理或已失效时，以短暂提示显示「已由「设备名」处理」或「该审批已结束」。卡片出现时只淡入（180ms），不长高，不推动正在读的内容；Host 结算后，卡片的审批部分按高度收起（180ms，内容在 120ms 内淡出），过渡结束后才移除。减少动效时这些过渡都近乎瞬时。

**差异与内容哈希。** 差异文件名旁的标记按执行端的说明区分（[DiffView.tsx](../apps/web/src/components/DiffView.tsx)）：执行端确认文件不存在时为中性「新文件」；文件存在但原内容过大、是二进制或无法读取时为琥珀色「原内容未显示」；执行端没有说明时为琥珀色「原内容未知」。后两种在差异内和审批区顶部各有一行说明可能覆盖现有文件，差异不显示删除行数。新增与删除行数只在不为 0 时用色调文字，为 0 时是提示墨色。差异展开后，文件名下方有一行灰色小字「新内容哈希」与等宽的 `xxxx-xxxx-xxxx-xxxx`，格式与本机确认窗口中的同名一行相同，便于核对审批区看到的内容就是确认窗口绑定的内容；哈希在渲染后计算，期间显示「计算中…」，页面没有 WebCrypto 或文本已被 Agent 截断时不显示这一行。

**会话权限。** 只有完全访问会话在顶栏右侧显示琥珀色的「完全访问」状态胶囊，前面是 `shield-alert`（手机上同样）；逐项询问（L1）是默认，顶栏不显示。会话信息的「权限」块写出级别、权限模式变化后的红色「权限模式已变化」胶囊，「权限说明」展开执行方、定义是否已验证、模式能否读回、是否请求审批与 Harness 的说明。输入框在以下情况换成带锁图标的只读说明（虚线 `--line-strong` 边的托盘，不带阴影，不像一个等待输入的输入框），运行条与停止按钮保留：完全访问会话在执行端以外的设备上（「完全访问会话只接受执行端电脑上 Latch 桌面端的输入。此设备可以查看、拒绝和取消。」），或设备没有「发起和继续会话」权限。会话不再接受输入时，消息区顶部出现横幅并附「新建会话」，输入框换成「该会话不再接受输入。」：权限模式漂移为红色，来自会话状态；Agent 定义变化、项目中的 Agent 配置在确认后变化、会话创建于安全升级之前，以及无法确认 Harness 已进入预期的权限模式为琥珀色，在这台设备的输入或选项修改被 Host 以对应错误码拒绝后出现。新会话选择器中的完全访问 Harness 带中性的 L3 小徽标（没被选中的选项不报警，选中后由顶栏的琥珀标记表达），在执行端以外的设备上禁用并注明「仅本机桌面端」；在桌面端选中时，输入框下方用琥珀色小字提示「开启完全访问会话需要本机确认。该会话可以读写 Latch 数据和 Host 身份私钥。」

**开发版标记。** Host 报告开发模式时（当前的构建都未经签名发布，所以总是如此），侧栏底部电脑名旁（≥1024px）、图标栏底部（平板）或设置页标题栏（手机）显示一个中性小标签「开发版」，悬停提示与读屏名称为「开发模式：Host 代码可被本机修改」；「设置 › 电脑」在电脑名旁同样显示它，「设置 › 设备」在「此设备」卡片下写出整句说明：此版本未经签名发布，能修改本机文件的程序也能修改 Host 与桌面端。它不使用红色。

**设备设置。** 「此设备」（[DevicesSettings.tsx](../apps/web/src/settings/DevicesSettings.tsx)）：可修改的设备名称，以及连接方式、状态（正常是默认状态，只写文字；需要处理的状态才用徽标）、设备指纹、权限与登记有效期，各占卡片的一行；「撤销此设备」在页面末尾红色描边的卡片里。「已登记的设备」（需要「管理此 Host」）：每台设备一行，显示名称（当前设备带「本机」）、非正常状态的徽标（待复核（仅查看）与需重新确认为琥珀色，已撤销为红色并排在最后）、连接方式与最近使用（或撤销时间）、权限；其他未撤销的设备尾部是 ⋯ 菜单：「调整权限…」（需重新确认的设备没有）与「撤销设备…」。撤销前说明由它邀请配对的设备会降为仅查看，等待复核。「调整权限」对话框中，「批准高风险操作」与「设置密钥」只对在执行端桌面端登记的设备提供；增加权限或恢复待复核的设备时按钮为「授予权限（需要本机确认）」，只能在执行端的桌面端进行，其他设备上按钮停用并说明原因；只收回权限时按钮为「保存权限」，任何管理设备都可以。设备名中的隐藏字符按审批区的规则显示为 `\u{XXXX}`，包括撤销确认与权限对话框里的名称；改名时的校验与登记页相同。「手机配对」（[PhonePairing.tsx](../apps/web/src/settings/PhonePairing.tsx)，安全界面）：只有执行端桌面端的管理设备、且 Host 配置了 HTTPS 时显示说明与蓝色的「生成配对二维码」；二维码为 data URL 图片，深色模块配白底（深色主题下也是，便于扫描），10 分钟内有效、只能使用一次，旁边是带编号的三步说明、剩余时间、复制链接（手机上为分享链接）与幽灵按钮「重新生成」；过期后回到说明并附一行「上一个二维码已过期。」。其他情况只显示一行原因：没有 HTTPS 时说明启动参数，不在执行端桌面端时指向桌面端或 `pnpm latch device invite`。

**模型服务与 Agent。** 执行端以外的设备不能输入或更换密钥（仍可移除），字段显示锁定状态，已有服务的说明给出 `pnpm latch provider set-key <id>` 的替代方式；已保存的密钥注明「密钥只发往 <地址>」，修改地址时提示会清空密钥。Host 出站策略拒绝某个地址时，执行端桌面端的管理设备会看到一行琥珀色说明与「允许 Host 访问 <地址>（需要本机确认）」，确认后地址加入白名单并重新检测连接。添加 Agent 以及修改启动命令、参数与环境变量只能在执行端桌面端进行，名称与启用状态任何管理设备都可以改；每个 Agent 标注中性的 L3 与许可证小徽标；未验证的定义另带中性小徽标「未验证的定义」，已验证的预设是默认，不加标记。

**旧版 Host。** 快照中没有 `host` 时，Host 来自升级前的构建：界面退回旧规则（普通的允许与拒绝、由旧的主设备身份决定设置），隐藏设备、邀请与本机确认相关的界面，并在消息区顶部显示一行中性提示「此 Host 仍是旧版本，重启 Host 后启用设备确认。」；未登录的浏览器在这样的 Host 上看到「此 Host 版本过旧，请在电脑上重启 Latch。」

**审计回滚。** 审计记录被回滚时显示红色横幅，可核对或关闭。

**界面出错。** 工作区渲染出错时不会整页空白：显示一张卡片「界面出错，当前内容无法显示。」，提供「回到新会话」与「重新加载」；本机确认对话框不受影响。单条回复渲染出错时，这一条按纯文本显示。

## 流式与阅读

| 情况 | 界面行为 |
| --- | --- |
| 等待首段输出 | 最新一轮的活的一行写正在启动 Agent 或等待模型；不伪造思考内容或百分比 |
| 推理到达 | 思考行写「正在思考」与秒数，身体自动展开并跟随最新的推理 |
| 正文到达 | 在稳定身份的同一消息行内更新 Markdown，完成后沿用该行；思考行收起并写出思考用时 |
| 工具调度 | 过程行区分等待执行、等待确认、执行中、完成、失败、取消；运行中的输出在自己的框里跟随最新的行 |
| 审批 | 合并在对应工具卡片内，展示原因、参数与预览；活的一行写「等你批准」，已运行时间停住 |
| 取消 | 请求中保留取消状态；超时显示"尚未确认"并允许重试；部分回复保留，回合脚部写「已停止 · 保留了部分回复」（没有正文时只写「已停止」） |
| 结束 | 活的一行在原地变成回合的结果、回复时间与用量；正常完成的回合把答案前的过程收成一行 |
| 离线 | 保留已读内容；连接状态单独标注，恢复并同步后才显示已连接 |
| 上翻阅读 | 进入阅读模式，流式输出不夺走位置；"回到最新"带着运行阶段，点它恢复跟随 |
| 切换会话 | 阅读位置按会话保存；旧会话的异步结果不得写入当前会话；对话区只淡入，不播放消息到达的动效 |

所有程序性滚动集中在 `useReadingPosition`（`jumpToLatest`、`reveal`）；消息与工具行使用 `data-message-id` 作为锚点。不要在组件中另外写入 `scrollTop` 或调用 `scrollIntoView`。布局改变、代码展开、展开块的动画与视口变化不等于用户主动滚动。思考与工具输出这类嵌套的滚动框用 `column-reverse` 从末尾排布来跟随最新内容，不写滚动位置。从会话信息的「变更」定位到一个已折叠的工具时，页面先请折叠的祖先打开（与页内查找同一个 `beforematch` 路径），再交给 `reveal`。

Markdown 支持标题、列表、引用、表格、内联代码与代码块；原始 HTML 不执行，URL 只允许安全协议；图片从不加载，网页图片显示为「外部图片：说明」链接，其他图片只显示说明文字；嵌套过深的回复以一行灰色说明加纯文本显示；表格与代码在自身容器内滚动；代码可复制与展开，剪贴板失败有明确提示；代码中的不可见字符显示为 `\u{XXXX}` 标记，工具栏注明「含不可见字符」，复制内容保持原样。在桌面端，链接要在主进程的原生对话框中确认完整地址后才会在系统浏览器打开。流式全文不设 `aria-live`，避免逐字播报。

## 验收

UI 改动需要在桌面、平板、手机宽度检查真实渲染，覆盖正常、进行中、失败或等待状态，以及浅色与深色。`e2e/design.e2e.ts` 覆盖 320 / 375 / 414 / 768 / 1440px 的可达性、溢出与真实点击区域，包括开发版标记；`e2e/enrollment.e2e.ts` 在 1440×1000、768×1024、390×844 下截取登记页的表单、等待、拒绝、本机确认不可用与旧版重新确认，并检查登记页在注入的样式下不变；`e2e/permissions-ui.e2e.ts` 截取高风险审批、完全访问只读（桌面与手机）、权限漂移（含深色）与 Harness 选择器；`e2e/visual.e2e.ts` 在 390×844、768×1024、1440×900 下以浅色与深色截取浏览器能到达的每个状态与原语总览页（`ui-gallery`），并可与上一次运行逐像素比较（见 [TESTING.md](TESTING.md#视觉截图)「视觉截图」）。原语的角色与名称、键盘、焦点、提示框、禁用与运行中、对话框的焦点限制与归还、手机上的底部面板、触屏命中区、减少动效，以及活的指示的同一相位、接力编号与周期、只为亲眼看到的变化播放的一次性动效，由 `packages/ui/test/` 在真实浏览器里检查（`pnpm test --project @latch/ui`）。截图写入被忽略提交的 `test-results/`，不包含任何凭据。桌面端才有的界面由 `e2e/desktop.e2e.ts`（`HARNESS_ELECTRON_E2E=1`）覆盖并以浅色与深色截图：审批卡里的高风险确认（等待与没有通过）、停靠框（等待与没有执行）、手机配对（未生成、二维码与过期）以及桌面端可以回应的「仅提示」询问；`e2e/permissions-ui.e2e.ts` 另把审批卡到达与收起的过渡停在 0、60、120、180ms 截图，并核对时长与曲线取自动效令牌。浏览器尺寸模拟不等于 iOS/Android 真机的软键盘、后台挂起与读屏验收。
