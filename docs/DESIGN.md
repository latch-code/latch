# Latch 界面设计

Latch 是跨设备的 Agent 工作台：任务在 Host 上运行，人从桌面、浏览器或手机查看、审批、取消并继续同一段工作。界面同时表达会话内容、执行状态、设备连接与设备权限，且只展示真实存在的能力。

本文写改界面时必须守住的规则。取值以 [tokens.css](../packages/ui/src/tokens.css) 与各样式表为准，文案以源码为准，这里不抄。机制在各自的文档：传输、续期与阅读位置见 [STREAMING.md](./STREAMING.md)，项目恢复见 [WORKSPACE-RECOVERY.md](./WORKSPACE-RECOVERY.md)，模型配置见 [MODEL-CONFIGURATION.md](./MODEL-CONFIGURATION.md)，按需加载见 [CLIENT-LOADING.md](./CLIENT-LOADING.md)，外观自定义见 [CUSTOMIZATION.md](CUSTOMIZATION.md)。

## 品牌与原则

- **名称与图标。** 名称为 Latch。`apps/web/public/icon.png` 用于界面、窗口与主屏幕，`apps/web/public/favicon.png` 用于浏览器标签，`build/icon.png` 是源图。不改动图形本身。图标是界面里唯一的暖色元素，它的橙色不用来表达状态。
- **简约、克制。** 蓝白为主，中性的近白与近黑。层次只靠几层平涂的表面、细线、阴影与墨色深浅，不用装饰色、渐变、底纹、插画或表情。菜单、选值与对话框是不透明的面。控件按数据的形状选择，一种意思只用一种画法。
- **每种颜色只表达一件事，并且总配文字或图形。**

| 颜色 | 只用于 | 不用于 |
| --- | --- | --- |
| 蓝 | 执行动作的主按钮，每个界面最多一个；被勾选的控件（开关的开、复选、单选）；焦点环与选中文字的底；跳到别处的链接文字；运行中的图形（会话行、工作行与总览里的转圈和图标） | 「运行中」的字、计数与进度、静止的图标、用户气泡、徽标；菜单里的对勾；列表的选中行；视图、筛选与外观的选中；切换按钮的「开」 |
| 琥珀 | 等你处理；警告（连接中断、原内容未知、含不可见字符、结果未知、已开启的完全访问会话）；演示标记 | 可按的按钮；普通信息；没被选中的选项与常驻的属性 |
| 红 | 真实的失败与风险：高风险（R2）审批、失败、权限模式漂移、审计记录回滚、设备撤销、差异中的删除、危险操作的文字与确认对话框里的销毁按钮 | 完全访问、开发版、停止按钮、结果未知 |
| 绿 | 差异中的新增；短暂的成功对勾；通过的检查段与在线的连接点 | 已连接、已就绪、已检测到、已验证这类默认状态；已保存、已启用这类本地操作的结果（值原位更新就是反馈） |
| 墨色 | 其余一切：「运行中」的字与流式光标、计数与进度、静止的图标、菜单里的对勾、列表的选中行、视图与外观的选中 | — |

- **默认状态安静。** 连接正常、逐项询问、已检测到、已验证的预设不用颜色，也不加标记。标题行只在偏离默认时出现标记（连接异常、完全访问、演示）。风险色只在风险值真的被选中时出现。
- **内容优先。** 对话列是主角；导航安静，不用大面积饱和色。只有用户自己的消息有气泡，且是中性的。
- **每个状态只出现一次，出现在正确的位置。** 会话级状态在页头状态词与会话行；进行中的活动在最新一轮；等你允许只在它自己的卡上说一次，卡不在视野里时由「回到最新」的位置带你回去；单步状态在它的工作行。
- **少说明，用界面说。** 控件、图标、色调与状态词能说的不写成句子。说明不占版面：不写在控件旁或头尾，不放 ⓘ，而是它所说的那个控件在悬停与键盘焦点时的提示框，出现与消失都不挪动任何东西；触屏由按住或已有的「…」与详情找到，从不留常显的图标。状态、结果、要人处理的琥珀与红色警告、安全界面里的字不算说明。规则要求能找到的细节（Latch 不隔离 Harness、密钥发往哪里）在没改完的地方仍在 `Hint` 里。菜单只列选项：不折叠「更多」与「收起」，选项下不加灰字。
  不在此列的：审批卡对动作本身的描述、系统确认的固定句子、Host 照抄的提醒、不可逆操作的说明、告诉人哪里失败与怎么办的错误。
- **只展示真实能力。** 选择器只列 Host 目录中真实的 Harness、模型与项目；只有一个选项时是只读文字。演示模型必须带琥珀色「演示」标记。不展示虚构的数量、进度或尚未实现的菜单。设备做不到的操作隐藏，或停用并说明原因，不让人提交后再失败。
- **默认隐藏内部细节。** 路径中段省略并可复制；工具 ID 是次要文字；空参数写「无参数」。
- **用词。** 界面不用的词在 `scripts/glossary.ts` 的 `BANNED_WORDS`；文档与标识符不受它限制。

来自已移除的 Agent 的会话只能查看：输入框的位置是一行原因（`sessionReadOnly`，[permissions.ts](../apps/web/src/core/permissions.ts)），没有撤销本轮与清空上下文。

## 设计令牌

令牌在 `@latch/ui` 的 [tokens.css](../packages/ui/src/tokens.css)，页面的样式入口 [index.css](../apps/web/src/styles/index.css) 先导入它。页面的颜色、阴影、字号与行高、间距、圆角与时长只读这些令牌。下面的规则由 `apps/web/test/styles.test.ts` 与 `packages/ui/test/tokens.test.ts` 执行：

- 样式表只读已定义的令牌；颜色不写字面值（遮罩与配对二维码的白底除外，二维码在深色下也要白底才能扫描）。
- 字号与行高只用角色令牌，字重只有 400、500、600。
- 内外边距与间隔只落在间距台阶上，圆角只取台阶上的值，不加 `corner-shape`。
- 前景透明度不是一档墨色：只用于隐藏、淡入淡出与禁用。禁用只有一种画法，整个控件降到 45%，颜色不变。
- 循环动画只写在 `prefers-reduced-motion: no-preference` 里。
- 表面都是平涂，令牌里没有渐变、底纹与带色相的底。

**主题。** 浅色写在 `:root`；深色重写每个含颜色的令牌，同时写在 `@media (prefers-color-scheme: dark)`（根元素没有 `data-theme="light"` 时）与 `:root[data-theme="dark"]` 下，两份必须完全相同。主题偏好按设备保存，写入根元素的 `data-theme`。换主题不播放过渡：`switchTheme` 与 `followSystemTheme` 在改写期间给根元素标 `data-theme-switching`。浏览器的 `theme-color` 在每个宽度都取 `--sidebar`。黑不用纯黑，白不用纯白。

**表面。** 六级，由深到浅：凹陷 `--sunken`（井：代码块、命令输出、搜索框）、地面 `--sidebar`、画布 `--canvas`、浮起 `--raised`（输入框、Toast）、卡面 `--card`（浮在面板上的卡）、弹层面 `--pop`（菜单、对话框与控件的面）。浮在页面上的东西靠阴影分层，带 `--sh-*` 阴影的元素不再加边；窗口的区域之间只用细线（见「区域划分」）。深色里这六级依次提亮。

**对比度下限。** 调整任何表面、选中或墨色的值都要通过 `tokens.test.ts`：

| 对象 | 下限 |
| --- | --- |
| 正文 `--ink`、次级 `--ink-2`、红字 `--red`、蓝字 `--accent-ink`，在每层表面与叠在上面的悬停、按下上 | 4.5:1 |
| 主色与悬停主色上的白字 `--on-accent` | 4.5:1 |
| 提示墨色 `--muted` 与琥珀字 `--amber`，在它们常驻的表面上 | 4.5:1 |
| `--muted` 在其余表面、主色 `--accent`（焦点环是非文字）、琥珀图形 `--amber-icon` | 3:1 |
| 语法颜色 `--syn-*`：普通角色 / 注释 | 4.5:1 / 3:1 |
| 内容色板 `--kind-*`、`--ansi-*`、`--syn-flag` 在画布与凹陷上；`--content-*-ink` 在自己的底色上 | 4.5:1 |
| 图表系列 `--chart-*` 在浮起、卡片与弹出表面上 | 3:1 |

蓝、琥珀、红、绿的文字色另在三类色觉缺陷模拟下逐对检查 OKLab 色差不低于 3，只防近似同色；状态仍必须同时带文字或图形。

**层叠层。** tokens.css 第一行声明层的顺序 `tokens, custom, base, ui, app, security`，后面的层总是胜过前面的层，与选择器权重无关。

- `custom` 只收外观文档编译出的允许令牌（[CUSTOMIZATION.md](CUSTOMIZATION.md)）。
- [base.css](../packages/ui/src/base.css)（元素默认样式、焦点环、减少动效）在 base；每个原语的样式表（`packages/ui/src/styles/`）在 ui。
- 页面的样式表每个都导入一个层：共用部件 `ui.css` 在 ui，布局与界面在 app，`auth.css`、`confirm.css` 与 `security*.css` 在 security。
- 页面可以在 app 层按位置调整原语。新增的安全界面放进 security 层。

**安全界面的锁定。** 审批卡、本机确认、登记、配对与安全横幅带 `data-secure`；两种标记的含义见 [CUSTOMIZATION.md](CUSTOMIZATION.md)，名单以源码为准。

- 令牌锁：tokens.css 对 `[data-secure]`、`[data-lock]` 及其中的一切用第一层的 `!important` 钉住主题令牌，后面的层、祖先或元素自己的声明都改不了；自定义外观（只有主色、圆角、字号）进不去。
- 可见性锁：security 层里它们的规则对决定「能不能看见、读清」的属性写 `!important`：`display`、`visibility`、静止时的不透明度、颜色、字号与字体，以及可能藏起或缩小它们的变换、滤镜与裁切。页面加的任何样式都不能隐藏、改色或缩小安全界面；里面的原语同样钉住。
- `data-lock` 只取令牌锁，给在任何自定义下都要长得一样、但不是安全界面的标记（权限菜单、提问卡、结果未知的状态）。
- 不遮盖、不移动：背景层不画在安全界面之下；具名动效与布局的整窗淡化跳过安全界面、它里面的元素和包含它的容器；审批、确认与配对显示的东西出现后不位移、不淡化、不过光，撤下也是直接撤下。
- 密度与自定义不改变安全界面的尺寸。

看不到项目文件的设备仍看到文件操作的动作、路径和原审批按钮；差异正文与编辑内容由 Host 在 HTTP/SSE 出口省略，不靠 CSS 隐藏。缺少文件内容不是「没执行」或「成功」的证据。会话的 Markdown 导出用同一投影。

**令牌的类别。**

| 类别 | 令牌 | 用途与规则 |
| --- | --- | --- |
| 墨色 | `--ink`、`--ink-2`、`--muted`、`--faint` | 正文与标题 / 次级强调 / 次级文字与静止的图标 / 占位符与时间 |
| 表面 | 上面六级，另有 `--hover`、`--press`、`--selected`、`--selected-ring`、`--bubble`、`--scrim`、`--surface` | 悬停与按下是黑（深色是白）加透明度；`--selected` 是列表选中行；`--surface` 是元素下面那层表面，状态点与计数用它镂空，换了表面的容器要改写它 |
| 线 | `--line`、`--line-strong`、`--joint` | 一律 1px；静止容器的边 / 输入、复选框与描边按钮的环 / 卡与下面输入框的接缝 |
| 阴影 | `--sh-*` | 层次用阴影画；静止的行不带阴影 |
| 主色 | `--accent`、`--accent-hover`、`--accent-ink`、`--accent-soft`、`--on-accent` | 白字下面的蓝底、焦点环与被勾选的控件用 `--accent`；蓝色的字只用 `--accent-ink`；`--accent-soft` 只给焦点外晕与选中文字的底，没有其他蓝色的底 |
| 琥珀 | `--amber`、`--amber-icon`、`--amber-soft`、`--amber-line` | 文字 / 图形；琥珀落在中性表面上，不做底色 |
| 红与绿 | `--red`、`--red-solid`、`--red-soft`、`--red-line`、`--green`、`--diff-*` | `--red-solid` 只给确认对话框里的销毁按钮；差异只染行背景，文字保持 `--ink` |
| 图表 | `--chart-1`…`--chart-4` | 只给图表的系列，按序取、不循环；四色在对话框表面上至少 3:1，相邻两色过色盲检查。系列旁总有名字，Harness 另带品牌图标，不只靠颜色；不用主色、琥珀、红表示普通系列 |
| 头像 | `--agent-*` | 只给我的 Agent 头像；不用红、橙、黄、亮绿与亮蓝，那些已经表示状态 |
| 内容 | `--syn-*`、`--content-*`、`--kind-*`、`--ansi-*` | 只出现在内容里（回复、代码、工作行的种类图标与命令输出），界面框架不用。不复用动作蓝、警告琥珀、风险红或差异绿；文件标记用链接的蓝，命令输出的红绿就是失败与通过 |
| 字级 | `--fs-<角色>`、`--lh-<角色>`、`--lh-<角色>-para` | 每个角色一个字号、一个单行行高；手机（<768px）整体换大一档，输入 16px 防止 iOS 聚焦时缩放。600 只给标题类，界面框架不超过 500，未读不加粗；时间、计数与表格数字用等宽数字 |
| 字体 | `--font`、`--mono` | 平台系统字体，不加载网络字体；等宽用于代码、参数、工具 ID、设备指纹、核对码与内容哈希 |
| 间距、圆角 | `--sp-*`、`--bleed`、`--r-*` | 嵌套圆角等于外圆角减内边距；可悬停的行可向两侧外扩 `--bleed`，让文字仍对齐列边 |
| 浮层 | `--layer-*`、`--tip-radius`、`--layer-radius`、`--modal-radius`、`--scrim-blur`、`--z-*` | 见「浮层」 |
| 动效 | `--m-*`、`--e-*`、`--rise`、`--s-press` | 见「动效」 |
| 工作台 | `--work-*`、`--density-row`、`--fx-ink` 等 | 对话与看板共用同一套画布、浮起、凹陷与墨色 |
| 布局 | `--sidebar-width`、`--inspector-width`、`--content-width`、`--gutter`、`--topbar-height`、`--touch` | 见「布局」；`--touch` 在粗指针上是 44px |

**动效。** 动效只用来说明界面发生的一个变化。

- 五档时长各配一条曲线：`--m-micro`（悬停与按下、图标替换、状态词交叉淡化）、`--m-enter`（菜单、弹层、消息与行的到达）、`--m-panel`（侧栏、面板宽度、展开与折叠）、`--m-sheet`（对话框、底部面板）、`--m-push`（手机的推入与返回）。离开用进入时长的 70% 与退出曲线。脚本读 `MOTION` 与 `EASING`，它们与令牌相等。
- 具名动效原语（[moves.ts](../packages/ui/src/moves.ts)）只动 `transform` 与 `opacity`。新的一次从上一次所在处出发并取消上一次，不排队。
- 没有 Host 的事件或回执不播放；乐观更新不配动画；失败不播完成的光。
- 过渡只为页面亲眼看到的变化播放一次，首次加载、重连与重新同步时直接显示新值（见「界面原语」的「状态」）。
- 只有正在进行的工作会循环；循环离开视野时暂停（流式光标除外）。
- 正在出字的层用 `useStreamingLayer` 标记（[stream.ts](../packages/ui/src/stream.ts)）：它在视野里时活动边、连接点与背景层暂停，该层内部跳过具名动效。
- 拖拽中跟手的部分不做过渡。
- 尚未实现：队列移位、发送、决策回执的专用动效接线（原语已有，外壳只接入了布局的交叉淡化）。

**减少动效。** 有两个来源：系统偏好与这台设备的「设置 › 通用 › 动效 › 减弱」（根上的 `data-motion="reduce"`）。

- 脚本只问 `motionAllowed()`，不单看媒体查询。
- 新样式里减少动效的规则写两份：`@media (prefers-reduced-motion: reduce)` 与 `:root[data-motion='reduce']`。只保留淡入淡出，不滑动、不缩放、不长高、不转动；循环停在静帧。
- 减少动效时流式回复立即画出已到达的文字。
- 截图用的冻结是另一个属性 `data-capture="still"`（`captureStill()`），设置写入或移除 `data-motion` 时不清它。

**背景层。** [Backdrop](../packages/ui/src/backdrop.tsx) 是内容之下单独的一张画布，不承载信息。

- 它只接收两个真实状态，每个在前景都另有文字和图标：在跑的会话数、刚处理完一个决定的位置。
- 它不画在 `[data-secure]` 之下，也不在安全界面内渲染；文字直接放在画布上的区域标 `data-backdrop-clear`，整块挖掉。区域出现、离开、改变大小或页面滚动时重新量，暂停时照样量。
- 每秒至多 30 帧；循环只写画布像素，不引起内容层的布局或重绘。
- 标签页隐藏、窗口失焦、视野里有流式文字、减少动效、截图冻结、电量低都停在一帧；平台不报告电量时手机默认静止。
- 会话用固定的阅读区避让正文，正文增长和跟随滚动时避让范围不变。
- 偏好（关、轻、标准）与密度（标准、紧凑，根上的 `data-density`）只存在这台设备。紧凑时触屏行仍至少 44px。

## 布局

**对话与看板。** 窗口标题行最右端是「对话 | 看板」开关（[ViewSwitch.tsx](../apps/web/src/shell/ViewSwitch.tsx)），手机在会话列表顶上；快捷键 ⌥⌘L（浏览器 Alt Shift L）与命令面板也切换。

- 偏好只存在本设备 `latch.preferences` 的 `workView`（`chat`、`board`），默认对话；存过旧顶栏布局的设备打开即在看板，下一次写入偏好时旧键消失。不写到 Host。
- 对话是侧栏、主区、右侧面板与底部终端。看板是独立的整面：盖住标题行与状态栏之间的整块，没有会话侧栏、底部输入框、右侧面板与终端；标题行放电脑与侧栏底部的设置、额度与用量、检查更新。
- 看板时对话保持挂载，隐藏且 `inert`：阅读位置、草稿、终端进程与右侧面板的页签不丢。只有起始页的新会话输入框不渲染，看板的「新建」用唯一的那一个，两处共用同一份新会话草稿。
- 打开会话、我的 Agent、应用或设置都回到对话；侧栏、面板、终端与输入框的快捷键在看板时不起作用。
- 开关里「看板」一段在对话时带等你处理的计数（琥珀，不为 0 才出现）。
- 切换时窗口整体淡入淡出（`crossFade` 的 `viewSwitch`）；安全界面已显示、减少动效或浏览器不支持视图过渡时直接切换。

**起始页。** 对话里没有打开会话时，主区是居中的输入框（[AppShell.tsx](../apps/web/src/shell/AppShell.tsx)），盖在当前会话之上；阅读的会话（`selectedId`）与编辑的目标（`inputTarget`）分开，仍只有一个 `useSubmission`。

- 「新会话」与 ⌘N 就是回到起始页并聚焦输入框：没有单独的新会话页。项目、文件夹或工作树、Harness、模型、思考、权限、首次引导、离线与未确认送达的提交都在这一个输入框上。
- 没选项目时可以直接发送，在 Host 的默认文件夹开始。
- 输入框下一行计数：等你处理 · 进行中 · 可交付，只写不为 0 的项，琥珀只给等你处理；全为 0 时位置保留，输入框不动。数的是 Host 的组（`board.group`）里看板上的卡，与空间无关。点一项切到看板并把那一组带到眼前。
- 被盖住的会话保持挂载：文件标签、原草稿、附件与阅读位置不变，在侧栏里仍是当前行。
- 起始页是真实的去处：从设置等页面返回、重新载入标签页都回到它（按设备记在 `sessionStorage`）。
- 晚到的发送回执不能把人从设置、Agent 页面或看板带走。

**断点。** 定义在 [breakpoints.ts](../apps/web/src/breakpoints.ts)（768、1024、1280），CSS 媒体查询用相同数值。

| 宽度 | 结构 |
| --- | --- |
| ≥1024 桌面 | 可调宽、可收起的项目侧栏加工作画布。右侧面板放得下时并排 |
| 768–1023 平板 | 图标轨加可打开的会话抽屉。右侧面板放得下时并排（对话留 440px），否则只在人明确打开时覆盖对话；设置覆盖工作台 |
| <768 手机 | 一页叠一页，没有并排的栏；选择器、菜单与弹层换成底部面板；控件至少 44px，安全区取真实 `env()` |

**区域划分。** 窗口是一个平面，没有浮起的主卡片，也没有卡中卡（[work-surface.css](../apps/web/src/styles/work-surface.css)）。

- 导航（侧栏或图标轨、状态栏）在地面 `--sidebar`；工作（主区及其标题行、右侧面板、底部终端）在画布 `--canvas`。只有这两种底色。
- 区域之间只有一条 `--line` 细线，在 T 字处相接：侧栏的右边、右侧面板的左边（从它的页签行到状态栏）、终端的上边（左接侧栏，右接右侧面板）、状态栏的上边。终端的左边就是主区的左边。
- 圆角与阴影只给真正浮在页面上的东西：浮层、输入框、内容里的卡片，以及窄屏时盖在对话上的右侧面板。我的 Agent 与应用的页面按同样的规则划分。

**窗口控件。** 面板开关（侧栏、底部终端、右侧面板，提示里印着各自的快捷键）、一条短竖线与「对话 | 看板」开关是一组，在窗口标题行的最右端，从不进入面板的页签行。开关只画一个，切换时不重挂载。

**被盖住的内容。** 被抽屉、推入的页面、设置或另一空间的页面盖住的列设为 `inert`，不接会话快捷键，保持挂载。被设置或我的 Agent 的页面盖住的会话整块透明，受保护的审批卡不会透到页面上。抽屉、对话框与底部面板捕获焦点，关闭后还给打开它的控件。

**标题行与页头。** [TitleBar.tsx](../apps/web/src/shell/TitleBar.tsx)；看板时它只有品牌、电脑、设置、额度与用量与检查更新。

- 桌面端的红绿灯与顶行在同一条线上（`main.cjs` 的 `LIGHTS_LINE`，页面的 `--lights-line`、`--lights-end`）。页头可拖动窗口，控件、弹层和安全界面除外。
- 只有连接本机 socket 的桌面端把电脑称作「这台 Mac」；回环上的浏览器按远程设备显示电脑名。
- 会话的页头（[ConversationHeader.tsx](../apps/web/src/shell/ConversationHeader.tsx)）写标题、项目、分支、电脑与 Host 报告的状态。断线时不画实时进行中；改动的增删数只在读到后出现。
- 标题按钮、页头菜单、侧栏行的菜单与手机上按住一行打开的是同一份会话菜单（`sessionMenuSections`）。运行或等你处理时，「清空上下文」与「删除」留在原处停用并写原因。
- Host 给出会话的组（`TaskSummary.board`）且设备能发起会话时，菜单在第一组后多「标签…」与「优先级」（高、中、低，当前的带对勾，没设是中）。看板卡片的菜单用同一份 `boardMarkSections`；标签在对话框里编辑（[SessionTagsDialog.tsx](../apps/web/src/components/SessionTagsDialog.tsx)），侧栏行不画标签与优先级。
- 页头只写一个「来自 …」（[sessionSource.ts](../apps/web/src/sessionSource.ts)）：交接来源，否则分叉来源，否则定时任务，再否则插件页面。来源会话在列表里、定时任务这台设备拿得到时是链接。交接来源与待交回见 [HANDOFFS.md](HANDOFFS.md#界面)。
- 失败的会话真正显示在主区时（对话可见：不是悬停或预读，不在起始页、设置、应用页面或看板之下，标签页可见），页面向 Host 记一次「打开过」（`attend`，每次结算一次，失败的下次打开或重连再发），它离开等你处理，红色「失败」留在行与卡上。

**两个空间。** Code 与我的 Agent 是两个空间，开关不是列表筛选；另一空间有待处理时带琥珀点。应用与设置是共用目的地，按 Host 能力与设备权限决定是否出现（[routes.ts](../apps/web/src/shell/routes.ts)）。切换保留会话、阅读位置、草稿与面板。我的 Agent 的空间不出现 Harness 与模型（只在创建与资料的设置里）；布局与组件见 [CUSTOM-AGENTS.md](CUSTOM-AGENTS.md#界面)，应用见 [APP-PAGES.md](APP-PAGES.md#壳层)。

**侧栏底部。** 两个空间共用一行图标（[SpaceNav.tsx](../apps/web/src/shell/SpaceNav.tsx) 的 `NavFoot`）：左边设置、额度与用量、应用，名称与快捷键在提示框里，连不上时设置带琥珀或红点；右端「检查更新」。侧栏收起时与看板时标题行放设置、额度与用量与检查更新；图轨与手机页头（375 以上）放同一个检查更新。
「检查更新」（[UpdateCheck.tsx](../apps/web/src/shell/UpdateCheck.tsx)）比较本页、Host 此刻提供的页面（`build.json`）与 Host 启动时的构建，桌面端另问应用自己的更新器；检查中转圈，有可做的带琥珀点，点开按原有规则给「重新载入」「重启 Latch」或通向设置 › 关于；没有更新源的构建只检查这台 Mac 上的构建（[UPDATES.md](UPDATES.md)）。

**手机的页面栈。** [PhoneSessionList.tsx](../apps/web/src/components/PhoneSessionList.tsx)。

- Code 的会话列表是根页，底栏的 Code 始终回到它；列表顶上是「对话 | 看板」开关。「新建会话」推入起始页：输入框贴底，计数行在它上面，页头有「返回会话列表」。
- 打开的会话返回列表。冷启动进列表，重新载入恢复原会话或起始页。看板盖住列表，底栏仍在。
- 推入的页面盖住的页设为 `inert`，焦点进入返回按钮；返回先经过未保存文件的离开确认，取消时留在原页。
- 推入的每一页与每个底部面板在浏览器历史里占一条（地址不变，[backStack.ts](../apps/web/src/hooks/backStack.ts)），平台的返回关闭最上面一层。
- 按住一行（或右键、上下文菜单键）打开会话菜单，这次松手不打开会话。
- 会话行没有内容预览与文件数：Host 不提供。
- 不可修改的输入控件仍显示真实当前值与停用原因。
- 复核页一次只画一个文件，底栏只有一个蓝色主操作；发送结果未知时给「放弃这次发送」与「重试同一请求」。数据范围不是 `all` 的设备看到锁和去哪里开启。

**设置。** 设置是盖在工作台上的面板（[SettingsPage.tsx](../apps/web/src/settings/SettingsPage.tsx)）：原会话、阅读位置、面板和草稿留在底下，运行照常继续，背景不可操作；本机确认可以在设置上方打开。手机上分类列表是根层，沿用页面栈。Esc 先交给内部的菜单、对话框或输入法，再关闭最上一级。

**会话行的状态。** 状态词只说 Host 说过的（[sessions.ts](../apps/web/src/sessions.ts) 的 `rowStatus`），变化每秒最多一次。

侧栏与手机列表的「等你处理」一组读 Host 的组（`board.group === 'attention'`），窗口标题、标题行与底栏的计数、空间开关的琥珀点同样读它。桌面端的 Dock 徽标与系统通知仍只数正在等你的审批、提问与卡住（`notifications.cjs`）。

| 情况 | 状态 | 进「等你处理」 |
| --- | --- | --- |
| 审批或提问 | 琥珀盾牌加「等你处理」 | 是 |
| `live.silent` | 琥珀「没有动静」加时长，从 `lastEventAt` 算起；界面不因时间长自己下这个判断 | 是 |
| Harness 发来不认识的请求后再无动静 | 琥珀「等你处理」；Harness 一有动静回到运行中 | 是 |
| 运行中 | 转圈加活动种类与时钟；时钟从 `live.runStartedAt` 算起，不含等人的时间，没有这个字段时不写时间 | 否 |
| 停止中 | 「正在停止」，直到这次运行真正结算 | 否 |
| 结算后 | 「已停止」「已中断」是提示墨色；「已强制停止」与结果未知是琥珀，并写「N 条结果未知」 | 结果未知：是，已核对后离开 |
| 失败 | 红色「失败」 | 是，打开过后离开；红色「失败」留在行上 |
| 连接中断 | 运行与等待的行不转圈、不计时，写上次确认的时间；已结束的状态不变 | 不变 |

- 会话按工作目录所在的最深的已保存项目分组，其余归「无项目」；组按最近更新排序，组内置顶在前。上一个、下一个会话的快捷键按屏幕顺序走，跳过折叠的组。
- 行尾的归档与更多操作只改变显隐，标题的位置与宽度不变。未读按设备记录，不加粗。
- 没有官方标记的自定义 Harness 用中性图形与名字。权限模式变化不在行上画红，由会话自己说明。
- 其他电脑：在线的待处理项写来源电脑与等待种类；离线的每台一行中性色。全局计数只算在线项。
- 归档后可用 ⌘Z 撤销；输入框有焦点时 ⌘Z 归输入框。

**可调宽的列（1024px 起）。** 数值在 [panelLayout.ts](../apps/web/src/shell/panelLayout.ts)，宽度与开合按设备保存，从不发给 Host。

- 侧栏 220–400px，拖到 160px 以下收起，与标题行的收起按钮是同一个状态。对话画布（连同页头的标题）始终至少 440px（`CONVERSATION_MIN`）。
- 右侧面板 360px 到窗口的 70%；打开时从对话那边让出宽度，让到对话只剩 440px 时自己变窄，窄到 360px 仍放不下才换成盖在对话上的浮层。
- 分隔线就是调宽的把手：悬停与拖动时线变深，没有额外的把手图形。
- 收起与展开时格道滑动，内容保持原宽被裁切、不重新换行；收起后不可聚焦。
- 把手可聚焦：←/→ 一步 8px（Shift 32px），Home/End 到两端，Enter 收起或展开，双击复原。
- 窄屏的覆盖式面板只由人明确打开，拖宽也算明确打开；默认的概要栏不因窗口变窄自动变成覆盖面板。

**右侧面板与终端。** 概要、改动、文件、浏览器、终端、交付、已打开的文件与插件面板共用一个面板（[SessionPanels.tsx](../apps/web/src/components/SessionPanels.tsx)）。手机上它是推入的一页，对话在下面保持挂载并 `inert`。

- 右侧面板与底部终端是同一种停靠区：第一行是 40px 的页签行，下面一条细线；没有自己的关闭按钮，由标题行的开关与快捷键收起。焦点在右侧面板里时 Esc 也收起它（终端里的 Esc 归 shell）。用键盘打开时焦点进入页签行，收起后回到原处。
- 面板把对话压到 600px 以下时，页头的「改动」收进 ⋯（快捷键不变），页头保持两行：标题一行，元信息与动作一行。
- 页签带图标与文字；放不下时末尾的页签收进一个「+N」菜单，当前页签始终留在行里（`fitTabs`），不会只剩图标。
- 概要按区块排：这次改动、检查、交付。每块是小标题加同一种行：图标、对象、状态（图形加短词）、时间、至多一个动作。读不到时是一行琥珀图标的「读不到…」，原文在悬停里，断线时写「上次 HH:MM」；运行中的检查在断线后转圈停住。空的区块不出现。

- 页签行只放打开了的页签，末尾的「+」（⌥⌘T，浏览器 Alt Shift T）列出这台设备在这个会话里真能打开的东西，各带字母键：浏览器 B、设备 V、终端 T、文件 F、改动 D、交付 P、概要 O，再是插件面板；不能用的不出现，不置灰（[panelTabs.ts](../apps/web/src/panel/panelTabs.ts)）。手机上它是底部面板。
- 概要、改动、文件、交付与每个插件面板只开一个，再选只是切过去；浏览器与终端各是一个页签，再选在其中新开一页或一个终端。每个页签都能关；全关后面板显示同一组选择（图标、名字、字母键），不写句子。没整理过的会话从概要开始。打开的页签与当前页签按会话、按设备记在浏览器里。页签不能拖动排序（页签原语尚不支持）。
- 浏览器只在这台 Mac 的桌面端、有项目的会话里出现（[PREVIEW-BROWSER.md](./PREVIEW-BROWSER.md#界面)）。设备只在这台 Mac 的桌面端、能用终端的设备上出现，画面不可点（[DEVICE-PREVIEW.md](./DEVICE-PREVIEW.md#面板)）。
- 已打开的文件最多 6 个标签；满了以后新文档留在这一轮的文件卡片上。
- 底部终端只在这台 Mac 上有终端能力时出现；折叠保留同一个终端，手机与远程浏览器没有入口（[TERMINAL.md](TERMINAL.md)）。
- 终端分屏：窗格之间一条 `--line` 细线即把手；分屏后每个窗格有 24px 的头（名字、结束状态、×），聚焦窗格的名字是墨色、顶边 2px `--line-strong`，不用主色；窄到放不下两个 40 列时逐个显示为页签（[TERMINAL.md](TERMINAL.md#界面)）。

## 界面原语

原语在 `@latch/ui`（[index.ts](../packages/ui/src/index.ts)）：React 组件加它们在 ui 层的样式。页面从这里取控件，不各自画一份。类名以 `ui-` 开头，变体与尺寸写在 `data-variant`、`data-size`、`data-tone` 上，状态直接用 ARIA 属性（`aria-pressed`、`aria-checked`、`aria-expanded`、`aria-disabled`、`aria-busy`、`aria-invalid`），不另设状态类。页面负责内容、请求和布局。原语总览页 `packages/ui/test/gallery` 只供测试（[TESTING.md](TESTING.md#组件测试浏览器模式)）。

**交互约定。**

- 禁用用 `aria-disabled`，不用原生 `disabled`：控件仍能用键盘聚焦，提示框说明原因，点击与表单提交被拦下。
- 键盘焦点是 2px 的主色描边，画在元素边内，滚动容器裁不到它；实心的主按钮与销毁按钮画在边外。
- 成组的单选控件（分段、标签页、单选列表、磁贴选择）整组只有一个 Tab 停靠点，方向键移动并选中，Home/End 到首尾，跳过不可选的项。
- 浮层的打开、关闭与焦点见「浮层」。
- 对话框与底部面板里 Tab 只在其中循环；从里面再打开的一层，Escape 只关闭最上面这一层。
- 触屏没有悬停：只在提示框里的信息必须另有可达的位置（菜单里的短标签、`Hint`）。不用浏览器原生的 `title`。
- 选中不滑动：列表、分段与标签页的选中交叉淡化。
- 可关闭的页签（终端、文件、浏览器，`PanelTabs`）是「图形 · 名字 · ×」：前面的图形说内容，从不是关闭；× 在末尾自己的位置上，悬停、焦点在内或触屏选中时出现，中键、Delete 与右键菜单也关闭。

**图标与转圈。** 界面图标是 Latch 自己画的一套（`packages/ui/src/glyphs/`），其余长尾用 Lucide，都经同一个 `Icon` 画出。

- 只用 12、14、16、20、24 五个尺寸，线宽按屏幕像素定（`ICON_STROKE`）；其他尺寸类型检查失败。12px 时另画的图形在 `SMALL_GLYPHS`。
- 每个图形至多一处实心，落在意义上。实心版（`solid`）只给选中或当前项；选中不用蓝色。
- 不用模板化的「AI 产品」图画：机器人、大脑、星光、烧瓶、眼镜、望远镜由 lint 拒绝导入，含别名与深路径（`.oxlintrc.json`）。Agent 是 `AgentsGlyph`，模型是 `ModelGlyph`，Harness 是 `HarnessGlyph`。
- Harness 与模型的品牌标志原样使用，不重画。
- 静止的图标是提示墨色，悬停与激活时是正文墨色。工作行的种类图标带内容色板的色相；其余图标只在表示状态时带色相：失败是红，等你处理是琥珀盾牌，被选中的完全访问是琥珀色 `shield-alert`。
- 箭头各有一种意思：向右是进入下一层或展开，上下双箭头是原地选值，向下是下拉动作。
- 转圈（`Spinner`）只表示正在进行的事。原语里它随所在文字的颜色；页面在会话行、工作行与总览里把运行中的图形画成主色，字仍是墨色。页面上可见的转圈相位对齐，离开视野时暂停，减少动效时停在静帧。
- 尚未实现：转圈换成与「进行中」图形一致的带头的弧。

**选哪个原语。**

| 需要 | 原语 | 规则 |
| --- | --- | --- |
| 执行或创建的动作 | `Button` 主按钮 | 一个界面里唯一的蓝色；「保存」这类不执行操作的确认用次按钮 |
| 其他动作 | 次按钮、描边、幽灵、`ButtonLink` | 链接样式只用于跳到别的页面或位置；页面上的危险操作是红字描边，实心红只在确认对话框里 |
| 图标动作 | `IconButton` | 名称同时是它的提示框；切换的「开」与菜单打开时是悬停底，不用蓝；触屏上点按区是 44×44；`busy` 时图形换成转圈并标 `aria-busy`，仍能打开它的弹层 |
| 一个动作加同类动作 | `SplitButton` | 主动作停用时菜单仍可用 |
| 状态 | `StatusWord`、`StatusSlot`、`StatusGlyph` | 几个字加至多一个图形，颜色就是意思；没有胶囊与前导点 |
| 名字后的属性 | `Badge` | 默认、本机、内置、离线等；从不表示卡片或行的状态 |
| 数量 | `Count`、`Meter` | 计数不加底，超过 99 写 99+；计量是格子，调用方给数字，没有动画。尚未实现：计量的上限刻线与超出的一段 |
| 互斥的值里选一个 | `ValuePicker` | 只显示当前值；只有一个可能值时是不可点的文字；没有选择时用提示墨色，不用警示色 |
| 2–3 个对等的视图 | 分段控件 | 类型只允许 2 或 3 项 |
| 能立即开关的行 | `Switch`、`SwitchRow` | 被策略锁住时关闭并停用，前面一把锁，说明换成原因 |
| 说明里的细节 | `Hint` | 短标签常显，细节在 ⓘ 后 |
| 页面里的提示与横幅 | `InlineNotice` | 先写保留了什么，再写原因，最后给至多一个动作；错误是 `alert`，其余是 `status` |
| 发生在别处的事与失败 | Toast | 本页做的置顶、归档、删除成功不弹，列表行的变化就是反馈 |
| 展开与替换 | `Collapse`、`Swap`、`FoldHeader` | 高度只经网格行变化，展开物上方什么都不移动 |
| 附在输入框上等待的东西 | `DrawerStack`、`Drawer` | 审批、问题、队列、清空上下文、选项目继续；按钮到位后短时间不可按（页面的 `useArmed`） |
| Harness 与模型的身份 | `Tile`、`BrandTile` | 放品牌自己的标志文件，从不画字母 |
| 调整列宽 | `ResizeHandle` | 只报告宽度，由页面收紧、吸附并保存 |
| 模态 | `Modal`、对话框与底部面板 | 原生顶层；改动即时生效的面板不放「确定」 |

**按钮。**

- 尺寸只有四档：xs、sm（桌面默认）、md（对话框与面板的脚部）、lg（手机）。
- 每张卡、每个对话框脚部与面板头部最多两个可见按钮，次在前、主在最后，第三个动作进 ⋯ 菜单。
- 运行中的按钮宽度不缩，前导位换成转圈，标 `aria-busy`，不再接受点击；它不算禁用，主按钮运行中仍是蓝色。
- 放在警告或红色调容器（`data-tint`）里的次按钮换成描边的样子。
- 非审批控件可以把此刻生效的键画在按钮上（`keys`）：触屏不画，读屏名称只有文字，键进 `aria-keyshortcuts`。
- 按键（kbd）只出现在提示框、菜单项尾部、搜索框，以及此刻按了真会生效的按钮上。

**选值。**

- 选中即生效，不弹提示。不可选的值也能聚焦，下面一行带禁止图标的原因保持原色并被读出。
- 要验证的改动返回一个 Promise：等待期间前导位是转圈，取消验证时值不变。
- 程序请求打开选择器时，只响应可见且不在 `inert`、`hidden` 或 `aria-hidden` 区域内的触发器。
- 带 `risk` 的值（完全访问）在菜单里不带琥珀；只有被选中后触发器前才出现琥珀色 `shield-alert`。

**菜单。** 当前项是墨色对勾；危险项排在最后，前面一条分隔线，文字与图标是红色。尾部只放一样（元信息、徽标或按键）。读屏名称是它的标签加头部写的作用对象。

**右键菜单。** 有「…」或悬停才出现的动作的行，右键（在指针处）、触屏按住与上下文菜单键、⇧F10（在行下）打开同一份菜单（`Menu` 的 `context`），没有第二份动作列表；只有悬停图标的行把那些图标的动作放进菜单。文字保留浏览器自己的菜单：输入框、可编辑区域、链接、代码与选中的文字（`keepsNativeMenu`）；终端画面有自己的菜单（复制、加入对话、分屏、关闭）。安全界面（确认卡、配对、登记）的行没有自定义菜单；桌面端用同一个页面内菜单。

**浮层。** 页面上方的一切层都是 `@latch/ui` 的五种原语：Popover（锚定、非模态）、Menu（含选值与斜杠、@ 建议）、Dialog（模态）、Sheet（前三者在手机上的唯一形态）、Drawer（输入框上方的整卡）。规则是 tokens.css「Overlays」的一张表，由 `apps/web/test/styles.test.ts` 与 `packages/ui/test/tokens.test.ts` 执行：

| 种类 | 宽 | 圆角 | 阴影 | 进出 |
| --- | --- | --- | --- | --- |
| 提示框 | 至多 sm | `--tip-radius`（6） | `--sh-tip` | `--m-enter` |
| Popover、Menu、建议、Toast | xs 240 · sm 320 · md 400；模型面板 lg 560 | `--layer-radius`（12） | `--sh-pop` | `--m-enter` |
| Drawer | 与输入框同宽 | `--modal-radius`（16） | `--sh-lift` | `--m-panel` |
| Dialog、Sheet | md 400 · lg 560 · xl 720 | `--modal-radius`（16） | `--sh-dialog` | `--m-sheet` |

- 宽只有 `--layer-*` 五档，组件只收档名（`LayerSize`），不收像素。顶层之外的层级只取 `--z-*`。
- 只靠点击或键盘打开，从不靠悬停（提示框除外）。Escape 与点外面关闭。打开时焦点进入第一个有意义的控件（不是关闭按钮），关闭后回到触发器；斜杠与 @ 建议是输入框的组合框弹出层，焦点留在输入框。
- 只有一个定位函数 `pinLayer`：换到放得下的一侧，沿边滑动并离可见窗口边缘 8px，仍放不下就限高在层内滚动；内容变化时尽量保持所在一侧与宽度。关闭的层在原处淡出。
- 只有最外层的模态有遮罩与模糊；从模态里再打开的模态（`data-stacked`）不再加遮罩。设置是整页，不算模态的那一层。
- 手机（<768px）上 Popover、Menu、选值与 Dialog 都换成同一个 Sheet，关闭只有标题左侧的「关闭」；斜杠与 @ 建议是贴在输入框上的非模态 Sheet，打字不中断。
- 减少动效只淡入淡出。安全界面（审批抽屉、配对、本机确认）出现与撤下都不位移、不淡化。
- 非模态的停靠层按 Popover 一类：`/btw` 侧问卡与窄屏时盖在对话上的右侧面板用层圆角与 `--sh-pop`，不加遮罩；侧问卡在 `--z-float`，手机上是整页（`--z-page`）。
- 手机上提问的对话框（确认、改名）在面板脚部留着明确的两个回答，次要的写「取消」或真实动词；左上的关闭只是放弃，从不等于确认。
- 状态栏与页头的小控件（电脑、项目、分支）点开就地的 Popover（手机为 Sheet）：一眼的状态与一两步常用操作，末行「设置」通向整页；只有真要整页的才直接跳转。
- 电脑弹层（[Computers.tsx](../apps/web/src/components/Computers.tsx) 的 `ComputerChip`）写本机名称、连接状态与连接方式，列出其他电脑（点开切换，右键「打开」）、设备、「连接新设备」与「设置」；配对、移除与信任证书只在设置里完成，弹层只通向它们。

**输入。** 要输入的地方是井（`--sunken`）。出错时环变红，下面一行红字写原因与改法，并作为读屏描述。手机上输入字号 16px。搜索框的 Escape 先清空。

**选中的三种画法。** 列表里的对象是 `--selected`；被勾选的控件是蓝色，菜单里的当前项是墨色对勾；视图、筛选与外观是中性的浮起块或悬停底。蓝色从不画在选中行上。

**行的状态。** 悬停、按下、焦点与选中只画在行自己的盒子里，不盖住相邻行或分隔线：卡片里用分隔线隔开的行铺到卡片内沿，由卡片裁圆角；自由列表（侧栏）是按列表内边距缩进的圆角块。悬停不改尺寸、内边距与边框，立即出现，只在能悬停的指针上（`@media (hover: hover)`），触屏只有按下。选中（`--selected`）胜过焦点环，焦点环胜过悬停，深浅两色都分得开。

**提示与反馈。**

- 提示框：禁用控件的原因、开关与分段的说明用它；提示文字同时是触发器的读屏描述。触屏上不出现。
- 本地操作成功用中性提示或只让值原位更新，不用绿色。
- 空状态是一句短名词、一行说明和最多一个按钮，左对齐，不放插画。
- 加载在对象旁放转圈和一行提示墨色的文字；骨架只做缓慢的明暗，不做扫光，占的盒子与内容相同。
- 工作区渲染出错时不整页空白：一张卡片说明并给「回到新会话」与「重新加载」，本机确认对话框不受影响；单条回复渲染出错时按纯文本显示。
- `CopyButton` 经 `writeClipboard` 复制；两种方式都失败才说「复制不可用」。
- `ProgressBar` 对读屏始终是不确定进度，因为它的位置不是测量值。

**磁贴的就绪度。** 就绪不加标记；不可用是灰度并变淡；启动或检测中带进度环；失败带红点。就绪度同时要在文字里写出。标志文件只经 `<img>` 或 CSS 遮罩使用，从不内联成标记。

**状态。** 只有正在进行的工作会动；等你处理、失败、已完成与时间从不动。

- 状态变化被页面亲眼看到时，新旧状态在同一格里交叉淡化，这是唯一的过渡。失败只换图标与文字，不抖动。
- 「亲眼看到」由 `LiveChanges` 的纪元判断：上一次渲染之后换了纪元的变化直接显示新值；没有纪元或减少动效时也直接显示。
- 外壳的纪元是 Host 状态重新同步的次数（[STREAMING.md](./STREAMING.md) 的 `resyncs`）；对话区的纪元另加打开的会话，切换会话时不播。
- 页面里的一次性过渡用 `useLiveChange`；只在有东西等待时才出现的计数用 `useLivePrevious` 记住出现前的值。
- `StatusSlot` 对读屏隐藏，行自己用一句隐藏文字说出状态与时间。
- `Shimmer` 是进行中的文字，离开视野时暂停，减少动效时静止。

**标记。** `DevMark` 是中性徽标「开发版」，整句在提示与读屏名称里，从不用红；`DemoMark` 是琥珀色徽标「演示模型」。Host 报告开发模式时「设置 › 关于」显示 `DevMark`。

## 组件

**品牌图标。** 每个 Harness 与模型服务显示它真实的品牌图标（`BrandTile`，[brands.ts](../apps/web/src/brands.ts)）。

- Harness 只用厂商官方仓库、官网或官方应用发布物中的资源；官方只提供位图时保留原图，不描摹。模型服务用已记录来源的品牌资源与 LobeHub Icons（MIT）。
- 文件原样复制到 `apps/web/src/assets/brands/`，以 `?no-inline` 导入。来源、许可证与商标声明写在 `apps/web/public/licenses/brands/`。适配器的开源许可证不授予厂商品牌许可。
- 没有图标的才用中性图形：自定义的 Agent 命令是 `HarnessGlyph`，插件是 `PluginsGlyph`；Latch 内置的 Harness 用应用图标。
- `apps/web/test/brands.test.ts` 要求每个预设都有图标，图标目录里正好是映射用到的文件，且每个 SVG 不含脚本、外来内容、事件属性、嵌入图片、样式表或指向文件外的引用。
- iOS 的资产目录使用同一份源文件。

**Agent 头像。** 我的 Agent 的头像是一对括号围着两只眼睛（[AgentAvatar.tsx](../apps/web/src/agents/AgentAvatar.tsx)，几何在 [avatarFace.ts](../apps/web/src/agents/avatarFace.ts)）：极简，有温度但不幼稚，没有嘴、腮红、高光和大眼睛。

- 挨着名字时是装饰（`aria-hidden`）；状态词始终写在旁边，头像只陪衬。不为放头像新增位置。
- 动作偶尔、平静，并只反映真实状态（空闲、运行、等你、失败、不可用）。小尺寸只眨眼或不动。
- 全页一个调度器，只驱动视口内的头像，页面隐藏时暂停，只动 `transform` 与 `opacity`。减少动效时完全不动，配件静态显示。
- 选择器里选了立即提交，只显示 Host 读回的值。

**我的 Agent。** 布局与规则见 [CUSTOM-AGENTS.md](CUSTOM-AGENTS.md#界面)。

- 创建先选 Harness。外部程序的「不隔离」说明始终可打开；看管程度按真实能力与读回显示，不按程序名字推断。
- 创建结果未知时保留原请求，提供重试与明确放弃；切换入口或刷新不视作成功或取消（[CUSTOM-AGENTS.md](CUSTOM-AGENTS.md#创建的待确认请求)）。
- 回复用头像和名字表示来源；模型和用量不占对话正文。
- 资料面板跨桌面、平板与手机是同一个实例：未保存的设置、当前页签和待确认的写入不复制、不丢失；撤权与换设备时卸载私有内容。
- 记忆与定时的提议、定时结果是对话里的卡，不是消息：没有头像与作者行，没有动画，一处只有一个蓝色主按钮。来自外部内容的提议带琥珀状态词。

**输入框上的四个控件。** Harness、模型、思考、权限平铺在输入框上（[Composer.tsx](../apps/web/src/composer/Composer.tsx)），每个只写值，在任何宽度都看得见，放不下就换行，不收进菜单。每个控件外层带 `data-composer-control`（`harness`、`model`、`thinking`、`permission`）。

「＋」在每种输入框里都是控件行的第一个，项目与分支等小片排在它后面或上一行；提示只写「添加文件」。控件行按输入框自己的宽度排（容器查询，不按窗口宽度）：一行放不下时项目与位置的小片在上一行，四个控件整枚换行、从不重叠，长名字截断，发送键在行末（`e2e/composer-row.e2e.ts`）。

- **Harness**（[ModelControl.tsx](../apps/web/src/composer/ModelControl.tsx)）：开始后不能换，菜单写明并给「分叉」与「新会话」；选模型从不换 Harness。最新一轮运行或等你处理时分叉不可按并写原因。
- **新会话默认**：「设为新会话默认」只在这台电脑上生效，其他设备看不到也收不回。它的 Harness 或模型用不了时默认不生效，也不替它换一个。
- **模型与思考是同一个面板**（[ModelPanel.tsx](../apps/web/src/composer/ModelPanel.tsx)，`PickerBoard`）：两个控件点开同一个固定大小的面板，焦点分别落在模型列表或思考列。左栏是来源（这个 Harness 自己的模型、每个能用的模型服务、有记录时的最近使用；只有一个来源时不画），中间是搜索与该来源的模型，前九行印着与「跳到第 N 个会话」同一组键（面板开着时归面板，只在桌面端印出），右栏是高亮模型的思考档位与 Harness 报告的其他模型设置。在列表里移动只换右栏，不改尺寸；选有档位的模型后焦点进右栏，选档位即关闭。手机上来源与档位各是一行。
- **模型**：只写模型。Harness 还没报告的模型写「默认模型」。能经 Latch 转发的服务组名注明「经 Latch」；有一轮没经过 Latch 时用琥珀色写明。用不了的服务折成一行，展开后每个写原因（[MODEL-CONFIGURATION.md](./MODEL-CONFIGURATION.md)）。
- **服务的健康**：只在不正常时出现，状态点加状态词。会自己过去的（变慢、额度用完、请求过多）是琥珀，真实失败（出错中、密钥无效）是红。由备选服务回答的一轮带中性「备选」徽标，它不是警告。
- **思考**（[ThinkingControl.tsx](../apps/web/src/composer/ThinkingControl.tsx)）：只列 Harness 或模型声明的档位，Latch 不替没声明的模型编档位；没有值时写「默认」，仍能点开。
- **权限**：始终显示、始终能点开。开始前来自 `HarnessInfo.permission`，开始后列 Harness 报告的模式（[HARNESSES.md](./HARNESSES.md#权限菜单)）。
  - 两到五个 Latch 认得的模式是一行图标分段（`ModeStrip`），由紧到宽；下面固定高度地写选中或预览中那一档的名字与它自己的一句说明，这是菜单不写说明的唯一例外。方向键与悬停只预览，Enter 或点按才选。模式更多、只有一档或 Latch 不认得时是单选列表。
  - 只有「不再询问」的标题、说明与图标是琥珀色（分段只在选中或预览时）；执行前不询问与读不回模式也是琥珀。
  - 任何能发起会话的设备都能直接选任何一档，不弹确认；Latch 不替人选更宽的一档。
  - Latch 只核对选的是哪一项、不隔离 Harness，这句话在菜单脚部的 `Hint` 里。限制只写在菜单里，输入框下面没有长句。
- **第一次用**：没有记录且可用 Harness 不止一个时询问，什么都不预选；不替人选完全访问的 Harness，也不用 Host 的默认代替询问。
- **分叉的草稿**借用来源的 Harness、项目、模型、思考与权限档，只对这份草稿有效；权限用同一档或更严的最宽一档，对应不上的逐条写明。
- 菜单里 Latch 自己的句子在别的设备上把「这台 Mac」换成电脑名（`computerName`），Harness 自己的说法照抄。
- 新会话从哪里开始就预选哪里的项目；选择按设备记忆，并按 Host 当前目录修正。

**模型的判断。** Harness 自己的模型审阅一次请求时，行上写的是模型的判断（放行、拦下、没有判断），不是人的批准，不用决定记录的写法；拦下不算失败，不用红色，没有「重试」。没有问人就运行的调用写「没有问你」。是谁决定的在展开的行里，整句在 ⓘ 后，不放在只有悬停才看得到的提示里。

**接入已有会话。** 入口只在项目里有能列出已有会话的 Harness 时出现；设备看不到私有会话时是同一行的上锁提示（[HistoryImport.tsx](../apps/web/src/history/HistoryImport.tsx)，机制见 [HARNESSES.md](HARNESSES.md#接入已有会话)）。

- 预览只读，工具输出不显示。会话正在别处使用时只能「再看一次」。项目其他文件夹里的会话只写数量与「尚未支持」。
- 「按文字重建，不是原样恢复」用琥珀色写明；重建的会话在发出第一条消息前写明重建的文字会发给哪个模型服务。
- 没有答复时写「结果未确认」并可重试；被拒绝时红字写原因。
- 原样接入的会话被 Harness 弄丢（`harness-session-lost`）时给「按文字重建」与「在新会话中继续」；重建后原会话只能查看。

**连接与版本的横幅。** 连接中断或离线时消息区顶部有一行琥珀色提示，右侧「重试」，没有第二句。

- 标题按事实写：请求没有应答、Host 以 5xx 应答、浏览器报告没有网络各不相同；Host 宣布过原因（休眠、重启、更新、停止）时写这个原因与开始时间。
- 桌面端的 Host 反复崩溃后停止自动重启，或 Host 没有响应时，这行是红色。
- Host 早于页面的构建时是一条琥珀提示（[build.ts](../apps/web/src/core/build.ts)）；只有那台 Mac 的桌面窗口给「重启 Latch」。
- 页头的连接状态只在不正常时出现；恢复并同步后才算已连接。

**对话与回合。** 对话按回合排列：一个回合是用户的一条消息和回答它的一切（[Transcript.tsx](../apps/web/src/components/Transcript.tsx)，推导在 [conversation.ts](../apps/web/src/conversation.ts)）。

- 只有用户消息有气泡；气泡里闭合的代码围栏（如行级反馈引用的行）画成代码块，未闭合的照原样显示。回合以作者行开始：Harness 标记、名字与模型。服务说回答的模型与选的不同时写服务说的，旁边用中性字写选的是哪个。
- 只在悬停或聚焦时出现的东西盖在回合下方的间隙里，不预留空间；触屏上最新一条常显。
- 到达的动效只给页面亲眼看着到达的消息；流进块里的文字不动。
- 「从这里编辑」在这条消息之前分叉，文字进入输入框；第一轮没有。
- 撤销之后带给 Harness 的说明不进气泡，在气泡上方另写一行（[CHANGES.md](CHANGES.md#撤销与丢弃)）。

**工作行。** 思考与每次工具调用是作者行下的一行（[ToolCard.tsx](../apps/web/src/components/ToolCard.tsx)）。行与块、分组、显示档位见 [STREAMING.md](STREAMING.md#工作过程的行)。

- 行首是 16px 的种类图标：读取、搜索、编辑、命令、网页、子 Agent 各有图形与色相。工作行在答案左边缘内 12px 的细线上；行展开的内容从行的文字处开始（手机上从行首开始），不另加缩进或字段名列。
- 行写动词与对象。读不出对象时写工具自己的标题，都没有时写工具的原名，不猜；Latch 不从命令文字推断它是读取还是搜索。
- 命令按 shell 着色（程序、开关、字符串、路径、变量、操作符）。展开后在一个凹陷面上：与项目不同的文件夹、`$` 与命令（只在行上截断或多行时，否则不重复）、输出（保留终端颜色，在空格与路径分隔处换行，超过 12 行收起）、结束状态；外壳的名字按下复制报告的原样。
- Mermaid 图用 `base` 主题，节点、线与字取当前主题的令牌（`diagramTheme.ts`），换主题时重画。
- 状态是图形加短词：运行中是主色的转圈，失败是红色，完成的行没有图形。中断与结果未知是琥珀色的提醒，不写成失败，不用红色。
- 审批的决定与时间常驻在行上。
- 失败的行下写一行原因：第一行写着错误的，没有时写第一行。「重试」只出现在这一轮最后失败的地方。
- 文件编辑的预览用 `DiffView` 的 `compact` 模式，行数上限是 `COMPACT_CHANGED` 与 `COMPACT_NEW_FILE`。
- 子 Agent 也是一行工作，状态只来自它自己的报告（[STREAMING.md](STREAMING.md#子-agent)）；只有能单独停止的有「停止」。
- 计划是最新一轮作者行下的一行；会话停下后，进行中的那一步读作未完成。

**折叠的工作。** 回合正常结束后工作收成一行（`workFolds`）。

- 只收工作行。工具之间的正文、答案、问题和它的回答从不折叠。
- 折进去的行有失败或被拒绝时，这一行写出来。
- 失败、停止、中断的回合，以及结束时没有一句话的回合，工作保持展开。

**回合状态行。** 运行中的回合下方的一行（[StatusLine.tsx](../apps/web/src/conversation/StatusLine.tsx)）只说页头没说的：Agent 正在启动，以及运行沉默之后的询问（[STREAMING.md](STREAMING.md#运行的真实状态)）。

- 沉默的询问是琥珀色，带「继续等」与「停止」。
- 连接中断时这一行不出现：横幅说连接，会话行写上次确认的时间。
- 运行不是以普通回答结束时，回合下留一行：进程退出是红色，强制停止与中断是琥珀色，并列出结果未知的命令。
- Host 因结果未知把会话放在等你处理时，这一行有次要按钮「已核对」（能发起会话的设备）：按下后忙到 Host 答复，结果未知就原样重发；之后这一行写「已核对」。各请求的核对与放弃不变。
- 失败的系统消息就是原因（已脱敏），旁边只给一个下一步（[failureAction.ts](../apps/web/src/conversation/failureAction.ts)）。

**回合卡片。** 结束的回合有文件变化时带一张卡（[TurnCards.tsx](../apps/web/src/conversation/TurnCards.tsx)）。

- 数字来自 Host 这一轮的记录。回合与记录按时间匹配，有歧义时不匹配，因为撤销本轮只作用于匹配到的那一轮；没有记录的卡没有撤销。
- 能否撤销与原因和「改动」页签的范围行是同一个函数、同一句话（`turnUndo`）。只能查看的设备或会话，卡片不给撤销。
- 有文件恢复不了时先在卡片里列出，确认后才执行。
- 撤销或恢复没有得到答复时写「结果未知」，重试用原 `requestId`。记录不完整时用琥珀字写明，不隐藏。

**回合脚部。** [TurnFooter.tsx](../apps/web/src/components/TurnFooter.tsx)。

- 时间、用时与令牌只写 Host 记录了的（[STREAMING.md](STREAMING.md#时间与用量)）。
- 「重试」只在最新一轮；这一轮可能已经改过东西时，先说明会重复什么（`resendWarning`）。
- 生成中的回合只能复制当前的原始回复；事实、「重试」与分叉等回合结束才显示。

**两轮之间。** 会话本身在两轮之间变了时（清空了上下文，或模型、思考深度变化），后一轮的气泡上方画一条带字的细线，只写变了的那一项；值来自 Host 的记录，没有记录的不画。

- 清空上下文在发送之前只是本设备的一个选择（[STREAMING.md](STREAMING.md#清空上下文)）：输入框上方写明并可撤销；运行中不可选并写出原因，Harness 不支持时入口不出现。
- 带 `idleOnly` 的 Harness 命令在运行中是斜杠菜单里的禁用行。

**回到最新。** 位置与跟随规则见 [STREAMING.md](STREAMING.md#阅读位置)。有请求或问题等你、而它的卡片不在视野里时，同一个位置变成琥珀字的「等你处理」，点它滚到那张卡片。

**输入框。**

- 发送是中性的墨色键：一屏唯一的蓝色主动作留给等你的那个决定。
- 没有内容时发送键仍可聚焦（`aria-disabled`），提示框写出原因。
- 停止不是风险操作，停止键不变红；停止进行中它不可按。
- 停止的结果未知时，输入框顶部的运行条写「尚未确认 · 重试」，这是唯一说它的地方：结果未知不是失败，不出红色提示。
- 等待提问时发送的位置是停止键，写了回答才换成发送。
- 只能查看或不再接受输入的会话，输入框换成锁与原因；运行条与停止键保留。
- 模型或思考的切换从下一条消息起生效，触发器写明，菜单里可撤销。
- 上方的卡与输入框相接成一个物体；卡本身的颜色与内容不因此改变。
- 桌面默认 Enter 发送、Shift+Enter 换行（「设置 › 通用」可改）；触屏 Enter 换行；⌘/Ctrl+Enter 总是发送；输入法组字时不发送。
- 只有新会话的草稿有状态行（[ComposerStatus.tsx](../apps/web/src/composer/ComposerStatus.tsx)）：项目名（不写路径）、分支与模型走哪条路。

**会话用量。** 打开的会话在输入框下有一行固定高度的用量（[VitalsStrip.tsx](../apps/web/src/composer/VitalsStrip.tsx)、[vitals.ts](../apps/web/src/composer/vitals.ts)）：轮数与工具步数、运行中一轮的 tok/s（`TurnStats.stream`：只写文字与推理的模型调用的输出 tokens ÷ Harness 自己计的流出时间；目前只有 Codex 报告）、会话 tokens 与缓存命中（缓存读取 ÷ 输入）、上下文环与百分比（80% 起琥珀）。每项只在有来源时出现，没有任何一项时也占住高度；悬停给分项，点 tokens 打开「额度与用量」。手机上留 tokens 与上下文，轮数收进点按。费用与用时在项目弹层，注明由谁报告（[sessionTotals.ts](../apps/web/src/composer/sessionTotals.ts)）。

**额度与用量。** 一个界面、一套组件、一套词（[apps/web/src/usage/](../apps/web/src/usage)）。来源见 [HARNESSES.md](HARNESSES.md#额度) 与 [MODEL-GATEWAY.md](MODEL-GATEWAY.md#用量花费与预算)。

- **限额窗口**（`LimitWindow`）是唯一的画法，Harness 的窗口与每月预算共用：名字、「已用 N%」、铺满容器的连续条、重置时间。80%（`QUOTA_NEAR_PERCENT`）起条与数字一起变琥珀，到上限一起变红；没有数字的窗口写「将用尽」「已用尽」，不画条；还没开始的窗口不写会走的重置时间。
- **输入框的小片**排在各控件最后、发送之前，来去不挪动别的控件；手机上钉在选项行的末端，始终可见。Harness 用自己的登录时写最紧的窗口（`leadingQuotaWindow`）的名字与「已用 N%」，或写明是额度（「5 小时额度将用尽」）；会话走 Latch 的模型服务时写那个服务的本月预算。没有数据就不画。
- **一个界面**（`UsageSurface`）：输入框小片（只看那个 Harness 或服务）、全局入口（侧栏底部，手机起始页的页头；看板在标题行设置旁，所有 Harness）、命令面板与 ⇧⌘U（浏览器 Alt Shift U，在入口的提示框里）都打开它；宽屏是固定大小的对话框，手机是底部面板，不是一级标签。只靠点击或按键打开。
- 「额度」视图逐个 Harness：套餐与遮住的账号、余额（只报告余额的 Harness 只有这一项，不画窗口，输入框也不显示，账户不能用时才显示「额度已用尽」）、各窗口；打开时 Host 在后台读缺失或过时的额度：读的时候显示上次的数字（悬停是读到的时间）或一个安静的读取标记，没有数字时只写原因（「未登录」「无 API 密钥」「读取失败 · 重试」），Claude Agent 写「只在对话中报告」，还没添加的预设写「未添加」；只能看的设备不触发读取，还没有数字时写「尚未报告额度」；Host 重启后显示上次的数字；程序不报告的列在末尾一行「不报告额度」。「用量」视图是 Latch 跑过的用量（经 Latch 服务的请求、自己登录的轮次与插件服务的轮次，可按来源只看一种；全部来源时一样东西一行，行里一条短条分出来源）：期间（24 小时、7、30、90 天）、合计（轮、请求、输入输出、缓存命中、估算花费，依据点按或悬停可见，从不称账单）、每日 tokens 堆叠柱（缓存读取、输入、输出；点一天列出那天的会话）、缓存命中折线（可只看一个 Harness）、一周 7×24 时段、来源与项目占比、同一模型在各 Harness 上每轮的 tokens、预算与按分组的明细。图表是 `@latch/ui` 的内联 SVG（`chart.tsx`），悬停或聚焦给精确数；没有用量时只写一行。加载时是与结果同形的骨架，数据到了不挪位置。
- 设置只放配置（单价、预算），不显示用量。

**设置的各分区。** 分区在 `SettingsPage.tsx` 的 `sections`；设备见「设备与权限」。

- 模型、Harness、MCP、项目与插件需要「管理此 Host」权限；没有该权限的设备看不到它们。
- 模型服务的状态来自打开页面时的模型列表请求（不消耗 tokens），不从是否存了密钥推断。缺密钥与地址未确认是琥珀色，拒绝密钥与连不上是红色。
- 单价、预算与用量见 [MODEL-CONFIGURATION.md](MODEL-CONFIGURATION.md#单价预算与用量)。
- Harness：找到了程序但还没有定义的预设只写「已找到」，不画成可用，不用绿色。Latch 不安装任何东西，只给安装命令与「重新检测」。
- 不隔离的说明出现在 Harness 列表、外部 Harness 的页与添加表单、关于页，文字只在 [securityCopy.ts](../apps/web/src/core/securityCopy.ts)。

**插件包界面。** 机制见 [PLUGIN-DEVELOPMENT.md](PLUGIN-DEVELOPMENT.md#应用内的自定义插件资产)。

- 编辑器与插件页都写「代码在哪里运行」，每部分一行短标签，整句在 ⓘ 里（`PLUGIN_REACH_COPY`）：界面面板在每台能看会话的设备上运行，工具和后台代码在这台 Mac 上运行，都不隔离；技能和静态面板只是文字。
- 编辑器按表单里正在输入的声明说；插件页说保存的声明与 Host 正在运行的能力的并集（`packageReach`）。
- 编辑器区分未保存、草稿、有未应用修改、已应用、已停用与真实的不可用原因。只有「应用」是蓝色主按钮。启用与导出只对已保存的状态操作。
- 丢失响应时保留编辑内容并提供「重试同一请求」，不创建第二份插件。

## 设备与权限

界面按设备的权限隐藏或停用操作，只是为了不展示做不到的事；每条规则都由 Host 再次执行。门控集中在 [permissions.ts](../apps/web/src/core/permissions.ts)，安全文案集中在 [securityCopy.ts](../apps/web/src/core/securityCopy.ts)。审批卡与错误文案统一说「运行 Latch 的电脑」。

**本机确认。** 只有 Host 的 `PRESENCE_ACTIONS` 里的操作要在这台 Mac 上确认：连接新设备与配对、为设备增加权限、首次使用自定义或本机模型服务地址、放宽出站策略、应用含代码的自定义插件、添加或放宽 MCP 服务器、手填或改过的 Harness 命令。预设 Harness 的原样命令与预设模型服务的 HTTPS 地址、开始会话、放宽权限模式、批准操作不弹窗。

- 按下后系统表单是唯一的窗口：发起的控件转圈，页面不重复表单里的句子；被取消或超时时一行原因留在原位。
- 系统窗口的句子是固定的，不随界面的叫法改。
- 页面读不到这台 Mac 有没有 Touch ID，所以只说「系统窗口」。
- 被完全访问会话挡住时，桌面端写明是哪个会话，并提供查看与停止；会话结束后重用仍有效的邀请。匿名的登记请求不返回会话信息。

**审批。** 审批在输入框上方的抽屉里决定（[ApprovalDrawer.tsx](../apps/web/src/composer/ApprovalDrawer.tsx)），会话记录里只留一行工具。卡带 `data-secure`。

- 卡是中性表面，琥珀只给标题前的一个点。标题就是要做的事和对象，不写「等你处理」。
- 工具 ID 与标题不同时总写出，因为标题可能是工具自己写的。
- 命令显示完整的里层命令，保留换行、不截断，下面写外壳报告的原样；很长时在自己的框里滚动，按钮始终够得着，并写明还有多少行。
- 只有普通的差异默认折叠在「查看改动」后。高风险、Agent 的询问、没有差异的调用与含隐藏字符的内容一开始就展开参数与原因。
- 高风险的原因单独一行红字，后面是 Host 的原句；高风险不能设为始终允许。
- 外部 Harness 的询问写明「拒绝只会转达，拦不住它」；隐藏字符、原内容未知与这台设备不能允许的原因也写在卡上。
- 这台设备能按哪些按钮由风险等级与设备权限决定（`approvalActions`）；缺少风险等级按 R2 处理。
- 按钮顺序是「更多」·「拒绝」·「允许」；其余选择与「停止这一轮」在「更多」里。
- 按钮到位 320ms 后才接受按压；重新显示的卡（切换视图、从别的页面回来）重新等待。
- Enter 不决定。Esc 拒绝一次；输入框有文字时不拒绝，打开的浮层先处理 Esc。
- ⌘/Ctrl+Enter 只在焦点在卡里时允许 Latch 内置普通请求的「允许一次」，从不允许高风险请求与 Agent 的询问。
- 审批按钮不画数字或快捷键；有效的键经 `aria-keyshortcuts` 提供给辅助技术。
- 请求到达后在输入框写的文字随拒绝交给模型（[useRejectionNote.ts](../apps/web/src/composer/useRejectionNote.ts)）；拒绝没有生效时文字回到输入框。Agent 的询问带不了文字，文字留作下一条消息。
- 请求到达之前就写着的文字仍是下一条消息，不当作回答（[useEarlierDraft.ts](../apps/web/src/composer/useEarlierDraft.ts)）。
- 文字发不出去（过长、含隐藏字符）时「拒绝」不受影响，直接拒绝并留下文字。
- 结果未知时给「重试」，沿用同一 `requestId`。
- 决定记录写的是人的决定，不是调用有没有执行：界面只把没有开始就结束的调用读作被拒绝；Agent 在审批未通过时仍报告执行了调用的，行下另有一行说明（`DECISION_COPY`）。

**提问与排队。** Agent 的提问与排队的消息也在抽屉里；规则见「Agent 提问卡」与「后续输入托盘」。尚未实现：调整排队顺序、立即发送并打断（需要 Host 接口）。

**差异。** [DiffView.tsx](../apps/web/src/components/DiffView.tsx) 有三种模式：`hunks`（默认，带 @@ 头、符号与两列行号）、`full`（审阅）、`compact`（对话里的预览）。

- 审批提案必须用 `hunks` 完整呈现。
- Host 确认文件不存在时直接显示新增内容。文件存在但原文未能展示时保留琥珀色「原内容未显示」或「原内容未知」，说明可能覆盖已有内容，且不显示删除行数。
- 二进制文件不显示行数。完整路径保留在提示与读屏名称中。
- 尚未使用：`full` 模式与留给评论的 `gutter`、`annotation` 位置还没有页面使用。

**会话权限。** 只有完全访问会话在页头显示琥珀色的「完全访问」状态词；逐项询问是默认，不显示。新会话选择器里没被选中的完全访问 Harness 只带中性徽标。

输入框在这些情况换成带锁的只读说明，运行条与停止键保留：Agent 定义变化、项目中的 Agent 配置在开始后变化、会话创建于安全升级之前，以及无法确认 Harness 已进入预期的权限模式（琥珀色）。它们在这台设备的输入或选项修改被 Host 以对应错误码拒绝后出现。

**连接页。** 未登记或凭据失效的浏览器看到一张卡片（[EnrollmentPage.tsx](../apps/web/src/components/EnrollmentPage.tsx)）：一个主按钮，按下才弹出系统窗口。

- 页面上没有输入框、权限清单或倒计时。名称、可以做的事与能看到的内容在折叠的「连接详情」里；等待时再加校验码，它与 Mac 上等待中的那一行相同才是这台设备。
- 经二维码的手机没有校验码可比，它的核对是确认后的那一问。
- 链接允许管理这台 Mac 时（只在回环上生效），按钮上方用琥珀色写明并可拒绝；读不到回答时不显示这一行，也不申请。HTTPS 上的设备不申请。
- 这台 Host 从未登记过设备时，桌面端自己的第一次打开不需要确认。
- 本机确认不可用时，只有桌面端提供离线连接码的表单；浏览器与手机上主按钮停用，并说明要在运行 Latch 的电脑上确认。
- 没有链接时只写去哪里取；失效的链接当场说明；浏览器无法安全保存设备密钥时只显示一行红色说明。
- 撤销是红色；满 30 天、换地址、丢失密钥、浏览器没有保存凭据是琥珀色，各有一行说明。
- 设备名可以含表情；含换行、不可见字符或改变文字方向的字符时用红字说明并停用提交。
- 登记完成后第一次读取状态失败时，「重试」只重新读取状态，不会再登记一台设备。

**配对手机。** 「显示二维码」只打开配对表单（[PairingSheet.tsx](../apps/web/src/settings/devices/PairingSheet.tsx)）。

- 表单没有地址、端口、权限选择、倒计时或复制；二维码自动更换。
- 手机确认时二维码停住，写「在系统窗口中确认」或「正在连接…」。
- 确认之后只问手机上是否显示已连接，回答期间表单不能用 Esc 或遮罩关闭；答「没有」直接移除这台设备。
- 取消、超时、两台设备扫同一个码与其他网络的尝试各写一行。
- 没有网络或被完全访问的会话拦下时不显示二维码，恢复后自动出现。
- 尚未实现：防火墙提示与「发送到其他设备」，不显示。

**设备。** 「设置 › 设备」（`apps/web/src/settings/devices/`，判断在 [deviceRows.ts](../apps/web/src/settings/devices/deviceRows.ts)）。

- 正在看页面的桌面端就是这台 Mac，不列出；其他桌面端设备仍持有权限，所以列出并可移除。已移除的设备不列出，记录在审计里。
- Host 不报告其他设备的实时连接，「在线」只说正在看页面的这台。
- 三十天未验证的设备只能查看，写明去那台设备上验证。连接它的设备被移除后写明，并提供「恢复使用」（在 Mac 上经本机确认）。
- 移除不需要本机确认；对话框按设备类型说明之后要重新扫码或重新发链接，由它连接的设备会受影响时一并写明。
- 开关（「可以管理这台 Mac」「可以看项目文件」「也能看私有内容」）是安全界面（`data-secure`）。关闭在任何能管理的设备上立即生效、不要确认；开启只在 Mac 上经一次本机确认（`device.grant`），别处关着的开关锁住并写去哪台电脑开启。确认时开关下照抄 Host 的提醒。
- 「可以看项目文件」的标签写明「也能看含私有内容的会话」，不写成只看文件。手机与桌面端从一开始就看得到全部，不显示这个开关。
- 外部 Harness 的会话运行或等你处理时开启被 Host 拒绝，开关下列出这些会话并给「查看」「停止」。
- 「连接新设备」只在 macOS 桌面端的管理设备上，只列走得通的方式。给另一台电脑的链接只复制到剪贴板，由主进程申请，页面拿不到也不显示；链接与邀请码不在页面上出现。
- 自建中继的导入、验证与移除只在 Mac 上有管理权限的桌面端；页面只显示目标地址与状态，注册令牌不显示。
- 设备名中的隐藏字符按审批区的规则显示为 `\u{XXXX}`，包括确认与 Toast 里的名称。
- 尚未实现：「保持可连接」；没有 HTTPS 入口时的「另一台电脑」。

**模型服务。**

- 桌面端以外的设备不能输入或更换密钥（仍可移除）：字段换成一行原因与去处。
- 已保存的密钥注明只发往哪个源与路径；修改地址时提示会清空密钥。
- 预置服务商地址的密钥直接保存；自定义与本机地址在桌面端确认一次（地址、密钥与出站许可一次确认）。
- 已确认的地址在桌面端模型页列出（[ConfirmedAddresses.tsx](../apps/web/src/settings/ConfirmedAddresses.tsx)），写明哪些服务在用与它带来的出站许可。移除不要系统确认，因为只是收回；对话框说清后果。
- 没有桌面端时，在 Host 停止时从 `policy.json` 的 `confirmedAddresses` 移除，本机或局域网地址另从 `hostEgressAllow` 移除；改动写入审计。

**Harness 定义、登录与测试启动。**

- 每个外部 Harness 标注中性的 L3 与许可证徽标。未验证的定义带中性徽标并显示实际命令，不显示预设的说明。程序不在这台 Mac 上的定义列在「可以安装」。
- 「登录」一组只在 Harness 有登录方式、状态或退出时出现，只写 Harness 自己报告的状态；「已登录」只在 Harness 自己说已登录时写。测试启动读到不同的状态时这一组跟着变。
- 「在终端里登录」在 Latch 自己的终端里运行（[TERMINAL.md](TERMINAL.md#登录命令)），写明「你的账户，不是沙箱」。
- 「测试启动」不发送提示词，只检查启动握手。成功时写明登录状态与模型访问尚未验证；能力只说 Agent 声明了什么，不加成功徽标。结果未知时重试同一次请求。
- 适配器与程序的版本组合没有核对过时用琥珀提示，不阻止启动。

**旧版 Host。** 快照里没有 `host` 时按旧规则显示：普通的允许与拒绝（`approvalActions` 的 `legacy`），隐藏设备、邀请与本机确认的界面，并写 `LEGACY_HOST_TEXT`。

**审计回滚。** 审计记录被回滚时显示红色横幅，可核对或关闭。

## 流式与阅读

机制见 [STREAMING.md](./STREAMING.md)；这里是界面必须表现出的行为。

| 情况 | 界面行为 |
| --- | --- |
| 等待首段输出 | 写正在启动或运行中；不伪造思考内容或百分比 |
| 推理到达 | 思考行写用时，身体自动展开并跟随最新的推理 |
| 正文到达 | 在稳定身份的同一消息行内更新，新到的文字匀速露出，不逐字动画；完成后沿用该行 |
| 工具调度 | 工作行区分等待执行、等待确认、执行中、完成、失败、取消 |
| 审批 | 卡片说「等你处理」，回合里没有第二处说它；已运行时间停住 |
| 取消 | 请求中保留取消状态；超时写「尚未确认」并可重试同一请求，不会停止之后开始的一轮；部分回复保留 |
| 结束 | 状态行消失，事实进入回合脚部；正文不折叠 |
| 离线 | 保留已读内容；运行中的回合不再转圈或走时；「重试」只在横幅里一个 |
| 上翻阅读 | 流式输出不夺走位置；命令结束、思考收起与分组合并时锚点不动 |
| 定位历史 | 六轮起在对话旁显示刻度，可用键盘操作；触屏刻度有 44px 命中区 |
| 切换会话 | 阅读位置按会话保存；旧会话的异步结果不得写入当前会话；不播放消息到达的动效 |

- 对话正文的程序性滚动集中在 `useReadingPosition`；消息与工具行以 `data-message-id` 为锚点。
- 布局改变、代码展开、展开块的动画与视口变化不等于用户主动滚动。
- 带遮罩的滚动容器不做透明度动画，避免可见控件失去点击命中。
- 流式全文不设 `aria-live`，避免逐字播报。

**回复的渲染。**

- 三级：答案是正文墨色；工作行安静、按种类可扫读；证据（展开的输出）是等宽字、在自己的凹陷面上。
- 链接是蓝字、悬停加下划线；行内代码与文件标记是带底色的标记；粗体领句与标题 600；表格只有行间细线，表头加粗。

- 回复里的原始 HTML 不执行；文字不丢失，标签显示为文字或代码块。
- URL 只允许安全协议；只有网页与邮件地址是链接。图片从不加载，网页图片显示为链接。
- 代码中的不可见字符显示为 `\u{XXXX}` 标记并注明「含不可见字符」，复制内容保持原样。
- 「在终端里打开」是复制旁的终端图标：shell 代码块（回复与思考）、命令行的展开详情、安装与升级命令都有，只在这台 Mac 的桌面端出现；不能填入的命令图标变灰、原因在悬停里，填入后短暂显示「已填入」；「在终端里登录」用同一个图标，带文字，因为它会运行命令。
- 嵌套过深的回复按纯文本显示并说明。表格与代码在自身容器内滚动。
- 实际点击的网页或邮件链接由桌面主进程交默认应用打开；脚本触发的外链另需确认。

**路径标记。** 回复里指向文件的链接不是链接，是路径标记（[FileChip.tsx](../apps/web/src/components/FileChip.tsx)），点击从不让页面离开。

- 一行放不下时从文件夹部分省略，文件名始终完整；完整路径在提示里。
- 看起来像路径的行内代码，只有在回复结束后、Host 确认它是会话文件夹里的文件时才画成标记。
- 点击打开同一种菜单（手机上是底部面板）。不在 Latch 桌面端时只有「复制路径」，并写去哪里可以打开。
- 桌面端先问一次 Host，菜单只列 Host 允许的动作；不提供的动作不出现，原因写在菜单底部，文案来自 `securityCopy.ts`。
- 锁只用于 Latch 有意拒绝的情况（可能含密钥、Latch 的私有数据、不在会话的文件夹里、类型不放行、内容与扩展名不符）。
- 成功不提示；被拒绝或失败时菜单重新打开并写出原因。
- Host 支持内容服务时，单击改为打开文件标签（[DOCUMENT-PREVIEWS.md](DOCUMENT-PREVIEWS.md)）。

## 看板

看板是标题行与状态栏之间的整面（[apps/web/src/board/](../apps/web/src/board/)），只读 Host 摘要的 `board`：`board.card` 为真才是一张卡，列取 `board.group`，等你处理写 `board.reason`。网页不自己判定组，不从审批、交接或定时任务补出卡或计数；对这台设备不可读的私有会话不在快照里，也就不在任何计数里（`apps/web/test/board-model.test.ts`）。

- **列。** 等你处理、进行中、可交付、已结束，等宽，顺序固定，任何宽度都不藏组。按看板自己的宽度（容器查询）重排：n 列需要 n × 240 + (n − 1) × 12 + 32 px，四列从 1028px，以下 2 × 2，524px 以下换成一张列表。第二期的未开始是最前面的第五列，规则已写在 [work-board.css](../apps/web/src/styles/work-board.css)：五列从 1280px，776px 起 3 + 2，524px 起 2 + 2 + 1。每格自己滚动，栏头固定；两行时等高，每格至少 180px，放不下时整面纵向滚动。
- **组内顺序。** 优先级 高 → 中 → 低（没设即中），同级里等你处理按 Host 的原因顺序（审批、提问、结果未知、失败、不支持的请求、没有动静），其余新的在前。置顶只管侧栏。已结束只放最近 7 天，全部在「表」里。
- **卡。** 优先级记号（高实心点、低空心点，中不画）、标题、时间；Harness 图标、项目、分支或工作树，我的 Agent 的卡画它的头像；状态词；标签；「来自」（交接、分叉或定时任务，来源不在快照里就不画）。失败的运行打开过后离开等你处理，卡上的红色「失败」不变。可交付的计数只为该列最上面 12 张卡读（`workbench/delivery`，要能读项目文件），其余与读不了的设备只写「可交付」；几个会话共用一个目录时写「这个目录有 N 个文件未提交」，不说是谁改的。
- **决定。** 等你处理里第一张只等普通 R1 请求的卡，原地展开与对话同一个审批控制器；R2、Agent 自己提出的请求、提问与失败点进对话。
- **打开。** 点卡切到对话并打开那个会话；回到看板时它带主色细框并滚到可见。卡的「⋯」、右键、菜单键与按住打开同一个菜单：优先级（高、中、低）、标签…、重命名、归档、在对话中打开。
- **标签。** 自由文字，只用于筛选，不触发任何事：每个 1–24 个字、最多 8 个，像凭据的被 Host 拒绝；改动立即经 `PATCH /tasks/:id`，被拒时回到原值并报 Host 的原文。
- **筛选。** 项目、Harness、谁在做（Code、通用、每个 Agent；不告诉这台设备的 Agent 不出现）、标签，都从快照推出；同一维度内是「或」，不同维度是「与」，已选的以片显示。按设备记在浏览器里。栏头写未筛选的总数，有筛选时写「显示数 / 总数」。
- **表。** 一行一个会话，状态筛选 全部、四组与已归档；按组、优先级、时间排，点「更新时间」只按时间。行与卡同一个菜单。
- **窄宽与手机。** 一张列表，顶上状态筛选（默认等你处理，为 0 时进行中），其余筛选收在「筛选」里；行与卡同内容，审批不在行上处理。
- **新建。** 「新建」在对话框（手机为底部面板）里挂首页那一个新会话输入框，与对话起始页共用同一份草稿；Host 接下后对话框关闭，看板不切走，新卡带选中框；结果未知时对话框不关，用输入框自己的重试与放弃。
- **待办页。** 一条待办在看板整面里打开（[ItemPage.tsx](../apps/web/src/board/ItemPage.tsx)），没有侧栏：页头「← 看板」、标题（点了就地改）、完成或重新打开、「⋯」（删除待办，会话保留）；左边要求与会话，右边属性卡（状态即 Host 的 `board.group`、项目、建议的 Harness、标签与优先级可改、创建时间），窄于 720px 时属性卡在最上，手机是推入的一页。打开哪一条只记在本标签页的 `sessionStorage`（只存 ID），所以去对话再回来、重新载入都回到它；「← 看板」、Esc（没有菜单或对话框开着时）与浏览器后退回到板。
  - 要求在没有会话时可改，有了会话只读（Host 拒绝 `item-started`）。要求不在快照里，页面按 Host 的 `revision` 读 `GET /work/items/:id`；快照里没有这条待办（删了或这台设备读不到）时页面直接回到板。
  - 会话一行一个：Harness 图标、标题、Host 给它的状态（与卡同一个状态词）、分支、时间；点行切到对话打开它，回看板仍在这一页、那一行带主色框。成员只从 `items[].sessionIds` 读。行的「⋯」：在对话中打开、带过去、移出待办。
  - 「再开一个」（没有会话时是「开始」）在对话框里挂首页的新会话输入框，文字是要求、项目是待办的，其余是人自己的选择；发送走 `POST /work/items/:id/start`，带页面所示的修订（`PendingSubmission.itemId` 与 `itemRevision`，结果未知时原样重试，不会改成 `POST /tasks`）。修订过期时 409 `item-changed` 写在输入框里，页面重读后再按一次即可；会话开了但没能加入（`outside`）时它以「未加入」一行留在页上，点了打开。
  - 「带过去」把源会话最后一条已结束的回复（最多 8 000 字，按行截断）作为引用放进目标会话的草稿并打开它，不发送。「加入会话」列出不在任何待办里、未归档的 Code 会话。
  - 讨论与 @ 的位置留在会话之下（`thread`），之前不画。
- **会话一侧。** 属于待办的会话，页头项目旁写待办名，点了切到看板并打开待办页。会话菜单在标签与优先级后多一项：不在待办里时「加入待办…」（选一条未完成、未满的），在时「移出待办」；只给 Code 会话、能发起会话的设备。

## 工作台搜索与起步

### 决定卡

决定卡（[WorkbenchDecision.tsx](../apps/web/src/shell/WorkbenchDecision.tsx)）只指路，不做决定以外的事：执行与授权沿用原会话的审批或提问控制器、权限与 `requestId`，不建立第二套决定状态。我的 Agent 的总览用它，看板的卡也用它。

- 摘要写实际动作、来源和状态；材料区只放 Host 已授权的材料或失败说明。
- 只有展开的决定读取任务详情。审批与提问的材料带 `data-secure`，切换视图时不进页面快照。
- Host 仍在核对改动时，只低频重读视野内的等待条目；结束、断线、权限变动或离屏即停。

**草稿。** 切换会话保留原会话未发送的文字，回到同一会话才恢复；附件与文件引用不随切换携带。每台设备最多 20 份、合计 256,000 个字符（[sessionDrafts.ts](../apps/web/src/core/sessionDrafts.ts)）；含凭据的文字，以及数据范围不足的设备上的私有文字只留在内存；设备被移除或退出时立即清除。存储见 [STREAMING.md](STREAMING.md)。结果未知的提交复用原请求，不从草稿另发。

**搜索与归档。** 命中项按原会话与消息身份定位（[STREAMING.md](STREAMING.md#搜索定位与阅读标记)）；查询改变即取消旧请求。归档视图的批量恢复与删除部分失败时，失败项保持选中并写出原因（[ARCHITECTURE.md](ARCHITECTURE.md#会话搜索与批处理)）。

**命令面板**（`apps/web/src/palette/`）。

- 危险动作只从它自己的页面执行；缺少权限或 Host 能力的入口不列。
- 进行中、失败与结果不全都明说；只有 Host 答完才写没有结果。
- Esc 先清空输入，再退回上一层，最后关闭。回车打开看到的那一行，迟到的结果不换掉它；输入法组合期间不触发。
- 关闭面板或查找条后 500ms 内的 Esc 与按住不放的 Esc，不停止运行、不拒绝请求（[escapeGrace.ts](../apps/web/src/escapeGrace.ts)）。

**会话内查找。** 不改写消息，滚动只由阅读位置控制器写入。搜索覆盖未挂载的工具输出，只展开当前匹配所在的卡片。运行中新增的文字只更新计数，读者留在当前项。

**快捷键。** 只有一张表（[workbenchShortcuts.ts](../apps/web/src/workbenchShortcuts.ts)），只列已经实现的绑定。

- 浏览器的 Alt 组合在输入框里让给打字：它会打出字符或是死键时输入字符，否则才是快捷键。
- 打开输入框控件的快捷键只开菜单，不选值。
- 空输入框 ↑ 取回上一条用户消息；500ms 内连续两次 Esc 取消运行，单次不清草稿。

**第一次打开。** 没有准备页：有就绪的 Harness 时输入框立即可用；未安装、还没登录、需要升级就写在新会话的 Harness 卡片与输入框提示里（安装命令可复制或放进 Latch 的终端）。桌面通知的首次开启在主进程，页面不设询问条（[NOTIFICATIONS.md](NOTIFICATIONS.md)）。

**「Latch 不隔离」。** 外部 Harness 的第一行说明每台设备每个 Harness 只出现一次，之后在权限菜单的 ⓘ 里。

**模型选择器。**

- 最近的选择列在「最近使用」，不在其他分组重复；已移除的模型不出现。
- 模型列表开关只影响这台设备，隐藏不关闭模型服务；当前已选的模型保持可见。
- 「添加模型服务…」在弹层内打开与设置页共用的表单（[providerSetup.ts](../apps/web/src/core/providerSetup.ts)）；每条规则由 Host 再判。
- 有「管理」但不在这台 Mac 上的设备：原地面板不打开需要密钥的服务的表单，只说去哪台电脑，因为从这里开始的会话用不了它。

**项目。** 机制见 [ARCHITECTURE.md](ARCHITECTURE.md#会话与项目)。「不选项目」只写后果（Latch 内置只回复文字、不读写文件；其他 Harness 在一个新的空文件夹里开始）。不可用的项目保留并写原因。只有这台 Mac 的应用能添加项目；其他设备写去哪里添加。

**文件标签。** 变化、已删除、秘密、超限与权限失效都有文字状态（[DOCUMENT-PREVIEWS.md](DOCUMENT-PREVIEWS.md)）。改动、终端与交付见 [CHANGES.md](CHANGES.md#界面)、[TERMINAL.md](TERMINAL.md#界面)、[GIT-DELIVERY.md](GIT-DELIVERY.md#界面)，运行期间的文件变化见 [FILE-OUTPUTS.md](FILE-OUTPUTS.md)。

### 从轮次分叉

只有已结束的轮次提供「从这里分叉」；Host 没有声明 `fork` 能力或设备没有「运行」权限时没有这个入口。机制见 [ARCHITECTURE.md](ARCHITECTURE.md#会话分叉)。

- 分叉进入起始页的输入框，预选的项目和 Harness 可改。必须写明：文件不复制、不回滚，同一项目的会话共用文件夹。
- 没能沿用的模型、思考与权限档每条一行。
- Host 补充的上下文默认折叠，展开按纯文本显示并保留隐藏字符提示。
- Harness 用自己的记录分叉时，首条消息只有一行说明、没有可展开的文字，因为文字没有发给它（[STREAMING.md](STREAMING.md#输入身份与分叉上下文)）。

### 后续输入托盘

排队只在声明 `queue` 能力的 Host 上出现，队列状态以 Host 为准（[STREAMING.md](STREAMING.md#排队状态与实际发送)）。

- 运行中草稿非空时发送键改为排队；草稿为空时只有停止。
- 暂停的项写 Host 的原因并给明确的发送按钮；失去权限的项写「未发送」，不承诺自动继续。
- 输入框不可用的会话仍可查看托盘，有「运行」权限可移除，没有编辑与发送入口。
- 结果未知沿用原请求标识并保留待确认项。

### Agent 提问卡

提问在输入框上方的抽屉里回答（[QuestionDrawer.tsx](../apps/web/src/composer/QuestionDrawer.tsx)），决定卡用同一个控制器；机制见 [STREAMING.md](STREAMING.md#agent-提问与回答)。

- 提交要求每题有效，「其他…」的回答非空。
- 草稿只存在本设备；提交中锁定选择，结果未知时保留同一份回答供重试。
- 没有回答权限的设备写明原因，不隐藏问题。
- Host 没有声明 `questions` 能力时保留普通工具行。

### 附件与显式文件引用

上限、拒绝与重试、缩略图、`@` 的权限与选择规则见 [ATTACHMENTS.md](ATTACHMENTS.md)。界面另守两条：上传进度用中性墨色，不用主色；取消发送保留文字与文件。

### 发送中的消息

本设备的投影只表示提交过程，不生成轮次或回复（[STREAMING.md](STREAMING.md#本设备的发送投影)）。

- 结果未知写「未确认送达」：只能原样重试同一请求，或由人放弃这次提交，文字回到输入框。
- 另一个窗口正在重试时不给放弃按钮，只写说明。排队的输入不显示气泡。

### Slash 建议

Slash 命令始终是输入框里的普通文字，视觉标记不改变发给 Host 的内容（[SlashCommands.tsx](../apps/web/src/composer/SlashCommands.tsx)）；来源与缓存见 [HARNESSES.md](HARNESSES.md#会话命令)。

- 输入 `/` 时不预选。「最近」只记当前设备、来源与 Harness 下的命令标识，不记参数、正文或路径；退出或更换设备时清除。
- 点按与 Tab 只插入。Enter 只对无参数的 Harness 命令、且不在运行中、不是缓存命令时走唯一的发送流程；其余只补全。技能一律只插入。
- 输入法组合期间不运行命令；回答提问与写拒绝理由时不启用。
- `/new` 与 `/fork` 只准备新草稿：离开未保存文件的确认完成后才消费来源草稿，期间目标或输入变了就拒绝。
- 结果未知或正在提交时不执行新动作；保留的 Latch 命令不转发给 Harness。

**iPhone 与 iPad。** `PhoneSlash` 与 Web 共用匹配向量；命令或模板超过 200 条时不出菜单。Latch 的名字在发送入口拦截，只打开页面已有的入口，未提供的写明尚未实现，不转发给 Harness。发送在第一次异步等待前固定电脑、会话与阅读代次：其间切了页面，不向新会话发送，也不清新页面的草稿。
