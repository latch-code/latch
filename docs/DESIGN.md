# Latch 界面设计

Latch 是跨设备的 Agent 工作台：任务在 Host 上运行，用户从桌面、浏览器或手机查看、审批、取消并继续同一段工作。界面要同时表达会话内容、执行状态、设备连接与设备权限，且只展示真实存在的能力。传输、续期与阅读位置的机制见 [STREAMING.md](./STREAMING.md)。

## 品牌与原则

- **名称与图标。** 名称为 Latch。应用图标是炭黑圆角方块、两片象牙色折面与一个橙色接点；`apps/web/public/icon.png`（512px）用于界面、窗口与主屏幕，`apps/web/public/favicon.png`（64px）用于浏览器标签，`build/icon.png` 是高分辨率源图。不要改动图形本身。图标是界面里唯一的暖色元素，不使用它的橙色表达状态。
- **简约、克制。** 蓝白为主：近中性的灰（色相极轻地偏暖，读作中性，不是米色或蓝灰），平涂的地面、更亮一级的纸、近黑的墨色文字；深色是近黑的地面与柔和的白字，黑不是纯黑、白不是纯白。层次靠表面（地面、托盘、纸、浮层）的明度阶梯和墨色深浅，不靠装饰色、渐变、插画或表情。控件按数据的形状选择，一种意思只用一种画法。
- **每种颜色只表达一件事。**

| 颜色 | 只用于 | 不用于 |
| --- | --- | --- |
| 蓝 | 执行动作的主按钮（发送、允许一次、请求本机确认），每个界面最多一个；被勾选的控件（开关的开、复选框、单选、菜单里的勾）；焦点环；跳到别处的链接文字 | 运行中、计数与进度、图标、用户气泡、徽标；列表的选中行（会话行、设置导航、模型服务列表）；视图、筛选与外观的选中；切换按钮的「开」 |
| 琥珀 | 等你处理（待批准、等待本机确认；轮到它时扫过待批准胶囊的暖光，与等你处理的计数增加时的一圈涟漪）；警告（连接中断、原内容未知、含不可见字符、已开启的完全访问会话）；演示标记 | 可按的按钮；普通信息；没被选中的选项与常驻的属性（菜单与列表里的完全访问 Harness、Agent 行的 L3） |
| 红 | 高风险（R2）审批、失败、权限模式漂移、审计记录回滚、设备撤销、差异中的删除、确认对话框里的销毁按钮 | 完全访问、开发版、停止按钮 |
| 绿 | 差异中的新增；成功的结果（本机确认后的对勾、连接检测通过） | 已连接、已就绪、已检测到、已验证这类默认状态；已保存、已启用这类本地操作的结果（值原位更新就是反馈） |
| 墨色 | 运行中的彗星、加载中的转圈与流式光标、未读点、计数与进度、所有静止的图标、列表的选中行（中性的不透明底）、视图与外观的选中、切换按钮的「开」 | — |

- **默认状态安静。** 连接正常、逐项询问、已检测到、已验证的预设这类默认状态不用颜色，也不加标记；顶栏只在偏离默认时出现标记（连接异常、完全访问、演示，以及失败、已取消、已中断、正在取消的会话），运行中与已完成不标；侧栏页脚不写「已连接」。风险色只在风险值真的被选中时出现。
- **内容优先。** 对话列是主角；导航安静，不使用大面积饱和色。只有用户自己的消息有气泡，且是中性的。
- **每个状态只出现一次，并出现在正确的位置。** 会话级状态在顶栏状态标签与侧栏图标；进行中的活动在附着于输入框的运行条；单步状态在工具卡片。
- **只展示真实能力。** 选择器只列出 Host 目录中真实的 Harness、模型与项目；只有一个选项时以只读标签显示。演示模型必须带琥珀色"演示"标记。不展示虚构的数量、进度或尚未实现的菜单。设备做不到的操作直接隐藏或停用并说明原因，不让用户提交后再失败。
- **默认隐藏内部细节。** 路径中段省略并提供复制；工具 ID 作为次要文字；空参数显示"无参数"。

## 设计令牌

令牌在 workspace 包 `@latch/ui` 的 [tokens.css](../packages/ui/src/tokens.css)，页面的样式入口 [index.css](../apps/web/src/styles/index.css) 第一行导入它。页面的每个颜色、阴影、字号与行高、间距、圆角与时长都只读这些令牌。[styles.test.ts](../apps/web/test/styles.test.ts) 检查：样式表只读已定义的令牌；颜色不写字面值（遮罩与配对二维码的白底除外，二维码在深色下也要深色模块配白底才能扫描）；字号与行高只用角色令牌，字重只有 400、500、600；内外边距与间隔不落在台阶之间；圆角矩形与胶囊各自的形状。

**主题。** 浅色写在 `:root`；深色重写每个含颜色的令牌，同时写在 `@media (prefers-color-scheme: dark)`（仅当根元素没有 `data-theme="light"`）与 `:root[data-theme="dark"]` 下，两份完全相同（[tokens.test.ts](../packages/ui/test/tokens.test.ts)）。只由其他令牌组成的令牌（`--comet`、焦点环）只写一次，随主题变化。所有中性的表面与墨色都近于无彩（OKLCH 彩度在 8 位取整的误差内，不超过 0.005，色相极轻地偏暖），半透明的中性色一律是同一种墨加透明度（浅色 `rgb(29 28 26)`，深色 `rgb(234 233 231)`；深色的凹槽与落影是黑色），所以在任何表面上读起来都一样。主题偏好（跟随系统 / 浅色 / 深色）按设备保存，写入根元素的 `data-theme`；浏览器的 `theme-color` 取它下面那层表面的颜色：768px 起是地面（`--bg-app`），手机上没有地面露出，是纸色；`index.html` 按宽度与配色方案写成四条，选定主题时 `applyTheme` 按同样的宽度改写（[styles.test.ts](../apps/web/test/styles.test.ts) 核对它们与令牌一致）。manifest 不分深浅，`theme_color` 与 `background_color` 都用浅色的地面色；桌面端窗口在首次绘制前的底色与它的错误页也用两种主题的地面色。深色不反转主色：主按钮仍是 `#2461E0` 配白字（5.44:1）。黑不是纯黑、白不是纯白：浅色正文 `#1D1C1A`，深色正文 `#EAE9E7`；浅色的纸是 `#FBFBFA`，只有浮层（输入框、菜单、对话框）是纯白。深色下应用图标的炭黑方块会和纸融在一起，所以沿方块自己的边画一圈 1px 的环（`--brand-ring`，浅色下透明）：图片四周有透明留白，环画在留白内侧方块的边上，不画在图片的方框上，图形本身不变。

**地面。** 地面是平涂的 `--bg-app`，没有渐变；base.css 把它画在根元素与 body 上，外壳、侧栏、图标栏、会话抽屉、设置导航与底部面板都用它。层级靠明度的阶梯：浅色里地面最暗，托盘、纸依次更亮，浮层是纯白；深色里地面最暗，托盘、纸、浮层依次提亮，纸始终比地面亮，层级不倒置（地面对纸约 1.09:1 与 1.08:1）。列表里被选中的行（侧栏的会话行、设置导航、模型服务列表）是不透明的中性色 `--bg-selected-solid`，不用蓝：浅色里比地面深一级，深色里比地面亮一级，对地面 1.19:1 与 1.36:1、对悬停 1.10:1 与 1.21:1，所以在地面与纸上都读得出来，也不会和悬停混淆。所有墨在地面、纸、浮起、托盘与选中行上，以及叠在地面与纸上的悬停与按下上都达到 WCAG 对比度：正文、次级与提示墨色和错误文字 4.5:1，图形墨色 3:1；四种墨的最低值都在选中行上（浅色 12.67、7.26、4.74、3.11，深色 11.20、7.56、4.72、3.50）。`tokens.test.ts` 逐项计算并核对这些最低值，也核对表面与墨色近于无彩、明度从地面起逐层升高；调整任何表面、选中或墨色的值都要通过它。

**层叠层。** tokens.css 第一行声明层的顺序：`tokens, base, ui, app, security`。`@latch/ui` 的 [ui.css](../packages/ui/src/ui.css) 把元素默认样式（[base.css](../packages/ui/src/base.css)：盒模型、文档字体与颜色、焦点环、按键、减少动效）导入 base，把每个原语的样式表（`packages/ui/src/styles/`）导入 ui；页面的 index.css 先导入 tokens.css 再导入 ui.css，然后把自己的每个样式表导入一个层：还没有做成原语的共用部件（`ui.css`：品牌图标、状态点、字母磁贴、进度条、表单字段与值选择 chip）也在 ui，页面自己的布局与界面在 app，登记、设备、权限与本机确认的样式（`auth.css`、`security.css`）在最上面的 security。后面的层总是胜过前面的层，与选择器的权重无关，所以页面可以在 app 层按位置调整原语，安全相关的界面不会被普通样式改写；新增的安全界面放进 security 层。

| --- | --- | --- |

| 表面 | `--bg-app`（地面）、`--bg-pane`（纸）、`--bg-raised`（浮起）、`--bg-sunken`（托盘）、`--well`、`--bg-hover`、`--bg-press`、`--fill`、`--fill-hover`、`--fill-press`、`--track-off`、`--bg-selected-solid`、`--bubble-user`、`--scrim`、`--surface` | 窗口、侧栏与设置导航是地面（见「地面」）；内容区是嵌在地面上的纸；托盘只放在纸上，并总带 `--line-subtle`；放值的控件在凹槽（`--well`）里；次按钮、选中的筛选与中性胶囊是 `--fill`；开关关闭时是 `--track-off` 加一圈 `--icon` 色的 1px 环；列表的选中行（地面上与纸上）都是中性的 `--bg-selected-solid`；`--surface` 是元素下面那层表面（默认纸），状态点与失败点用它镂空，放在别的表面上的容器把它改成那层表面 |
| 线 | `--line`、`--line-subtle`、`--line-strong`、`--kbd-ring` | 一律 1px，颜色是墨加透明度，所以在任何底色上都刚好可见；按键的环是 `--kbd-ring`；`--line` 是静止容器的边，`--line-subtle` 分隔行，`--line-strong` 只作装饰分界与虚线框，不作控件唯一的边 |
| 阴影 | `--sh-raised`、`--sh-float`、`--sh-composer`、`--sh-composer-focus`、`--sh-modal` | 配方自带 1px 发丝环，带阴影的元素不再加边；静止的东西（纸、卡片、托盘、审批卡）不带阴影。凸起只给分段控件的选中块、开关滑块与琥珀或红色调里的次按钮；浮层给弹出菜单、Toast、「回到最新」与抽屉；输入框单独一档；模态配 `--scrim` |
| 主色 | `--accent`（`#2461E0`）、`--accent-hover`、`--accent-press`、`--accent-text`、`--accent-text-hover`、`--on-accent`、`--focus`、`--focus-halo` | 深色下主色不变；蓝色文字与链接用 `--accent-text`；深色只有 `--accent` 与 `--accent-text` 两个蓝；没有蓝色的底色调 |
| 磁贴与指示 | `--tile-plate`、`--tile-ring`；`--comet`、`--comet-track`、`--sweep`、`--ripple-ink` | 所有 Harness 与模型磁贴放在同一块托板上（浅色是白色，深色是比纸亮一级的灰），托板上的字母、图形与单色标志都是 `--text-1`；运行中的彗星是 `--comet`（即 `--text-2`），画在 `--comet-track` 的底环上；待批准胶囊上的暖光是 `--sweep`，计数增加时的涟漪是 `--ripple-ink`，都是琥珀，只表示等你处理 |
| 语义色 | `--warn-*`、`--err-*`、`--ok-*`；差异 `--diff-add-bg`、`--diff-add-tok`、`--diff-del-bg`、`--diff-del-tok` | 每组有文字、底、边与实心色；状态胶囊是底色加同色调的 1px 内环；琥珀填充上放墨色（`--on-warn-fill`），不放白字；差异只染行背景，文字保持 `--text-1`，加减号与行数用色调文字 |
| 焦点 | `--ring-focus-inset`、`--ring-field`、`--ring-field-focus` | 按钮、行与选择器只在键盘操作时显示焦点：先是 2px 所在面的间隙，再是 2px `--focus`。全局写成 2px 偏移的 `outline`：间隙露出元素下方真实的表面，所以地面、纸与对话框里不必各配一种环，强制颜色模式下也照样显示（阴影在该模式下会被去掉）；滚动列表里的行用内嵌环，不被容器裁掉；文本输入聚焦时始终显示，换成浮起底加蓝环与外晕；输入框（composer）聚焦时只把环换成 `--line-strong`，不变蓝 |
| 字级 | `--fs-<角色>`、`--lh-<角色>`、`--lh-<角色>-para`、`--ls-mono-display` | 角色有 micro、caption、meta、label、ui、list-title、body、input、card-title、title-sm、title、display、mono-sm、code、mono、mono-display。每个角色一个字号（整数像素）、一个单行行高和一个可能换行时用的段落行高（不低于 1.5）；正文 15/26，手机（<768px）整体换下一档，正文 16/27，输入 16px 防止 iOS 聚焦时缩放。字重只有 400、500、600：600 只给卡片标题、标题、问候、核对码、计数数字与品牌名，界面框架不超过 500，正文里的强调用 500，未读不加粗。字距为 0，只有核对码用 `--ls-mono-display`；时间、计数与表格数字用等宽数字 |
| 字体 | `--font-sans`、`--font-mono` | 平台系统字体与中文字体，不加载网络字体；等宽用于代码、参数、工具 ID、设备指纹、核对码与内容哈希 |
| 间距 | `--sp-2` 到 `--sp-64`、`--bleed` | 台阶为 2、4、6、8、12、16、20、24、32、40、48、64；2 与 6 只在控件内部；10、14、18、22、26 不是台阶。可悬停的行可以向两侧外扩 `--bleed`（6px），让文字仍对齐列边 |
| 圆角 | `--r-2`、`--r-4`、`--r-6`、`--r-8`、`--r-12`、`--r-16`、`--r-pill`、`--corner-shape` | 胶囊与圆形表示状态、视图或身份，圆角矩形表示动作、值与容器，所以徽标与按钮一眼可分；2 只给 4px 细条；嵌套圆角等于外圆角减内边距；图标磁贴按 round(边长 × 0.225)。浏览器支持时，圆角矩形另加 `corner-shape: var(--corner-shape)`，即 `superellipse(1.2)`：令牌只在 `@supports` 中定义，不支持时退回普通圆角；胶囊与圆形从不加 |
| 动效 | `--ease`、`--ease-exit`、`--d-fast`、`--d-base`、`--d-slow` | 一条进入曲线 `cubic-bezier(.2, 0, 0, 1)`、一条退出曲线 `cubic-bezier(.4, 0, 1, 1)`，三档时长 120 / 180 / 240ms。悬停立即出现、120ms 退去；按下只深一档，不位移、不缩放；弹层与展开 180ms，对话框、底部面板与抽屉 240ms。活的指示有自己的节奏（见「界面原语」的「活的指示」），动画只写在 `prefers-reduced-motion: no-preference` 里。`prefers-reduced-motion` 时动画与过渡都变成瞬时，只保留加载的转圈；活的指示停在能独立表达状态的静帧 |
| 布局 | `--sidebar-width`、`--sidebar-open-width`、`--inspector-width`、`--content-width`、`--gutter`、`--topbar-height`、`--shell-inset`、`--touch` | 见「布局」；1024px 起侧栏的宽度由页面写在外壳上 |

## 布局

断点定义在 [breakpoints.ts](../apps/web/src/breakpoints.ts)，CSS 媒体查询使用相同数值；侧栏另在 1440px 处变宽。

| 宽度 | 结构 |
| --- | --- |
| ≥1280 桌面 | 侧栏（默认 1440px 起 300px，以下 264px；可调宽与收起，见下）/ 对话列 / 可选检查器 320px（打开状态按设备记忆）。侧栏直接放在地面上，不画分隔线；对话区是嵌在地面上的一张纸：距窗口上、右、下各 8px，圆角 12，1px `--line`，不带阴影；检查器在同一张纸内，以一条 `--line-subtle` 分隔。纸内顶栏 48px，消息列最大 760px 居中。 |
| 1024–1279 | 侧栏默认 248px（同样可调宽与收起）+ 对话列（纸）；检查器以右侧面板打开。 |
| 768–1023 平板 | 56px 图标栏（地面：应用图标、打开会话列表、新建会话、搜索、有待处理时带琥珀计数的「等你处理」、开发版标记、设置）；对话区是纸；会话列表从左侧滑出，带浮层阴影。 |
| <768 手机 | 没有纸，整屏页面；52px 顶栏（菜单、标题与状态、新建、更多），底边一条 `--line-subtle`；会话抽屉；选择器、菜单、详情与本机确认使用底部面板；输入框贴底并留出安全区；触控目标至少 44px。 |

抽屉打开时主区域设为 `inert`，焦点限制在抽屉内，Esc 关闭后焦点回到打开按钮。对话框与底部面板同样捕获并恢复焦点。

**可调宽的侧栏（1024px 起）。** 侧栏的内侧边缘（对话纸的左边框）是调整宽度的把手（`ResizeHandle`，见「界面原语」）：宽度在 220–480px 之间，对话纸始终至少 520px，拖拽中与窗口变窄时都按此收紧（检查器并排时也算上它）；双击恢复默认宽度。拖到 160px 以下就收起，与侧栏头部「收起侧栏」按钮是同一个状态：侧栏的格道滑到 0（180ms），内容保持原宽被裁切、不重新换行，收起后不可聚焦；拖拽越过这个点时（收起，或把收起的侧栏拖出来）格道同样滑过去，而不是跟着指针一下跳到位，之后的宽度才继续跟手。顶栏开头的「展开侧栏」与「新建会话」（有等待处理的审批时还有带琥珀计数的「等你处理」）从 1024px 起一直在顶栏里，随格道一起展开与收起（宽度 180ms，淡入 180ms、淡出 120ms），所以标题跟着纸朝一个方向滑动、不会先跳一下；侧栏打开时它们不可聚焦，也不在无障碍树里。⌘K 先展开侧栏再聚焦搜索；展开或从窗口左缘拖出时回到上次的宽度。收起时侧栏的格道只留窗口的 8px 边距，纸四周的间距不变。键盘：把手可聚焦，←/→ 一步 8px（Shift 32px），Home/End 到最窄与最宽，Enter 收起或展开；用侧栏或顶栏的按钮收起、展开时，焦点移到做相反动作的那个按钮。拖拽中跟手的宽度不做过渡、不选中文字，指针由把手捕获。宽度与收起状态按设备保存在本地偏好里（从不发给 Host），按断点类别（1024–1279 与 ≥1280）分别记住，窄窗口不会继承宽窗口的宽度；读不到或不合规的值按默认处理。平板与手机没有把手。

## 界面原语

原语在 workspace 包 `@latch/ui`（[index.ts](../packages/ui/src/index.ts)），是 React 组件加上它们在 ui 层的样式。页面从这里取按钮、胶囊、开关、分段控件、选值、菜单、对话框、提示与磁贴，不再各自画一份；同一种意思只有一种画法。样式只读令牌。类名以 `ui-` 开头，变体与尺寸写在 `data-variant`、`data-size`、`data-tone` 上，状态直接用 ARIA 属性（`aria-pressed`、`aria-checked`、`aria-expanded`、`aria-disabled`、`aria-busy`、`aria-invalid`），所以样式跟着可访问性状态走，不另设状态类。

**交互约定。** 悬停立即出现、120ms 退去；列表里选中底的切换 120ms（刚点过、还在指针下的那一行也淡入），不做滑动的选中块；按下只深一档，不位移、不缩放。禁用的控件用 `aria-disabled`：整个控件降到 45%，仍能用键盘聚焦，提示框说明原因，点击与表单提交都被拦下（不用原生 `disabled`，否则原因无人能读）。成组的单选控件（分段控件、文字标签页、筛选胶囊、单选列表）整组只有一个 Tab 停靠点，方向键移动并立即选中，Home / End 到首尾，跳过不可选的项。弹层与菜单在顶层（top layer）显示，滚动容器与对话框都裁不到它；打开时焦点进入当前项或第一项，Escape 关闭并把焦点还给触发器，Tab 离开即关闭，点外面或滚动让触发器移动了 1px 以上时关闭（打开时把触发器滚进视野的那次滚动、别处的滚动都不算）。手机宽度（<768px）下，菜单、选值与弹层都换成底部面板。对话框与底部面板里 Tab 只经过真正的 Tab 停靠点（`tabindex="-1"` 的菜单项和单选组里的其余项不在其中），从最后一个回到第一个。

**图标与转圈。** Lucide（ISC）线性图标只用 12、14、16、20、24 五个尺寸，描边随尺寸变化（2.5、2.15、1.9、1.8、1.5），画出来的线宽在 16 及以下约 1.25px，20 与 24 为 1.5px；`ICON_STROKE` 按尺寸取值，用其他尺寸时类型检查失败。静止的图标是 `--icon`，悬停与激活时是 `--text-1`，和文字放在一起时随文字颜色；图标只在表示状态时带色相，失败是红色三角，被选中的完全访问是琥珀色的 `shield-alert`。箭头各有一种意思：向右是进入下一层或展开（展开时转 90°），上下双箭头是原地选值，向下是下拉动作。停止是 10×10、圆角 2 的实心方块，不是描边图形。转圈是一圈淡轨道加一段四分之一弧，旋转加在外层元素上，900ms 一圈；页面上所有转圈按文档时间线对齐相位，并排时不会错开。它只表示加载或等待一个响应（加载行、按钮运行中、取消中），是墨色，在按钮里随文字颜色；减少动效时仍然转。Agent 正在运行用彗星（见「活的指示」）。

**按钮。** 尺寸只有四档：xs 24（提示、托盘行与检查器里的行内动作）、sm 28（桌面默认：页头、卡片按钮行、行尾）、md 32（对话框与面板的脚部）、lg 44（手机）；带前导图标时起始内边距少 4。变体：主按钮是一个界面里唯一的蓝色，只给执行或创建的动作（发送、允许一次、请求本机确认、添加服务）；「保存」「保存默认值」这类不执行操作的确认用次按钮。次按钮是中性填充，没有环和阴影，放在琥珀或红色调的容器里（容器标 `data-tint`，内联提示自己会标）时改为浮起的白色；幽灵按钮用于工具栏、行尾与「重置」这类安静的动作；链接样式只用于跳到别的页面或位置（`ButtonLink` 是同样画法的 `<a>`）；页面上的危险操作是红字的次按钮；实心红（destroy）只在确认对话框里。运行中的按钮宽度不缩、前导位换成转圈、文案可以换成进行时（「检测中…」），并标 `aria-busy`，不再接受点击；运行中的按钮不算禁用，页面同时禁用它时也不降透明度，主按钮运行中仍是蓝色。快捷键写在提示框里（「允许一次 ⌘⏎」），从不放进按钮。每张卡、每个对话框脚部与面板头部最多两个可见按钮，次在前、主在最后，第三个动作进 ⋯ 菜单。图标按钮是 24、28、32、44 的正方形（图标 12、16、16、20），名称同时是它的提示框；切换按钮的「开」是中性的按下底，不用蓝；输入框里的发送与停止是圆形。图标按钮的面（悬停、按下与「开」的底，以及键盘焦点环）按它自己的尺寸画在中间，所以在任何屏幕上看起来一样大；触屏上它的盒子长到 44×44，工具栏与图标栏里相邻的按钮因此相隔 44，点按区不重叠；页面在密集的行里保留较小的盒子时（回合脚部的复制、列表头的筛选），透明的点按区仍伸到面四周的 44×44。计数放在面的右上角外 4px，垫着一层所在表面的颜色并镂空一圈 2px（`--surface`），字形不被遮住，琥珀的半透明底也不透出字形。`--surface` 默认是纸色；放在别的表面上的容器把它改成自己的颜色：图标栏在地面上，所以是地面色；菜单、弹层、对话框与 Toast 是浮起色，底部面板是地面色，面板里的卡片与单选列表又回到纸色。

**提示框。** 悬停 500ms 后出现，键盘聚焦时立即出现；离开、按下或 Escape 立即消失；从一个提示框移到相邻的控件时立即切换。浮起表面、圆角 6、24 高、12/16 文字，跟随主题，不反色，不接收指针；提示文字同时是触发器的读屏描述（图标按钮的名称已经是同一段文字时除外）。禁用控件的原因（按钮、图标按钮、选值）、开关与分段的说明和开发版标记的整句都用它，不用浏览器原生的 `title`。触屏上不出现。

**胶囊、小徽标、计数、状态点与按键。** 胶囊表示状态、视图或身份，圆角矩形表示动作、值与容器，所以状态胶囊和按钮一眼可分。20 高的状态胶囊是卡片、行或会话的状态（待批准、失败、已取消）；16 高的小徽标是跟在名字后面的属性（默认、本机、内置、离线、开发版、演示）。中性是填充，琥珀、红、绿加同色调的 1px 内环；没有蓝色胶囊，没有前导点。计数是 16 高的胶囊、等宽数字、超过 99 写 99+：被动计数中性，手机上的未读是墨色实心，等你处理的是琥珀；页面亲眼看到计数变了一时数字滚一格，等你处理的计数增加时另有一圈涟漪（见「活的指示」）。状态点桌面 6、手机 8，琥珀与红点总要和文字或图形一起出现，叠在磁贴上时用所在表面的颜色（`--surface`）镂空一圈。按键（kbd）只出现在提示框、菜单项尾部、搜索框与审批卡聚焦时的提示行里。

**选值（ValuePicker）。** 在原地从一组互斥的值里选一个，只显示当前值：幽灵、28 高（检查器里是 24、箭头只在悬停或聚焦时出现）、值 13/18 常规字重、末尾上下双箭头，前导、值与箭头彼此相隔 6。值总是紧跟前导（没有前导时从内边距开始），所以检查器里外扩的一列值与列的边缘对齐；手机设置面板里的值离箭头 6，同一张卡的值右缘对齐。悬停与菜单打开时变深，值换成正文墨色；只有一个可能值时是不可点的文字；没有选择时写「选择模型」这类说法，用提示墨色，不用警示色。读屏名称是「标签：值」。菜单打开时焦点在当前值上，Enter 选中，可以按首字母跳转；不可选的值也能聚焦，下面一行带禁止图标的原因保持原色并被读出。选中即生效，不弹提示；值改变时淡入 120ms。调高权限这类要验证的改动返回一个 Promise，等待期间前导位是转圈、值换成「等待验证…」，取消验证时值不变。箭头不动：设置行尾部的选值向左伸展；输入框工具栏里左对齐的权限菜单（`reserve`）预留值与「等待验证…」中较宽的宽度，多出的宽度留在值和箭头之间。只有可能等待验证的选值才预留，模型、项目这类选值、检查器的 24 高选值与手机行都不预留。设置行尾部的选值按 `--bleed` 向右外扩 6px，使箭头与同卡导航行的箭头对齐。长列表可以带搜索行。禁用的选值降到 45%，原因在提示框里。手机上是底部面板里的单选列表，打开时焦点在当前值上（单选组唯一的 Tab 停靠点），不论它排在第几；`variant="row"` 是手机设置面板里的一行（标签、值、箭头），同一张卡里相邻的行之间有一条从文字边开始的 `--line-subtle` 细线，最后一行下面没有。

**权限菜单（PermissionMenu）。** 有序的权限等级只用这一个菜单，不用一排分段：整层 320 宽，头部写作用对象，四个两行项从低到高，每项一句后果，默认项带中性小徽标「默认」，越级的项不可选并写出原因，脚部是一行导航或带锁的说明。菜单里的完全访问不带琥珀；只有它被选中后，触发器前才出现琥珀色 `shield-alert`。调低立即生效，调高走上面的验证流程。等级的文案由页面传入，原语只负责顺序、画法与交互。手机上的单选面板用同一份文案：头部写在列表上方并作为单选组的名称，「默认」徽标跟在标题后面，脚部说明与单选和标题两列对齐。

**菜单与弹层。** 浮起表面、圆角 12、内边距 4、浮层阴影，最小宽 220（给出的宽度都是整层的外宽，内边距在内；可搜索的选值 360），距触发器 6，设置行与检查器里右缘对齐触发器，输入框里左缘对齐。打开时从触发器一侧移入 4px 并淡入（180ms），关闭只淡出（120ms）。菜单项 32 高（带说明 48），圆角 8，前导槽 16：选值菜单里当前项是蓝色对勾、标题换成 500 字重，动作菜单里是图标；尾部只放一样（元信息、小徽标或按键）；两行项（带说明或不可选的原因）把前导与尾部放在标题那一行，不放在两行中间；原因行在上一行下 4、禁止图标与文字相隔 6；高亮瞬时变化。菜单项的图标静止时是图标色，悬停、键盘高亮与按下时换成正文墨色。危险项（删除）排在最后，前面一条分隔线，文字与它的图标都是红色。菜单的读屏名称是它的标签加头部写的作用对象（「权限：在这台电脑上发起的会话」，头部只重复标签时不再加），头部的元信息是它的读屏描述。分隔线下的脚部行与菜单项用同一网格，文字从标题那一列开始：导航行（「电脑与权限上限…」）是正文墨色 13/18，前导槽空着，末尾向右箭头；说明行（「调高要在这台电脑上验证身份」）把锁放在前导槽中间，文字 12/16 提示墨色。`Popover` 是同样表面的内容弹层，焦点进入它的第一个控件。

**输入。** 文本字段放在凹槽里，带 1px 环；聚焦时（不只是键盘）升到浮起表面并换成蓝环与外晕。标签在上（12/16·500），提示在下（12/18 提示墨色），出错时环变红、下面一行红字写原因与改法，并作为读屏描述。桌面 32 高；手机 44 高、16px 字，iOS 聚焦时不缩放。页面内的搜索框是同样的凹槽加前导放大镜（与文字相隔 6，控件内图标与文字的间距），有内容时尾部是 24 的清除按钮（触屏上四周有 44×44 的透明点按区），Escape 先清空。地面上一列行里的搜索（侧栏）用 `variant="ghost"`：与那一列的行同样 36 高、16 的放大镜距起点与文字各 8，静止时没有凹槽，悬停是悬停底，只有聚焦时升到浮起表面并带蓝环。

**开关与选择。** 开关只给能立即开关的行：桌面轨道 32×18、滑块 14（触屏 44×26、22），关是实心 `--track-off` 加一圈 `--icon` 色的 1px 环（对纸达到 3:1），开是蓝色；滑块是浮起的白色，180ms 滑到位，按住时向前进方向拉宽 4px；Space 切换；键盘焦点环画在轨道外 2px，跟着胶囊的形状，不画在更大的点按盒子上。`SwitchRow` 整行是开关的标签，点标题也能切换，整行不响应悬停；被策略锁住时开关关闭并降到 45%，前面一把锁，说明换成原因。分段控件只用于 2–3 个对等的视图或模式（类型只允许 2 或 3 项）：没有环的凹槽、等宽段、选中段是浮起的白色滑块，平移到位；它是一个单选组，段的说明（例如为什么不可选）在提示框里。文字标签页与筛选胶囊是没有轨道的胶囊，选中是中性填充（标签页的填充平移到位），从不下划线、不用蓝；标签页是 tablist，筛选是一组 `aria-pressed` 的切换按钮。复选框与单选框是 16px 的原生输入：未选中是 `--icon` 色的 1px 环，选中是蓝色（实心加白勾，或 5px 的蓝环）。单选列表放在卡片里，每行 48（手机 56），前导单选、标题与一句后果，选中项标题 500，单选与标题在同一行，下面有说明或原因时也不下移；不可选的行降低单选与标题，原因一行保持原色。

**选中的三种画法。** 列表里的对象（会话行、设置导航、模型服务列表）是中性的不透明底 `--bg-selected-solid`，标题换成正文墨色；被勾选的控件（菜单对勾、单选、复选、开关的开）是蓝色；视图、筛选与外观（分段、标签页、筛选胶囊）是中性的滑块或填充。蓝色从不画在选中行上。

**对话框与底部面板。** 对话框是原生模态 `<dialog>`：480（确认）、560（表单）、720（双栏），浮起表面、圆角 16、模态阴影与遮罩；头部 56（标题 15/22·600、可选副标题、关闭）、正文内边距 24、脚部 64（左侧说明，右侧最多两个 md 按钮，次在前、主在最后），头与脚各用一条 `--line-subtle` 分开；没有头尾的确认四边留 24。打开时聚焦第一个输入（没有输入时是正文的第一个控件），Tab 在对话框里循环，Escape 与点遮罩关闭，关闭后焦点回到打开它的控件；从 98% 放大并淡入，240ms。底部面板（手机）是地面色、上圆角 16，抓手、52 高的头部（左「取消」是常规字重的幽灵按钮、中间标题、右侧动作：执行操作的主按钮，或只关闭面板的次按钮「完成」，热区都是 44；「取消」的文字与动作的右缘都落在下面卡片的 16 那条线上），从底部滑入；内容高时先停在窗口的 65%，向上拖到 92%，向下拖过三分之一或快速下滑则关闭。改动即时生效的面板不放「确定」。

**调整宽度（ResizeHandle）。** 侧边列（侧栏，以后的检查器）的边缘：跨在边缘上的 6px 透明命中区，光标是 `col-resize`；悬停 300ms 后（避免划过时闪烁）、拖拽中立即、键盘聚焦时随焦点环一起，在中间画一条 2px 的 `--line-strong` 竖线，不用蓝色，也不占布局。它是竖向的 `role="separator"`，读屏名称写明作用（「调整侧栏宽度」），`aria-valuenow`、`aria-valuemin`、`aria-valuemax` 是像素宽度，收起时 `aria-valuetext` 为「已收起」。它只报告宽度：拖拽中报告指针下的原始宽度、松开时再报告一次（由页面收紧、吸附收起并保存），键盘一步 8px（Shift 32px）、Home/End 到两端，Enter 切换收起，双击复原；拖拽时捕获指针，并在根元素上标 `data-resizing`，整页显示调整光标、不选中文字。

**提示与 Toast。** 内联提示（也用作消息区顶部的横幅）是色调底加同色调 1px 边：警告配三角，错误配圆形叉号，中性配信息图标，中性的底是托盘；图标与标题用色调文字，说明是次级墨色 12/18；最多一个 xs 动作（琥珀与红色调里是浮起的白色次按钮），可选一个关闭按钮。先写保留了什么，再写原因，最后给动作。错误提示是 `alert`，其余是 `status`。本地操作成功（保存、启用、获取到模型）用中性提示或只让值原位更新，不用绿色。Toast 是 36 高的浮层胶囊，前面一个色调图形，用于发生在别处的事（「已由「设备名」处理」）和失败；置顶、归档、删除这类在本页做的操作成功时不弹 Toast，列表行的移动或收起就是反馈。

**空、加载与错误。** 空状态是一句短名词（「还没有会话」）、一行说明和最多一个 xs 按钮，左对齐，不放插画。加载在对象旁边放 14 的转圈和一行提示墨色的文字；页面中央的连接状态用 20 的转圈；列表的骨架只做呼吸（不透明度 .55 到 1，1.6s），不做扫光，占的盒子与内容相同。界面出错的卡片是一张 480 的纸：红色三角、标题、一行说明会话和草稿都在执行端，最多两个按钮。

**磁贴。** Harness 与模型的方形磁贴：16、20、24、32、40、56，圆角按 round(边长 × 0.225)，所有磁贴同一块托板（`--tile-plate`：浅色是白色，深色是比纸亮一级的灰）加 1px `--tile-ring`。磁贴放品牌自己的标志文件（`mark`），只有没有图标的东西才放调用方给的图形（`icon`）；类型上二者必有其一，磁贴从不画字母。标志居中占 62.5%，文件自己带了很宽的留白时（`margin`）铺满托板。彩色标志原样放在托板上（`<img>`），品牌另有深色版文件时（`dark`）按页面的主题换用；单色标志按品牌的单色复制方式，以文件为 CSS 遮罩、填成 `--text-1`，所以浅色里是近黑、深色里是柔和的白，图形本身不改；品牌自己的应用图标（`tile`）自带底色与外形，原样显示，不加托板与细环，也不按磁贴的圆角裁切。标志文件从不作为标记内联进页面。托板上的图形也是 `--text-1`；图形是 Lucide 图标，磁贴按它画出来的大小定线宽，画出的线在 20px 以下是 1.25px、20px 起是 1.5px，与图标尺度一致，小磁贴里的图形不会糊成一团；16 的位置上（选择器的按钮、顶栏与回复的来源行）没有图标的东西只画图形本身（`plain`），因为托板上 10px 的图形认不出来。`plain` 只有图形没有磁贴，图形用它所在表面上更安静的 `--text-2`（单色标志仍是 `--text-1`）。就绪度画在磁贴上，就绪不加任何标记：不可用（例如找不到命令）灰度并降到 40%；启动或检测中灰度、降到 70%，外面 2px 处一圈 2px 的进度环（有进度时从 12 点起顺时针按比例画弧，否则一段弧 1.4s 绕一圈，减少动效时和转圈一样仍然转）；失败在右上角放一个 8px 的红点并镂空一圈表面色。就绪度也要在文字里写出。

**活的指示。** 只有活的状态会动（运行中、等你处理、新到），静止的事实（时间、已完成、已取消、失败）从不动；每行最多一个动的东西，动的元素不超过 52×20，只动 transform、opacity 或小元素的背景位置，没有闪烁、弹跳与变色。所有动画只写在 `prefers-reduced-motion: no-preference` 里（[live.css](../packages/ui/src/styles/live.css)），默认的静帧就是减少动效时的样子，必须能独立表达状态。

- **彗星（`Comet`）。** 运行中：12（侧栏、运行条与检查器的过程行）、14（工具卡 16 的图标位）、16（手机列表）。计划的步骤不带彗星：运行中的工具已在它的行与运行条上转动，一个运行在桌面上最多同时转三四颗。一圈 `--comet-track` 底环（描边 1.5 / 1.6 / 1.75px）上一段 160° 渐亮的尾巴与圆头，`rotate(1turn)` 2.4s 线性；所有彗星同一相位：挂载时把 `animation-delay` 设为 −(文档时间 mod 2400ms)，每次它的旋转重新开始时（例如从 `display: none` 恢复，或从减少动效切回）再按旋转真正的开始时间重设一次。静帧是头停在 12 点、尾巴沿左侧淡出，仍读作运行中。`held` 的彗星不再运行：停在挂载时同一相位所在的角度，没有动画，也不参加接力，是运行结束时离开的那一颗。
- **接力。** 一个窗口里可见的活项（彗星与等你处理的胶囊）按阅读顺序编号：从上到下，竖直中心相差不到 8px 的算同一行、从左到右（不同大小的彗星并排时顶边不齐，按中心不会把大的排在前面），各得 `--i` 与 `--cyc`，周期 max(3, n) × 1.6s，只有前 8 个参与；轮到 `--i` 时彗星在常转之上多转一圈（1.6s，`cubic-bezier(.37, 0, .63, 1)`，转完回到同一相位），胶囊则扫过一次暖光，其余时间休息，所以一个周期里只有一处在做额外的事。3–8 格各有预置关键帧，由 `data-relay` 选择。可见指在窗口里（IntersectionObserver），且它与容器都不是不透明度 0：鼠标停在会话行上、状态槽让位给 ⋯ 时，那一行不再占一格，周期里没有看不见的一轮。每个格的边界重新量一次顺序与可见性（列表重排时行不重新挂载）；编号变了就在这个边界上换，所有接力动画一起重新开始，这时每一圈与每次扫光都已停下，不会被截断；只有已编号的项都已卸载时才立即编号。
- **等你处理（`WaitingPill`）。** 琥珀状态胶囊（「待批准」）；轮到它时文字后面一道 `--sweep` 暖光从左扫到右（宽 300% 的渐变，背景位置 100% → 0%，1.5s `cubic-bezier(.45, 0, .2, 1)`），其余时间静止。
- **一次性动效。** 计数变了一时数字栈滚一格（+1 上滚、−1 下滚，240ms）；等你处理的计数增加时一圈 1px `--ripple-ink` 涟漪（不随缩放加粗的 SVG 矩形，1 → 1.8 倍，两位数为 1.3 × 1.8，1.4s，延迟 .4s）；只在有东西等待时才出现的计数（侧栏的「待批准」行、图标栏的待批准按钮）由所在的组件用 `useLivePrevious` 记住它出现前的值并传给 `Count` 的 `from`，所以第一项到达（0 → 1）也有涟漪，但不滚数字，因为旧值不在屏幕上；状态槽从运行中变成未读时彗星收拢（240ms）、未读点落下（264ms，晚 48ms），从未读变成时间时点沉下（144ms）、时间淡入（192ms，晚 96ms）。它们只为页面亲眼看到的变化播放一次：页面经 `LiveChanges` 给出重新同步的纪元，在上一次渲染之后换了纪元的变化直接显示新值；没有纪元或减少动效时也直接显示。外壳（侧栏、图标栏）的纪元是 Host 状态重新同步的次数（首次加载、重连后的快照同步、页面重新可见，见 [STREAMING.md](./STREAMING.md)「客户端：事件流、凭据与版本门禁」）；对话区与会话详情的纪元另加打开的会话，切换会话时那里不播。会话列表跨会话存在，所以打开一个未读的会话时，它那一行的点沉下、时间淡入。过程行的状态变化（下一条）与页面里的其他一次性过渡用同一个 `useLiveChange`。
- **过程行的状态（`StatusGlyph`、`StatusWords`）。** 工具卡、检查器的工具时间线与计划步骤共用：图形格里运行中是彗星，其余是这一行的图标（计划步骤按状态是空心圆、带点的圆与对勾，都是静止的）；`state` 写明图形表示什么。页面看着它变化时，旧图形（运行中的是停住的彗星）120ms 沿退出曲线淡出，新图形从 80% 长到原大并淡入（120ms，进入曲线），在同一格里交叉淡化；状态文字（执行中 → 完成）上移 4px 淡入（120ms）。失败只换图标与文字，不抖动。首次渲染、重新同步、切换会话与减少动效时直接显示。
- **状态槽（`StatusSlot`）。** 列表行行尾的一格，右对齐、至少 24 宽，只显示一样：彗星、等你处理的胶囊、失败（12 的红色三角加文字，`--err-text`，文字由页面给出，默认「失败」）、未读点、时间，或什么都没有；尺寸跟彗星，桌面的侧栏 12，手机的列表 16（未读点在手机上也是 8）。收拢时彗星朝未读点的圆心（行尾向内半个点宽）缩小，像圆环收成一点，而不是在旁边跳一下。它对读屏隐藏，行自己用一句隐藏文字说出状态与时间。

**开发版与演示标记。** `DevMark` 是中性小徽标「开发版」，整句说明（「开发模式：Host 代码可被本机修改」）是它悬停时的提示与读屏名称，从不用红；`DemoMark` 是琥珀色小徽标「演示模型」（窄处写「演示」）。

**原语与页面。** 页面里的按钮、图标按钮、开关、分段控件、筛选胶囊、胶囊与小徽标、计数、内联提示、侧栏搜索框、发送方式的单选列表、加载行、Toast、开发版标记、Harness 与模型服务的磁贴、侧栏的调整宽度把手，以及运行中的彗星、等你处理的胶囊、会话行的状态槽与过程行的状态图形和文字都来自原语。会话行、选值 chip、菜单与对话框的外壳（`overlays.tsx`）与表单字段还在页面里，随各自界面的改版换成原语。

[packages/ui/test/gallery](../packages/ui/test/gallery) 是只供测试的原语总览页：每个原语的每种状态都在一页上（悬停、按下与键盘焦点由截图时强制），不进入 `dist/web`。一次性动效在总览页挂载后一帧重放一次，另有几格把暖光、涟漪、数字滚动、收拢与过程行的交叉淡化定格在中途，便于评审；活的指示一节里只有「接力」那几行参加接力，其余单个样本都不参加，所以那几行自己轮流；总览页自己的排版只作用于它自己的元素，原语的标题与字号保持原样；就地画出的对话框、弹层与底部面板在手机宽度下收进卡片，完整可见；截图时视口长到整页高度，手机与平板的截图因此带着触屏尺寸（44 的点按盒子、44×26 的开关）。

## 组件

**Harness 与模型服务的图标。** 每个 Harness 与模型服务都显示它真实的品牌图标，放在磁贴上（`BrandTile`，[brands.ts](../apps/web/src/brands.ts)）：先用品牌自己的文件（项目仓库里的或官网上不需登录即可取得的），没有时用开源图标集 LobeHub Icons（MIT）在固定提交中的文件，品牌标志是彩色的就用彩色版，否则用单色版。文件原样复制到 `apps/web/src/assets/brands/`，不作为 npm 依赖；以 `?no-inline` 导入，构建产物里是同样字节的文件，不被改写成内联数据；只经 `<img>` 或 CSS（遮罩）使用，从不内联成标记。来源（仓库与路径及提交，或网址与日期）、许可证、图标集的 MIT 声明与「标志属于各自的所有者，只用于标明服务或工具」写在仓库根的 `NOTICE`。目录里的会话与服务不带预设标识，所以按 Host 由预设派生的标识（`codex`、`codex-2`……）认出它的预设；设置里有预设标识时直接用它。没有图标的才用中性图形：自定义的 Agent 命令是 `bot`，插件是 `puzzle`，自定义的 OpenAI 兼容服务是 `plug`，演示模型是 `flask-conical`；Latch 内置的 Harness 用应用图标原样显示。[brands.test.ts](../apps/web/test/brands.test.ts) 检查每个 Harness 预设与模型服务预设都有图标，演示、插件与自定义各有图形，图标目录里正好是映射用到的文件，且每个 SVG 不含脚本、外来内容、事件属性、嵌入图片、样式表或指向文件外的引用。图标出现在侧栏的会话行、顶栏与每轮回复的来源行、选择器，以及设置里的模型服务（预设、列表与表单）与 Agent（预设、列表与表单）。

**侧栏。** 从上到下：头行（48：20 的应用图标与「Latch」，右侧是幽灵图标按钮「新建会话」——新会话页打开时是切换按钮的「开」——与「收起侧栏」；抽屉里换成「关闭会话列表」）、搜索（32，⌘K 聚焦，按标题即时过滤）、只在有审批等待时出现的「等你处理」行（`inbox` 图标、正文墨色 500 的文字与琥珀计数；点它打开最早一项等待的审批所在的会话并定位到它）、会话列表与页脚（52：`laptop` 图标、运行 Host 的这台电脑的名称、开发版标记、只在连接中断或离线时出现的琥珀小徽标，以及设置）。本设备的名称在「设置 › 设备」里，设备也只从设置进入。搜索与「等你处理」都是幽灵行：16 的图标位距起点与文字各 8，静止时没有底色，悬停是悬停底、按下深一级，所以这一列里唯一静止的底色就是打开的会话那一行的中性选中底；琥珀只在计数上。搜索聚焦、有内容或筛选不是「全部」时，它下面展开一行筛选胶囊：全部、对话、Agent，有已归档会话或正在看它们时还有已归档（展开与收起是高度加淡入淡出）。在搜索里按下、直到这次点击落下之前，搜索失去焦点而焦点无处可去也不收起胶囊（Safari 与 iOS 点按钮不会让它获得焦点：用鼠标时搜索在按下的一刻失去焦点，触屏时在手指抬起之后、点击之前），其余时候焦点离开搜索或在别处按下就收起；列表末尾另有一行安静的「已归档」与数量，有已归档会话时出现，点它切到已归档。页脚的连接徽标也是同步最新状态的按钮，点按范围在 16 高的徽标四周各多出 4px；平板图标栏不画连接，连接出问题时由顶栏的琥珀胶囊写出。会话先按置顶分组，其余按项目分组：会话的工作目录落在哪个保存的项目里（取最深的一个）就归哪一组，没有记录目录的会话属于启动目录，都不属于的归「其他目录」；启动目录这一组用它的文件夹名，其余用项目名。组按其中最近更新的会话排序，组内最新的在前；Host 不提供项目列表时按工作目录分组。组头 28（12/16·500 提示墨色），悬停或聚焦时右端出现 24 的「+」，在这个项目里新建会话（项目在本次启动时不可用，或设备不能发起会话时没有）。每行一行高（36px，触屏 44px）：20 的 Harness 磁贴、标题与状态槽；状态槽按优先级只显示一样：等你处理的「待批准」胶囊、失败（红色三角加「失败」；权限模式变化后停下的会话同样是红色，写「权限已变化」）、运行中的彗星（打开的会话不显示，它的运行条已经说了）、未读点，其余是相对时间（已取消与已中断的会话也显示时间，打开时由顶栏的状态胶囊说出）；手机的会话列表里状态槽是 16；悬停、键盘聚焦或菜单打开时状态槽 120ms 淡出，换成 ⋯ 菜单（鼠标点开会话不藏起状态），提供重命名、置顶、归档、导出 Markdown、删除（需确认，运行中不可删除）。标题太长时最后 16px 渐隐，不用省略号；菜单打开时这一行保持悬停底，指针移进菜单后仍看得出菜单属于哪一行。行里的 Harness 磁贴说的是这个会话，不画 Harness 现在是否可用（每轮回复的来源行也是）。行标题默认用次级墨色，比阅读列安静；选中的行是中性的不透明选中底（120ms 切换）与 500 字重；未读的行把标题换成正文墨色并在状态槽显示墨色圆点，字重不变。未读按设备记录。列表随 Host 变化时，移动的行与组从原位置滑到新位置（180ms），新到的行淡入，离开的行（归档、删除、移到别的组）高度收起并淡出（140ms）；换筛选或搜索时直接重画，减少动效时都不动。

**新会话。** 居中的问候与输入框。输入框工具栏依次是 Harness、模型（仅当该 Harness 使用 Host 模型）、项目、模式（只显示 Harness 支持的模式）；手机上合并为一个"运行设置"面板。选择按设备记忆，并按 Host 当前目录修正。缺少可用模型或 Harness 时显示指向设置的引导卡片。演示模式下显示带"演示"标记的示例卡片。

**会话。** 顶栏（纸内 48）左侧是标题：一个幽灵按钮，悬停时露出向下箭头，打开会话菜单（重命名、置顶、归档、导出 Markdown、删除）；接着是会话在哪里运行（16 的 Harness 磁贴与提示墨色的「Harness · 项目文件夹名」）和不是默认时的状态胶囊（失败为红色，已取消、已中断、正在取消为中性；运行中与已完成不标）。右侧依次是连接胶囊（只在连接不正常时出现：琥珀色写出状态与「· 重试」并带刷新图标，没有圆点，手机上同样写出文字；点击同步）、完全访问会话的琥珀胶囊（`shield-alert` 加「完全访问」）、演示标记（"演示模型"，手机为"演示"）、检查器开关（打开时是中性的按下底，不用蓝色）与更多菜单（会话的操作与「同步最新状态」；新会话页里只有后者；手机与平板另有「会话详情」）。手机上标题是文字，会话的操作都在更多菜单里。每轮回复的来源行是 16 的 Harness 磁贴与 Harness 名称。用户消息为右侧的中性气泡；助手回复为整宽内容，每轮显示一次来源行。思考过程默认折叠，只有模型真实报告时出现。连接中断或离线时，消息区顶部有一行琥珀色提示：三角图标与琥珀色标题（「连接已中断，正在重连…」或「当前设备已离线」），说明为次级墨色，右侧「重试」。会话里的系统说明报告失败（模型服务出错、运行被中断、会话停止）时与错误提示画法相同：红色调、红色圆形叉号，文字为次级墨色；其余系统说明是中性的。

**工具卡片。** 卡片是纸上的托盘；图标按工具类型区分；标题优先使用人类可读的说明，工具 ID 为等宽次要文字；右侧是状态，执行中时图标位换成 14 的彗星、状态文字是墨色，失败时是红色三角加「失败」，工具图标不变色。页面看着状态变化时，彗星与工具图标交叉淡化、状态文字上移淡入（过程行的状态原语，见「活的指示」）；检查器的工具时间线与计划步骤用同一个原语，所以每个过程行的变化都一样。展开后在托盘里的一张纸上显示"参数 / 变更 / 输出"，文件变更以统一差异视图展示。待审批时卡片展开为审批区，卡片头部右侧的状态换成等你处理的琥珀色胶囊「待批准」（只有文字，没有图标，轮到它时扫过暖光），这是卡上唯一表示等你的标记；标题「需要你批准」与它的盾牌图标是墨色。普通操作保持中性托盘；高风险只有托盘与「高风险」胶囊是红色，红色只表示风险，不表示等待。按钮来自审批选项（手机为整宽 44px 按钮）。

**计划与用量。** Harness 报告计划时，在输入框上方显示带进度的计划卡片（静止的纸，进度条是墨色；当前步骤用正文墨色与 500 字重，标记是静止的带点圆，已完成的步骤变淡；步骤状态变化时标记交叉淡化）；检查器中也有完整列表。每条助手回复底部显示该步用量，检查器显示会话合计。

**运行条与输入框。** 运行中输入框仍可编辑，但需等本轮结束才能发送；运行条显示当前活动与耗时（12 的彗星与文字都是墨色），并提供停止；停止不是风险操作，按钮不变红。有待审批时运行条变为琥珀色"N 项待批准 · 查看"。输入框浮在自己的阴影上，聚焦时只把环加深，不变蓝；发送是输入框里唯一的蓝色按钮，没有内容时退为中性填充。桌面 Enter 发送、Shift+Enter 换行；触屏设备 Enter 换行；⌘/Ctrl+Enter 总是发送；输入法组字时不会发送。

**设置。** 桌面为两栏页面：导航在地面上，分区内容是纸，卡片与输入框放在纸上；手机为逐级进入的页面，整页是纸。通用（主题、发送键，有「管理此 Host」权限的设备还有新会话默认值）；模型服务（列表与详情，从预设添加，已保存的密钥显示"已保存（不回显）"并提供更换与移除，不修改则保留；获取模型、手动添加、默认模型、检测连接）；Agent（ACP 预设、许可证、安装提示与检测状态，命令、参数与环境变量名）；项目（启动目录带「启动目录」标记；Host 本次启动时停用的项目仍在列表中，带琥珀色「不可用」标记与原因，并保留「移除」；新会话的项目选择器与默认值都不提供它；保存的默认项目被停用时，Host 让新会话改用默认工作区，默认值表单也显示默认工作区）；插件（按类型分组，受管理或使用中的开关附原因禁用）；设备；关于。模型服务、Agent、项目与插件需要「管理此 Host」权限；没有该权限的设备只看到通用、设备与关于。

## 设备与权限

界面按设备的权限隐藏或禁用操作，只是为了不展示做不到的事；每条规则都由 Host 再次执行。门控规则集中在 [permissions.ts](../apps/web/src/core/permissions.ts)。

**安全文案。** 这些错误文案集中在 [securityCopy.ts](../apps/web/src/core/securityCopy.ts)。

**登记页。** 未登记或凭据失效的浏览器在地面上看到一张安静的纸（[EnrollmentPage.tsx](../apps/web/src/components/EnrollmentPage.tsx)，静止卡片的 12px 圆角）：标题「连接到 Latch」、说明、设备名称、权限清单与主按钮「请求本机确认」。输入框与主按钮在 768px 起是 32px，手机上是 44px。浏览器的权限清单中，查看会话、发起和继续会话、批准普通操作为固定项，「管理此 Host」为复选框，不经配对邀请登记 Host 的第一台设备时默认勾选；桌面端在 `host.sock` 上登记，六项权限全部列为固定项，没有复选框。提交后进入等待状态：静止的琥珀色状态点、「等待本机确认」、剩余秒数、一条琥珀色倒计时细线与「取消」；设备指纹是页面上唯一的大号文字（与本机确认的核对码同一字级：等宽 24px、字距略宽，20 位、按 4 字符分组，窄屏上折行），下面是较小的核对码，便于和电脑上的确认窗口逐字比对。被拒绝、超时与指纹不一致用红色提示并可重新提交。本机确认不可用时，琥珀色提示写出原因与 `pnpm latch device enroll --offline`，表单只接受离线登记码；Host 接受离线登记码时，正常表单下方也提供「使用离线登记码」。手机等远程设备没有配对邀请时只显示获取邀请的说明；浏览器无法在当前地址安全保存设备密钥时只显示一行红色说明，建议换用新版浏览器或桌面端。旧版登录状态显示「此设备需要在本机重新确认」并沿用旧设备名。撤销（红色）、满 30 天、换地址、丢失密钥、登记后浏览器没有保存凭据（例如禁止了 Cookie）与续期后浏览器没有保存新凭据（琥珀色）各有一行说明；后者建议允许 Cookie 后重新加载页面。设备名称可以包含表情（如「❤️ iPhone」「👨‍💻 Mac」）；含换行、不可见字符或改变文字方向的字符时，输入框下方用红色小字说明，提交按钮停用；旧设备名只在符合同一规则时沿用。登记完成后若第一次读取执行端状态失败，页面停在一行琥珀色提示与「重试」上，重试只重新读取状态，不会再登记一台设备。第一次连上 Host 之前，页面只显示「正在连接执行端…」，失败时显示琥珀色提示与「重试」。

**本机确认对话框。** 高风险操作只能在运行 Latch 的电脑上确认。

**审批。** 审批区标题「需要你批准」旁有徽标：普通操作（中性，托盘保持中性）、高风险（红色，托盘转为红色调，卡上的按钮都是浮起的白色次按钮，没有蓝色）、提示，不是安全边界（琥珀色，完全访问会话的询问，并附一行说明：Harness 的询问只是提示，拒绝会转达给它，但不能阻止它执行其他操作）。Host 没有给出风险等级时按高风险决定按钮。按钮中拒绝类在前，「允许一次」在最后，除高风险卡外是唯一的蓝色主按钮。设备不能允许时，「允许」按钮不出现，按钮上方用带锁图标的一行说明原因（没有对应权限，或只能在执行端电脑的 Latch 桌面端批准或回应）；「拒绝」始终可用。桌面端批准高风险操作的按钮是带锁图标的次按钮「在本机确认后允许」，强烈的视觉留给随后的本机确认对话框；「本会话始终允许」只出现在普通操作上，完全访问会话的询问在桌面端只提供拒绝与允许一次。审批区里的标题、原因、参数、路径与差异把控制字符、改变显示方向的字符和零宽字符显示为琥珀底的 `\u{XXXX}` 标记，审批区顶部多一行说明，且没有任何允许按钮使用蓝色主按钮样式。决定之后：结果未知（网络中断、超时）时，输入框上方的红色提示附「可重试同一选择，不会重复提交。」；这台设备此前作了不同选择时提示「此设备此前已选择「…」，本次「…」未生效。」；已由其他设备处理或已失效时，以短暂提示显示「已由「设备名」处理」或「该审批已结束」。

**差异与内容哈希。** 差异文件名旁的标记按执行端的说明区分（[DiffView.tsx](../apps/web/src/components/DiffView.tsx)）：执行端确认文件不存在时为中性「新文件」；文件存在但原内容过大、是二进制或无法读取时为琥珀色「原内容未显示」；执行端没有说明时为琥珀色「原内容未知」。后两种在差异内和审批区顶部各有一行说明可能覆盖现有文件，差异不显示删除行数。新增与删除行数只在不为 0 时用色调文字，为 0 时是提示墨色。差异展开后，文件名下方有一行灰色小字「新内容哈希」与等宽的 `xxxx-xxxx-xxxx-xxxx`，格式与本机确认窗口中的同名一行相同，便于核对审批区看到的内容就是确认窗口绑定的内容；哈希在渲染后计算，期间显示「计算中…」，页面没有 WebCrypto 或文本已被 Agent 截断时不显示这一行。

**会话权限。** 只有完全访问会话在顶栏右侧显示琥珀色的「完全访问」状态胶囊，前面是 `shield-alert`（手机上同样）；逐项询问（L1）是默认，顶栏不显示。检查器的「权限」行列出两种级别的徽标、权限模式变化后的红色「权限模式已变化」徽标，以及执行方、定义是否已验证、模式能否读回、是否请求审批与 Harness 的说明。输入框在以下情况换成带锁图标的只读说明（虚线 `--line-strong` 边的托盘，不带阴影，不像一个等待输入的输入框），运行条与停止按钮保留：完全访问会话在执行端以外的设备上（「完全访问会话只接受执行端电脑上 Latch 桌面端的输入。此设备可以查看、拒绝和取消。」），或设备没有「发起和继续会话」权限。会话不再接受输入时，消息区顶部出现横幅并附「新建会话」，输入框换成「该会话不再接受输入。」：权限模式漂移为红色，来自会话状态；Agent 定义变化、项目中的 Agent 配置在确认后变化、会话创建于安全升级之前，以及无法确认 Harness 已进入预期的权限模式为琥珀色，在这台设备的输入或选项修改被 Host 以对应错误码拒绝后出现。新会话选择器中的完全访问 Harness 带中性的 L3 小徽标（没被选中的选项不报警，选中后由顶栏的琥珀标记表达），在执行端以外的设备上禁用并注明「仅本机桌面端」；在桌面端选中时，输入框下方用琥珀色小字提示「开启完全访问会话需要本机确认。该会话可以读写 Latch 数据和 Host 身份私钥。」

**开发版标记。** Host 报告开发模式时（当前的构建都未经签名发布，所以总是如此），侧栏底部电脑名旁（≥1024px）、图标栏底部（平板）或设置页标题栏（手机）显示一个中性小标签「开发版」，悬停提示与读屏名称为「开发模式：Host 代码可被本机修改」；「设置 › 设备」在「此设备」下写出整句说明：此版本未经签名发布，能修改本机文件的程序也能修改 Host 与桌面端。它不使用红色。

**设备设置。** 「此设备」（[DevicesSettings.tsx](../apps/web/src/settings/DevicesSettings.tsx)）：可修改的设备名称，以及连接方式、状态（正常是默认状态，只写文字；需要处理的状态才用徽标）、设备指纹、权限与登记有效期，以细分隔线排列，末尾是红字次按钮「撤销此设备」。「已登记的设备」（需要「管理此 Host」）：每台设备一行，显示名称（当前设备带「本机」）、非正常状态的徽标（待复核（仅查看）与需重新确认为琥珀色，已撤销为红色并排在最后）、连接方式与最近使用（或撤销时间）、权限；其他未撤销的设备提供「权限…」（需重新确认的设备没有）与「撤销」。撤销前说明由它邀请配对的设备会降为仅查看，等待复核。「权限…」对话框中，「批准高风险操作」与「设置密钥」只对在执行端桌面端登记的设备提供；增加权限或恢复待复核的设备时按钮为「授予权限（需要本机确认）」，只能在执行端的桌面端进行，其他设备上按钮停用并说明原因；只收回权限时按钮为「保存权限」，任何管理设备都可以。设备名中的隐藏字符按审批区的规则显示为 `\u{XXXX}`，包括撤销确认与权限对话框里的名称；改名时的校验与登记页相同。「手机配对」：只有执行端桌面端的管理设备、且 Host 配置了 HTTPS 时显示「生成配对二维码」；二维码为 data URL 图片，10 分钟内有效、只能使用一次，附剩余时间、三步说明、复制链接（手机上为分享链接）与「重新生成」。其他情况只显示一行原因：没有 HTTPS 时说明启动参数，不在执行端桌面端时指向桌面端或 `pnpm latch device invite`。

**模型服务与 Agent。** 执行端以外的设备不能输入或更换密钥（仍可移除），字段显示锁定状态，已有服务的说明给出 `pnpm latch provider set-key <id>` 的替代方式；已保存的密钥注明「密钥只发往 <地址>」，修改地址时提示会清空密钥。Host 出站策略拒绝某个地址时，执行端桌面端的管理设备会看到一行琥珀色说明与「允许 Host 访问 <地址>（需要本机确认）」，确认后地址加入白名单并重新检测连接。添加 Agent 以及修改启动命令、参数与环境变量只能在执行端桌面端进行，名称与启用状态任何管理设备都可以改；每个 Agent 标注中性的 L3 与许可证小徽标；未验证的定义另带中性小徽标「未验证的定义」，已验证的预设是默认，不加标记。

**旧版 Host。** 快照中没有 `host` 时，Host 来自升级前的构建：界面退回旧规则（普通的允许与拒绝、由旧的主设备身份决定设置），隐藏设备、邀请与本机确认相关的界面，并在消息区顶部显示一行中性提示「此 Host 仍是旧版本，重启 Host 后启用设备确认。」；未登录的浏览器在这样的 Host 上看到「此 Host 版本过旧，请在电脑上重启 Latch。」

**审计回滚。** 审计记录被回滚时显示红色横幅，可核对或关闭。

**界面出错。** 工作区渲染出错时不会整页空白：显示一张卡片「界面出错，当前内容无法显示。」，提供「回到新会话」与「重新加载」；本机确认对话框不受影响。单条回复渲染出错时，这一条按纯文本显示。

## 流式与阅读

| 情况 | 界面行为 |
| --- | --- |
| 等待首段输出 | 运行条显示等待模型；不伪造思考内容或百分比 |
| 正文到达 | 在稳定身份的同一消息行内更新 Markdown，完成后沿用该行 |
| 工具调度 | 区分等待执行、等待确认、执行中、完成、失败、取消 |
| 审批 | 合并在对应工具卡片内，展示原因、参数与预览 |
| 取消 | 请求中保留取消状态；超时显示"尚未确认"并允许重试；部分回复保留 |
| 离线 | 保留已读内容；连接状态单独标注，恢复并同步后才显示已连接 |
| 上翻阅读 | 进入阅读模式，流式输出不夺走位置；"回到最新"恢复跟随 |
| 切换会话 | 阅读位置按会话保存；旧会话的异步结果不得写入当前会话 |

所有程序性滚动集中在 `useReadingPosition`（`jumpToLatest`、`reveal`）；消息与工具行使用 `data-message-id` 作为锚点。不要在组件中另外写入 `scrollTop` 或调用 `scrollIntoView`。布局改变、代码展开与视口变化不等于用户主动滚动。

Markdown 支持标题、列表、引用、表格、内联代码与代码块；原始 HTML 不执行，URL 只允许安全协议；图片从不加载，网页图片显示为「外部图片：说明」链接，其他图片只显示说明文字；嵌套过深的回复以一行灰色说明加纯文本显示；表格与代码在自身容器内滚动；代码可复制与展开，剪贴板失败有明确提示；代码中的不可见字符显示为 `\u{XXXX}` 标记，工具栏注明「含不可见字符」，复制内容保持原样。在桌面端，链接要在主进程的原生对话框中确认完整地址后才会在系统浏览器打开。流式全文不设 `aria-live`，避免逐字播报。

## 验收

UI 改动需要在桌面、平板、手机宽度检查真实渲染，覆盖正常、进行中、失败或等待状态，以及浅色与深色。`e2e/design.e2e.ts` 覆盖 320 / 375 / 414 / 768 / 1440px 的可达性、溢出与真实点击区域，包括开发版标记；`e2e/enrollment.e2e.ts` 在 1440×1000、768×1024、390×844 下截取登记页的表单、等待、拒绝、本机确认不可用与旧版重新确认；`e2e/permissions-ui.e2e.ts` 截取高风险审批、完全访问只读（桌面与手机）、权限漂移（含深色）与 Harness 选择器；`e2e/visual.e2e.ts` 在 390×844、768×1024、1440×900 下以浅色与深色截取浏览器能到达的每个状态与原语总览页（`ui-gallery`），并可与上一次运行逐像素比较（见 [TESTING.md](TESTING.md#视觉截图)「视觉截图」）。原语的角色与名称、键盘、焦点、提示框、禁用与运行中、对话框的焦点限制与归还、手机上的底部面板、触屏命中区、减少动效，以及活的指示的同一相位、接力编号与周期、只为亲眼看到的变化播放的一次性动效，由 `packages/ui/test/` 在真实浏览器里检查（`pnpm test --project @latch/ui`）。截图写入被忽略提交的 `test-results/`，不包含任何凭据。本机确认对话框只在桌面端出现，由 `e2e/desktop.e2e.ts`（`HARNESS_ELECTRON_E2E=1`）覆盖并截图。浏览器尺寸模拟不等于 iOS/Android 真机的软键盘、后台挂起与读屏验收。
