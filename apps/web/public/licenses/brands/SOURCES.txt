Brand icons

The web client shows the icon of each agent and model service it can use, from the files in
apps/web/src/assets/brands/. They are copied unmodified from the sources below; native/ios/App/Brands.xcassets holds the same
engine-mark files, unmodified, for the iPhone app (SVG kept as vectors; codex.svg, whose 1em size the system SVG
renderer cannot draw, as a PDF printed from it with no change to the drawing and its title and creator left blank). The
