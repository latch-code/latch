# Latch iOS

`Sources/LatchNativeCore` 支持 iOS/macOS；选中会话协商增量。`Testkit` 不进产品。

- Host 是设备、权限、会话与执行结果的唯一权威；地址、Bonjour 与中继不是身份。
- 先验证敲门的服务端 HMAC，再发设备证书；TLS 1.3、固定 SNI/ALPN、禁恢复，根证明通过前不交付业务数据。内层身份不从网络学习或替换。
- 真机的连接与验证分别用不可导出的 Secure Enclave 密钥。连接、续签不弹认证；正文签名只在启用 Face ID 后确认在场（默认关）。模拟器只验协议。
- 密钥、邀请码、地址簿通行证与正文窗口回执不进日志、URL、通知正文或明文文件。验证窗口和恢复回执仅内存；设备资料和缓存使用本设备、解锁时可用的 Keychain 与认证加密。
- `Phone*` 夹具覆盖真实能力。正文到期时按 Face ID 偏好自动重开或确认；连接独立，旧错不撤新窗，读取不开窗。
- 重开、锁屏、撤销或窗口到期立即撤下正文与预览、清理解密文件。快照不授予正文。重开先等旧快照与锁定完成，再查打开代次及保护数据。
- 对话和输入的复制/剪切只写本机剪贴板并设到期时间，关闭文本拖出与 Writing Tools；后台切换先遮住系统快照。纯文本与重绘 PNG/JPEG 以外的 Quick Look 格式没有自动验收，不开启。
- 资料和缓存按固定 Root 加设备 ID 隔开。撤销清理失败保留加密待办，不能重新连接被撤销身份；恢复资料库时重试。密钥删除回调不能验收系统钥匙串。
- 写入超时保持结果未知，保留原 requestId/请求体，不自动重放。路径切换不恢复权限，不重发写入，迟到的响应不能覆盖新连接。
- 所有缓冲、解析、请求、重试与阶段时间都有上限；网络失败不删除登记身份。
- 中继内外层画像固定、直连h2。读写文件逐块复查窗口/版本，单流至多1MiB；取消经NIOTS关闭并等待，不再申请。
- 列表与每个会话分别确认已应用的 SSE 游标；快照变新不能跳过未应用正文。Root 签名撤销证明同时绑定电脑和本设备后才能清除登记，连接错误不清除登记。
- Bonjour 只提示当前接口地址，不盲拨旧私网地址。过期连接簿只取完整验证的发现密钥，弃用地址与票据。
- 发现 epoch 仅作取簿提示：有效正文窗口内由一个所有者合并刷新，固定 Root 验签并持久化后才采用；提示不能替换已验密钥或确认正文游标。
- 邻近提示只用当前公有 NWPath 网关与接口掩码，在正文窗口内后台提交；是否邻近由 Host 的物理连接证据决定，不提升权限，也不阻塞拨号。
- 待办须有 `workItems`、`workItemTurns`；随窗口撤下私有列表、正文与证据。决定匹配原运行与决定 ID，沿用会话回执。差异与 PR 各核 SHA。
- 审批摘要优先结构化标题，回退时显示已知动作和工具名；只补 Host 投影目标，转义不可见字符。
- Swift 包版本精确锁定，主源发布至少七天；提交 Package.resolved。共享编码遵循 link-v1/security-v1 向量，不另创协议。
- Vitest 编排 Swift 编译、向量与本地互操作，不另设 JS/XCTest。用临时目录、端口 0、假模型、无签名模拟器与夹具身份；不动用户 Host、默认钥匙串或真实模型。

见 docs/STREAMING.md。真机 Secure Enclave、Face ID、App Attest 与推送签名由所有者验收。

- `LatchScreens` 只编模拟器：截图场景与 `-LatchLive 1` 的软件密钥（`ios-live.e2e.ts`）在 `Screens/` 与 `LATCH_SCREENS` 下，不进 `Latch`（`ios-app.e2e.ts`、`check:boundaries` 核对）。
- Slash 点按只改草稿；组合输入不执行，保留动作不转发。预览晚回不展示。
- 助手见 docs/CUSTOM-AGENTS.md；创建只认成功回执，畸形成功保原请求；离页重试不导航。
- 目录只为固定节点/公钥恢复公网地址；提示不授予正文或替换身份。
