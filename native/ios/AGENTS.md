# Latch iOS

`LatchNativeCore` 支持 iOS/macOS，选中会话协商增量。`Testkit` 不进产品。

- Host 是设备、权限、会话与执行结果的唯一权威；地址、Bonjour 与中继不是身份。
- 先验证敲门的服务端 HMAC，再发设备证书；TLS 1.3、固定 SNI/ALPN、禁恢复，根证明通过前不交付业务数据。内层身份不从网络学习或替换。
- 真机的连接与验证分别用不可导出的 Secure Enclave 密钥。连接、续签不弹认证；正文签名只在启用 Face ID 后确认在场（默认关）。模拟器只验协议。
- 密钥、邀请码、地址簿通行证与正文窗口回执不进日志、URL、通知正文或明文文件。验证窗口和恢复回执仅内存；设备资料和缓存用本设备、解锁时可用的 Keychain 与认证加密。
- `Phone*` 夹具覆盖真实能力。正文到期按 Face ID 偏好重开或确认；连接独立，旧错不撤新窗，读取不开窗。
- 进后台、重开、锁屏、撤销或窗口到期立即撤下正文与预览、清理解密文件；后台至多留连接与窗口令牌 30 s，回来 Host 复核。快照不授予正文。重开先等旧快照与锁定，再查代次与保护数据。
- 对话与输入复制/剪切仅本机、设到期；禁拖出与 Writing Tools。仅点按打开链接，后台先遮系统快照。Quick Look 仅纯文本和重绘 PNG/JPEG。只在人粘贴时取图，排队绑定原会话与正文窗口。
- 资料与缓存按固定 Root、设备 ID 隔开，记住上次选机。密钥删除回调不能验收钥匙串。
- 断链按代次静默重拨，Code 开窗保留输入。正文按 requestId 标记发送。写超时未知，保留原请求不重发。切路复核权限，丢弃旧回执。
- 缓冲、解析、请求、重试与阶段时间都有上限；网络失败不删身份。
- 中继内外层画像固定、直连h2。读写文件逐块复查窗口/版本，单流至多1MiB；取消经NIOTS关闭并等待，不再申请。
- 摘要先显，限次补齐。列表与会话各认已应用 SSE 游标，不跳正文。关窗撤下团队关系。
- Mac 撤销须有绑定电脑与本设备的 Root 签名。人可确认本机移除；连接簿仅更新已登记项。见[移除](../../docs/DESIGN.md#原生待办与审阅)。
- Bonjour 只提示当前接口地址，不盲拨旧私网地址。过期连接簿只取完整验证的密钥，弃用地址与票据。
- 发现 epoch 仅作取簿提示：有效正文窗口内由一个所有者合并刷新，固定 Root 验签并持久化后才采用；提示不替换已验密钥或确认正文游标。
- 邻近提示只用当前公有 NWPath 网关与接口掩码，在正文窗口内后台提交；是否邻近由 Host 的物理连接证据决定，不提权或阻塞拨号。
- 待办须有 `workItems`、`workItemTurns`。列表仅用摘要。关窗撤下私有列表、文件树、正文和证据。决定核对运行与决定 ID，沿用原回执；差异和 PR 核 SHA。
- 审批摘要优先结构化标题，否则显示已知动作与工具名；只补 Host 投影，转义不可见字符。
- Swift 包精确锁定，发布满七天，提交 Package.resolved。编码按 link-v1/security-v1 向量。
- Vitest 编排 Swift 编译、向量与互操作。临时目录、端口 0、假模型、无签名模拟器、夹具身份；不碰用户 Host 与默认钥匙串。

锁屏可预览，决定重验。私有审批用通用提示，密钥仅本机。[通知](../../docs/IOS-NOTIFICATIONS.md)

- `LatchScreens` 仅模拟器：场景与 `-LatchLive 1` 软件密钥限 `Screens/`、`LATCH_SCREENS`；`ios-app.e2e.ts`、`check:boundaries` 核对。
- ＋只插入或复用 Slash；组词不执行，保留动作不转发，迟到预览丢弃。
- 创建助手凭有效回执，畸形保原请求；离页重试不导航。工作电脑按 hostId、agentId 打开，草稿不跨机。
- 即将的定时归「动态」；电脑、唤醒与通知归「运行设置」。
- 目录仅按固定节点/公钥恢复公网地址；提示不授正文、不换身份。
