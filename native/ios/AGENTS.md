# Latch iOS

`LatchNativeCore` 支持 iOS/macOS，选中会话协商增量。`Testkit` 不进产品。

- Host 权威管理设备、权限、会话与执行结果；地址、Bonjour、中继不授身份。
- 跨网首次配对独立用固定 Root、本次登记挑战与两把公钥算六位码，和 Mac 系统窗口核对。
- 先验敲门 HMAC 再发设备证书。TLS 1.3、固定 SNI/ALPN、禁恢复；先验固定 Root 再交付数据。
- 真机用两把不可导出的 Secure Enclave 密钥。连接、续签免认证；正文签名按 Face ID 设置（默认关）。模拟器只验协议。
- 密钥、邀请码、通行证与正文回执不进日志、URL、通知或明文。验证窗口与恢复回执仅内存；资料与缓存用本设备解锁 Keychain 与认证加密。
- `Phone*` 夹具覆盖真实能力。正文到期按 Face ID 偏好重开或确认；连接独立，旧错不撤新窗，读取不开窗。
- 进后台、重开、锁屏、撤销或窗口到期立即撤下正文与预览、清理解密文件；后台至多留连接与窗口令牌 30 s，回来 Host 复核。快照不授予正文。重开先等旧快照与锁定，再查代次与保护数据。
- 引用整块编辑、复制原话。复制/剪切限本机且到期；禁拖出与 Writing Tools。仅点按打开链接，后台先遮系统快照。Quick Look 仅纯文本和重绘 PNG/JPEG。粘贴才取图。附件绑定会话与窗口；按本机偏好排队或追加，＋切换。
- 资料、缓存按固定 Root 与设备 ID 隔开，记住选机。删除回调不能验收钥匙串。
- 断链按代次静默重拨，Code 开窗保留输入。发送记 requestId，写超时未知，留原请求不重发。切路复核权限，丢弃旧回执。
- 缓冲、解析、请求、重试与阶段耗时有界；断网不删身份。
- 中继内外层画像固定、直连h2。读写文件逐块复查窗口/版本，单流至多1MiB；取消经NIOTS关闭并等待，不再申请。
- 摘要先显，限次补齐。列表与会话各认已应用 SSE 游标，不跳正文。关窗撤下团队关系。
- Mac 撤销须有绑定电脑与本设备的 Root 签名。人可确认本机移除；连接簿仅更新登记项。见[移除](../../docs/DESIGN.md#原生待办与审阅)。
- 跨网直连只用当前发现与有效签名簿一致的地址、人选择的簿地址或同 Root 新扫码。换网清临时地址。过期簿弃地址与票据，只取已验密钥。
- 发现 epoch 仅提示取簿。有效窗口内合并刷新，固定 Root 验签并持久化后采用；提示不换密钥、不确认正文游标。
- 邻近提示取当前 NWPath 网关与接口掩码，在正文窗口内后台提交。Host 核验物理连接，不提权、不阻塞拨号。
- 待办须有 `workItems`、`workItemTurns`。列表仅用摘要。关窗撤下私有列表、文件树、正文和证据。决定核对运行与决定 ID，沿用原回执；差异和 PR 核 SHA。
- 审批摘要优先结构化标题，否则显示已知动作与工具名；只补 Host 投影，转义不可见字符。
- Swift 包精确锁定，发布满七天，提交 Package.resolved。编码按 link-v1/security-v1 向量。
- Vitest 验 Swift、向量与互操作。用临时目录、端口 0、假模型、免签模拟器、夹具身份。禁碰用户 Host 与钥匙串。

锁屏可预览，决定重验。私有审批用通用提示，密钥仅本机。[通知](../../docs/IOS-NOTIFICATIONS.md)

- `LatchScreens` 仅模拟器。场景、 `-LatchLive 1` 软件密钥限 `Screens/`、`LATCH_SCREENS`（`ios-app.e2e.ts`、`check:boundaries`）。
- @ 文件点选；待办一人；协作文字、收发分权，回访原轮。
- ＋仅插入或复用 Slash；组词不执行，保留动作不转发，弃迟到预览。
- 创建凭回执，畸形保原请求；离页重试不导航。按 hostId、agentId 打开工作电脑，草稿不跨机。
- 即将定时归「动态」；电脑、唤醒与通知归「运行设置」。
- 目录仅按固定节点/公钥恢复公网地址；提示不授正文、不换身份。
