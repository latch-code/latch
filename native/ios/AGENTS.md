# Latch iOS

`Sources/LatchNativeCore` 是 iOS/macOS 共享的有界线格式、系统密码学、传输、验证窗口、工作台与加密资料库。`App` 与 `Latch.xcodeproj` 是 iPhone/iPad 应用，SwiftUI 组合平台页面，UIKit/TextKit 2 承载对话与输入。`Testkit` 是只由 Vitest 驱动的隔离夹具，不进入应用产品。

- Host 是设备、权限、会话与执行结果的唯一权威；地址、Bonjour 与中继不是身份。
- 先验证敲门的服务端 HMAC，再发设备证书；TLS 1.3、固定 SNI/ALPN、禁恢复，根证明通过前不交付业务数据。内层身份不从网络学习或替换。
- 连接密钥与验证密钥不同；真实设备用不可导出的 Secure Enclave 密钥。连接及证书续签不弹认证；正文窗口签名使用独立验证密钥和系统用户在场确认。模拟器只验证协议。
- 密钥、邀请码、地址簿通行证与正文窗口回执不进日志、URL、通知正文或明文文件。验证窗口和恢复回执仅内存；设备资料和缓存使用本设备、解锁时可用的 Keychain 与认证加密。
- App 重新打开、锁屏、撤销或窗口到期时撤下正文和预览，清理临时解密文件；快照列表不能代替正文授权。
- 对话和输入的复制/剪切只写本机剪贴板并设到期时间，关闭文本拖出与 Writing Tools；后台切换先遮住系统快照。纯文本与重绘 PNG/JPEG 以外的 Quick Look 格式没有自动验收，不开启。
- 资料和缓存按固定 Root 加设备 ID 隔开。撤销清理失败保留加密待办，不能重新连接被撤销身份；恢复资料库时重试清理。测试的密钥删除回调不等于系统钥匙串验收。
- 写入超时保持结果未知，保留原 requestId/请求体，不自动重放。路径切换不恢复权限，不重发写入，迟到的响应不能覆盖新连接。
- 所有缓冲、解析、请求、重试与阶段时间都有上限；网络失败不删除登记身份。
- 列表与每个会话分别确认已应用的 SSE 游标；快照变新不能跳过未应用正文。Root 签名撤销证明同时绑定电脑和本设备后才能清除登记，普通连接错误不能触发清除。
- Bonjour 只提供当前接口的地址提示；不盲拨历史私网地址。过期连接簿只可提取经过完整验证的发现密钥，不能继续使用其地址或票据。
- 发现 epoch 仅作取簿提示：有效正文窗口内由一个所有者合并刷新，固定 Root 验签并持久化后才采用；提示不能替换已验密钥或确认正文游标。
- 邻近提示只用当前公有 NWPath 网关与接口掩码，在正文窗口内后台提交；是否邻近由 Host 的物理连接证据决定，不提升权限，也不阻塞拨号。
- Swift 包版本精确锁定，主源发布至少七天；提交 Package.resolved。共享编码遵循 link-v1/security-v1 向量，不另创协议。
- 系统性验证统一由现有 Vitest 项目编排 Swift 编译、向量及本地 Host 互操作；不新增独立 JS 或 XCTest 测试入口。只用临时目录、端口0、假模型、无签名模拟器构建与夹具身份；不操作用户 Host、默认钥匙串或真实模型。

机制见 docs/REMOTE.md、docs/RELAY.md、docs/STREAMING.md。真机 Secure Enclave、Face ID、App Attest 与推送签名配置由所有者人工验收，自动化结果不能代替它们。
