# @latch/link-client

Node 原生链路、平台密码适配器、WebSocket 与 HTTP/2。只通过包名导入 link-wire。

- 只用平台 TLS1.3；先核对 Host 的敲门绑定证明，再发送设备证书；Host 根证明通过前不交付业务数据。
- 正文窗口按当前连接与 App 打开回执恢复，网络身份不能替代验证回执。
- 外层中继固定 SPKI 后才发送准入秘密；禁用会话恢复与 0-RTT。
- 一个 PathManager 拥有重连；迟到结果关闭；网络失败不清除设备身份。
- 连接簿先核对固定根签名与设备，再检查代次；回滚或同代次不同内容拒绝。中继控制与已有数据分开关闭。
- 所有队列、缓冲、阶段时限有上限，取消等待真实结算。

机制见根 docs/REMOTE.md、docs/RELAY.md。测试只用临时目录与端口0的 Vitest。
