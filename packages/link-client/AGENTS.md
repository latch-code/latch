# @latch/link-client

Node 原生链路、平台密码适配器、WebSocket 与 HTTP/2。只通过包名导入 link-wire。

构建 TLS 组件需要 Go 1.26.x ≥1.26.10 或 1.27.x ≥1.27.3，仅标准库；通过 build-native-tls 子入口构建。调用方显式提供输出和编译器位置，运行连接时不编译或下载。

- 只用平台 TLS1.3；先核对 Host 的敲门绑定证明，再发送设备证书；Host 根证明通过前不交付业务数据。
- 内层服务端使用组合根注入的本地 Go TLS 组件，私有 FD 连接；组件缺失拒绝，不能退回出票的 Node TLS。限制自有进程并等待真实退出。
- 正文窗口按当前连接与 App 打开回执恢复，网络身份不能替代验证回执。
- 外层中继：self 固定 SPKI、edge 先验中继密钥对本连接随机数的签名，之后才发送登记、接合或准入；edge 的多个地址竞速，以签名而非主机名认节点。禁用会话恢复与 0-RTT。
- Host 传入的出站租约绑定每条连接的来源与锁定 IP；撤销后立即关闭对应的实际连接。
- 一个 PathManager 拥有重连；迟到结果关闭；网络失败不清除设备身份。
- 连接簿先核对固定根签名与设备，再检查代次；回滚或同代次不同内容拒绝。中继控制与已有数据分开关闭。
- 注册计算挑战只在有界后台线程运行；墙钟超时开始取消，实际 exit 前不归还容量，不在主线程执行 scrypt。
- 有效敲门的重放记录每身份最多 32 条、合计 4096 条、三分钟保留；Host 拒绝准入槽位的敲门不进入记录。
- 所有队列、缓冲、阶段时限有上限，取消等待真实结算。
- 自定义 carrier 独立绑定 driver/描述摘要，固定 h2；官方 relay 不协商降级。字节/消息桥和真实 close 契约见 TRANSPORT-PLUGINS.md，慢速 IM 与手机 connector 不冒充已实现。
- 中继 HTTP/2 全部字节经 latch-pad/1 固定网格，直连固定 h2；控制冷却不突变已有大档，每单元前重查原窗口，失效丢队列并关闭，不延长期限。
- 仅固定根签名的自身设备墓碑可以结束工作台与清除身份；连接失败、中继回执都不能替代。
- 发现 epoch 只是合并取簿的提示，不替代根签名、正文窗口或设备状态；签簿本身不改变 epoch。
- 恢复游标按列表/选中会话保存，只在消费者应用后推进；元数据快照的 revision 不能吞掉尚未应用的正文事件。

测试只用临时目录与端口0的 Vitest。
